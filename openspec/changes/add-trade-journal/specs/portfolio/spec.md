## Purpose

Портфель робота — модель счёта и позиций: баланс (стартовый депозит, реализованный и плавающий P/L), открытые позиции со средней ценой входа, агрегированный риск открытых позиций и контроль ГО-ёмкости перед новыми сделками.

## ADDED Requirements

### Requirement: Стартовый депозит
Система ДОЛЖНА вести учёт счёта, начиная со значения `initial_deposit` из торговой секции конфигурации. Депозит задаётся в рублях и НЕ запрашивается у биржи/брокера.

#### Scenario: Первый запуск
- **WHEN** робот запускается без истории сделок
- **THEN** баланс равен `initial_deposit` из конфигурации

### Requirement: Баланс как сумма депозита, реализованного и плавающего P/L
Текущий баланс ДОЛЖЕН складываться из стартового депозита, суммы реализованных прибылей/убытков закрытых этапов и плавающего (нереализованного) P/L открытых позиций, пересчитанного по последней закрытой цене свечи. Баланс ДОЛЖЕН использоваться как база для лимита риска и проверки ГО при приёме новых заявок.

#### Scenario: Плавающий P/L учитывается
- **WHEN** есть открытая позиция по инструменту и цена изменилась
- **THEN** баланс отражает плавающий P/L этой позиции по последней закрытой цене

#### Scenario: Реализованный P/L после выхода
- **WHEN** позиция (или её часть) закрыта
- **THEN** разница цена входа/выхода × количество минус комиссии добавляется к реализованному P/L баланса

### Requirement: Учёт позиций и средней цены входа
Система ДОЛЖНА вести открытые позиции: инструмент, направление (BUY/SELL), количество, средняя цена входа, привязанный стоп/тейк и `position_id`. При доборе средняя цена входа ДОЛЖНА пересчитываться по формуле `(сумма объём×цена)/(сумма объём)`. При частичном выходе средняя цена входа НЕ меняется, количество уменьшается.

#### Scenario: Добор пересчитывает среднюю цену
- **WHEN** в позицию из 2 контрактов по 100 добавляется 1 контракт по 110
- **THEN** средняя цена входа становится `(2×100 + 1×110)/3`

#### Scenario: Частичный выход не меняет среднюю цену
- **WHEN** из позиции 3 контрактов закрывается 1
- **THEN** средняя цена входа остаётся прежней, количество становится 2

### Requirement: Лимит суммарного риска открытых позиций
Сумма рисков открытых позиций (каждая зафиксирована при входе как `risk_rub`) НЕ ДОЛЖНА превышать `max_risk_pct` процентов от текущего баланса. Заявки, при которых суммарный риск выходит за лимит, ДОЛЖНЫ отклоняться слоем исполнения (см. broker).

#### Scenario: Вторая сделка в лимите
- **WHEN** риск первой позиции 1000, баланс 100000, лимит 2%, новая сделка добавляет риск 500
- **THEN** суммарный риск 1500 ≤ 2000, сделка допустима

#### Scenario: Вторая сделка превышает лимит
- **WHEN** риск первой позиции 1600, баланс 100000, лимит 2%, новая сделка добавляет риск 600
- **THEN** суммарный риск 2200 > 2000, новая заявка отклоняется (или контролируется по правилам broker)

### Requirement: Проверка ГО-ёмкости
Новая позиция ДОЛЖНА приниматься только если сумма ГО открытых позиций и ожидаемого ГО новой позиции не превышает текущий баланс. Ожидаемое ГО берётся из метаданных контракта (ГО покупателя/продавца для фьючерсов; для инструментов без ГО учёт ГО не выполняется).

#### Scenario: Достаточно свободных средств
- **WHEN** сумма занятого ГО равна 40000, баланс 100000, ГО новой позиции 30000
- **THEN** 40000 + 30000 ≤ 100000, сделка допустима по ГО

#### Scenario: Недостаточно средств
- **WHEN** сумма занятого ГО равна 80000, ГО новой позиции 30000
- **THEN** 80000 + 30000 > 100000, заявка отклоняется по ГО

### Requirement: Отметка сделки с превышением риска и контр-заявка
Если заявка исполнилась, но суммарный риск превышает лимит, система ДОЛЖНА зафиксировать в дневнике отметку «свершена с превышением риска» и немедленно выставить контр-заявку на закрытие той же части позиции, что поступила с превышением. Позиция после контр-заявки возвращается в пределы риска; убыток/прибыль контр-операции фиксируется в дневнике.

#### Scenario: Превышение после исполнения
- **WHEN** заявка исполнилась, а суммарный риск открытых позиций превысил лимит
- **THEN** в дневник пишется отметка о превышении и подаётся контр-заявка на закрытие лишнего объёма
