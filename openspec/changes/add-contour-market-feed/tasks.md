## 1. Рыночная база: схема и отметки контура

- [ ] 1.1 Версия схемы в `metadata`, миграция вперёд одной транзакцией: `contour_cursors`, `contour_id` в `analysis_cursors` (пересоздание таблицы), `input_reference` → `input_references["emulation"]`, перенос `processed_through` контуру `emulation`; резервная копия `*.pre-contour-feed` перед первой миграцией

- [ ] 1.3 Удержание целостности в `record_candles` и `mark_processed`: потреблено хотя бы одним контуром; `contour_id` в инциденте; `cursors()` отдаёт наибольший `processed_through` по контурам
- [ ] 1.4 Таблица `pair_readiness`, методы `publish_pair_readiness` и `pair_readiness`
- [ ] 1.5 Зарезервированный префикс `contour-` в `acknowledge` через HTTP (`export_api.py`); контуры подтверждают напрямую
- [ ] 1.6 Тесты `tests/unit/data/`: миграция на копии схемы до изменения, отклонение записи без контура, удержание по отметкам двух контуров, независимость курсоров анализа
