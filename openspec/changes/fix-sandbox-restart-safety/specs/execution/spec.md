## MODIFIED Requirements

### Requirement: Возобновление адресного исполнения после блокировки данными
Нормативный уровень: MUST. В текущем режиме симуляция адресных команд ДОЛЖНА обрабатывать доказанно доступные минуты без зависимости от legacy CSV-журнала. После разрешения пропуска она ДОЛЖНА продолжать с долговечной границы исполнения по порядку; при повторном чтении минуты количество, комиссии и финансовый результат НЕ ДОЛЖНЫ применяться дважды. Если данных для текущей переоценки открытой позиции нет из-за остановленного исполнения, риск новых увеличений ДОЛЖЕН оставаться неизвестным до обработки нужных минут, а старые сигналы НЕ ДОЛЖНЫ превращаться в новые входы. Исключение — контур на брокере: база бюджета у него — капитал со счёта, переоценка журнала справочная, и неизвестная цена одной позиции НЕ ДОЛЖНА запрещать входы по другим инструментам.

Граница исполнения ДОЛЖНА лежать на сетке минут. Исполнение у брокера, подтверждение стопа и постановка входа происходят внутри минуты; граница из такого события ДОЛЖНА быть началом его минуты (включительно), а проба следующих минут барьера покрытия ДОЛЖНА идти по сетке и от границы, пришедшей не по сетке. После перезапуска цена открытой позиции для переоценки ДОЛЖНА браться из закрытия последней исполненной минуты, как до перезапуска; удержанные барьером минуты в неё НЕ ДОЛЖНЫ попадать.

Исключение симулятора до надёжной фиксации событий НЕ ДОЛЖНО продвигать границу исполнения или разрешать дальнейшие бары по этому инструменту в том же непроверенном состоянии. Незавершённый пакет событий ДОЛЖЕН быть повторён с прежней идентичностью, если его безопасный повтор возможен; иначе исполнение ДОЛЖНО возобновляться из долговечного состояния после восстановления, без молчаливого пропуска минуты.

#### Scenario: Адресный симулятор без CSV-журнала
- **WHEN** адресный симулятор создан без legacy CSV-журнала и получает закрытый бар для открытой позиции
- **THEN** бар обрабатывается через адресные события без ошибки обращения к отсутствующему журналу

#### Scenario: Пробел разрешён после перезапуска
- **WHEN** после перезапуска минуту между сохранённой границей и текущими свечами удалось доказанно разрешить
- **THEN** последующие свечи обрабатываются по порядку один раз, позиция получает актуальную переоценку после догоняющей обработки, а старые сигналы не создают входов задним числом

#### Scenario: Исключение до фиксации минуты
- **WHEN** симулятор прервал обработку минуты до надёжной фиксации её событий
- **THEN** курсор остаётся перед этой минутой, последующие минуты не исполняются из частично изменённого состояния, а восстановление не удваивает уже подтверждённые финансовые факты

#### Scenario: Рестарт через секунды после исполнения у брокера
- **GIVEN** вход ED исполнился у брокера в 12:00:04.091 UTC, в минуте 12:01 сделок нет (`confirmed_no_trade`), свечи 12:02 и дальше получены
- **WHEN** контур перезапущен в 12:00:18
- **THEN** граница исполнения ED — 12:00 включительно, минута 12:01 проходится как разрешённая, минуты 12:02 и дальше исполняются по порядку, виртуальный стоп ED проверяется по ним

#### Scenario: Тихий инструмент после рестарта
- **GIVEN** у ED открыта позиция, последняя исполненная минута до рестарта — 11:59
- **WHEN** после рестарта первой приходит минутка другого инструмента
- **THEN** позиция ED переоценивается по закрытию 11:59, и входы не отклоняются как `risk-state-unknown` из-за отсутствия цены ED
