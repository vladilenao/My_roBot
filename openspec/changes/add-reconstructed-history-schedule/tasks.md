## 4. Предварительная загрузка и предупреждение

- [x] 4.1 Загрузка расписания UID цепочки на `[начало − 7 дн, конец + 7 дн]` кусками ≤ 366 дней в хранилище снимка; закрытие диапазонов ленивой загрузки; ошибка не прерывает прогон (D6).
- [x] 4.2 Подсчёт дат по происхождению на участках цепочки; WARNING в консоль и лог при датах без расписания и включённой защите с перечнем внутридневных привязок; INFO-строка при полном покрытии.
- [x] 4.3 Unit-тесты: диапазон длиннее 366 дней режется на куски; после предзагрузки тики не делают запросов расписания; предупреждение есть при пропусках и включённой защите; нет предупреждения при `enabled = false` или без внутридневных привязок; ошибка эмулятора — прогон продолжается, причина в логе.
