## 1. Сторож полос

- [ ] 1.1 `src/data/lane_watchdog.py`: `LaneWatchdog` — `begin(name)` / `end(name)` из потока полосы, `check(now)` находит шаги дольше порога, `snapshot()` для API; стек потока через `sys._current_frames` и `traceback.format_stack`.
- [ ] 1.2 `src/data/poller.py`: `_run_lane` и `_run_live_worker` обрамляют `step()` вызовами `begin` / `end` в `try/finally`; поток `market-data-watchdog` запускается и останавливается вместе с полосами.
- [ ] 1.3 Тревога: один WARNING со стеком на зависший шаг и строка в консоль ядра; по завершении шага — INFO с длительностью.
- [ ] 1.4 Сводка «Полосы данных: запросы за минуту…» пишется из потока сторожа; при зависших полосах в конце строки — «зависли: <полоса> с <время>».
