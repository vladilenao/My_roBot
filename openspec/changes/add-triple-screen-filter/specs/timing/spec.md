# Планирование времени

## ADDED Requirements

### Requirement: Сетки неактивных таймфреймов по запросу
Планировщик ДОЛЖЕН предоставлять математику сетки для любого таймфрейма лестницы, включая не входящие в множество активных ТФ. Сетки неактивных ТФ ДОЛЖНЫ возвращаться по запросу потребителям (фильтрам и кэшу данных) и НЕ ДОЛЖНЫ влиять на момент следующего тика, определение пройденных границ и fallback-паузу. Лестница сеток ДОЛЖНА поддерживать таймфреймы `30m` и `4h` наравне с существующими.

#### Scenario: Сетка неактивного ТФ доступна
- **WHEN** активны ТФ `15m` и `1h`, а запрошена сетка `4h`
- **THEN** возвращается сетка `4h` с корректной математикой границ

#### Scenario: Тридцатиминутная граница
- **WHEN** для сетки `30m` запрошена следующая граница при текущем времени `10:17 UTC`
- **THEN** граница — `10:30 UTC`

#### Scenario: Неактивный ТФ не меняет ритм
- **WHEN** активны ТФ `15m` и `1h`, а сетка `4h` запрошена потребителем
- **THEN** следующий тик планируется на ближайшую границу только активных ТФ (`15m`/`1h`)
