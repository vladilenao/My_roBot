# Дельта: test-data

## MODIFIED Requirements

### Requirement: Жёсткий лимит глубины истории
Запрос к API ДОЛЖЕН ограничивать глубину истории так, чтобы объём скачанных данных не превышал 300 свечей на один тест-кейс. Глубина запроса ДОЛЖНА по умолчанию составлять абсолютный потолок — 300 свечей — и НЕ ДОЛЖНА зависеть от `SIGNAL_WINDOW` или иных параметров `src.config`. Граница `from_` ДОЛЖНА вычисляться явно как `end − (глубина × длительность таймфрейма)`; диапазон по умолчанию `load_candles` (30 дней) НЕ ДОЛЖЕН использоваться.

#### Scenario: Дефолт равен потолку
- **WHEN** скрипт скачивания формирует запрос без явного указания глубины
- **THEN** запрашивается окно на 300 свечей таймфрейма; значение `SIGNAL_WINDOW` на объём запроса не влияет

#### Scenario: Расчёт глубины из конфигурации
- **WHEN** в `src.config` изменено значение `SIGNAL_WINDOW`
- **THEN** глубина запроса скрипта не меняется и остаётся равной 300 свечам

#### Scenario: Часовой таймфрейм, потолок 300
- **WHEN** расчётная глубина превышает 300 свечей
- **THEN** запрашиваются последние 300 свечей; полный доступный период истории не запрашивается

#### Scenario: Запрет дефолтного диапазона
- **WHEN** скрипт формирует запрос
- **THEN** `start_date` и `end_date` передаются в загрузчик явно; значение по умолчанию (30 дней ≈ 720 часовых свечей) не применяется
