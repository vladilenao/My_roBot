## ADDED Requirements

### Requirement: Телеметрия SDK брокера отключена
Нормативный уровень: MUST.
Робот НЕ ДОЛЖЕН включать телеметрию SDK T-Bank Invest (Sentry разработчика SDK). Импорт модуля боевого клиента ДОЛЖЕН заменять точки включения телеметрии в SDK (`init_error_hub`, `async_init_error_hub` модуля `t_tech.invest.clients`) функциями без действий до создания любого клиента. Если SDK не содержит этих точек, ДОЛЖНО записываться предупреждение в лог, а работа ДОЛЖНА продолжаться.

#### Scenario: Открытие боевого клиента
- **WHEN** робот открывает `Client` или `AsyncClient` SDK брокера
- **THEN** `sentry_sdk` не инициализируется, и ни сбои потоков, ни записи лога не отправляются разработчику SDK

#### Scenario: SDK изменил точки включения
- **WHEN** после обновления SDK в `t_tech.invest.clients` нет `init_error_hub`
- **THEN** в лог пишется предупреждение о том, что отключение телеметрии нужно проверить
