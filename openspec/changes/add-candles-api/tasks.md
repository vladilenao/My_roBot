## 1. Рыночная база

- [x] 1.1 `MarketDataStore.candle_series(source)`: пары состава всех происхождений с `short_name`, `ticker`, `instrument_type`, первой и последней завершённой свечой, последней ценой и готовностью — одна транзакция чтения.
- [x] 1.2 `MarketDataStore.candle_window(source, instrument_uid, interval, lower, upper, limit)`: последние `limit` строк окна `[lower, upper)` по возрастанию, признак «раньше есть ещё»; предварительная свеча — только последней и позже последней завершённой.
