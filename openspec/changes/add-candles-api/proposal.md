## Why

UI робота (отдельный репозиторий `UI`, макеты — холст «UI робота — MVP») уже в MVP показывает графики: свечи инструмента на экране контура и мини-графики дня на обзоре. Робот хранит все нужные свечи в рыночной базе ядра, но отдать их UI нечем:

- экспорт `/api/v1/market-data/changes` — машинная лента изменений для Historical Broker API Emulator: курсор, `instrument_uid`, ключ экспорта, формат ошибок 1.8;
- API управления свечей не отдаёт вовсе.

Нужен простой ресурс только на чтение: «дай свечи NG-12.26 15m за окно» — по ключу управления, в формате API управления, с теми же именами инструментов, что в командах контуров.

## What Changes

- **Ресурс `/api/v1/candles`** — ряды свечей, которые хранит ядро: инструмент, таймфрейм, первая и последняя свеча, последняя цена, готовность пары. По этому списку UI строит выбор инструмента и таймфрейма.
- **Ресурс `/api/v1/candles/{instrument}/{timeframe}`** — свечи одного ряда за окно `[from, to)`: последние `limit` свечей окна, новые в конце, незавершённая текущая свеча с `complete: false`. Ссылка `_links.earlier` — на предыдущее окно той же длины, если раньше есть свечи: UI листает график назад.
- **Имена инструментов — как в командах контуров:** короткое имя контракта (`NG-12.26`) или тикер акции (`SBER`). Биржевой тикер (`NGZ6`) и код семейства (`NG`) не принимаются: `404` с подсказкой коротких имён из `suggestions`.
- **Только хранимые ряды, без агрегации и без брокера.** Ресурс читает рыночную базу ядра и не делает запросов к брокеру, не меняет покрытие, курсоры и ленту экспорта.
- **Доступ** — ключ управления и проверка `Host`, как у остальных маршрутов управления. Ошибки — `application/problem+json`; новый код `MARKET_DATA_NOT_READY` (`503`), пока ядро не открыло рыночную базу.
- **Точка входа** `GET /api/v1` для ключа управления получает ссылку `_links.candles`.
- **Swagger** — черновик `openspec/changes/add-candles-api/openapi.yaml` (версия 2.3.0: 2.2.0 занят ещё не влитым `add-tinvest-orders`). В `docs/api/openapi.yaml` он переезжает вместе с обработчиками.

## Capabilities

### New Capabilities

- `candles-api`: ряды свечей ядра и свечи ряда за окно для графиков UI — имена инструментов, окно и листание, незавершённая свеча, ограничения чтения.

### Modified Capabilities

- `control-api`: доступ к `/api/v1/candles…` по ключу управления; ссылка `candles` в точке входа; код ошибки `MARKET_DATA_NOT_READY` и поле `suggestions`.

## Impact

- **`src/data/market_store.py`:** чтение рядов (`roster` всех происхождений + первая и последняя свеча) и свечей окна одним запросом по первичному ключу `candle_current`.
- **Новый `src/bot/candles_view.py`:** разбор параметров, разрешение имени инструмента по составу рыночной базы, сборка ответа и `_links`.
- **`src/data/export_api.py`:** маршруты `GET /api/v1/candles` и `GET /api/v1/candles/{instrument}/{timeframe}` под ключом управления; `_links.candles` в `GET /api/v1`.
- **`src/bot/control_views.py`:** код `MARKET_DATA_NOT_READY`, поле `suggestions`.
- **Контракт:** `docs/api/openapi.yaml` 2.3.0, `docs/api/README.md`, `docs/api/v2-decisions.md`.
- **Тесты:** `tests/unit/data/` (чтение окна и рядов), `tests/unit/bot/` (маршруты, имена, ошибки, контрактный тест на 2.3.0).
- **Без изменений:** приём данных, покрытие, лента `/api/v1/market-data/*`, торговля, история.
