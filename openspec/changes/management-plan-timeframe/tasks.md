- [ ] 1.2 Unit-тест сигнального выхода: 15m-закрытие ниже 15m MA40 при 1h-закрытии выше 1h MA40 не закрывает сделку на 1h. Тест падает на текущем коде.
- [ ] 1.3 Найти тесты, которые сопровождают сделку кадром другого таймфрейма или вызывают `manage` без `timeframe`, и отметить их для переписывания под D1.

## 2. Правило в менеджере

- [ ] 2.1 `TradeManager.manage`: профиль считается только для сделок с `plan.timeframe == timeframe`. `_cancel_stale_entries`, `_close_expiring` и `drain_contract` работают, как раньше. Без `timeframe` профиль не считается (D1).
- [ ] 2.2 Неизвестный или пустой `plan.timeframe`: пропуск на любом кадре, трасса и предупреждение `management-timeframe-unknown` не чаще раза на сделку за запуск (D2).
- [ ] 2.3 `_manage_owned` и обработка противоположного сигнала: сигнал применяется к сделке только при совпадении таймфрейма, иначе трасса `management-timeframe-mismatch` (D6).
- [ ] 2.4 Трасса `profile.<name>.manage` содержит вход `timeframe` (D7).
- [ ] 2.5 Unit-тесты по сценариям требования «Сопровождение на таймфрейме плана»: свой бар переносит стоп; чужой бар не меняет стоп, состояние и экстремум `atr_trend`; неизвестный таймфрейм; сигнал связки с другого таймфрейма; ранее подтянутый стоп 1.1205 не ослабляется кандидатом 1.1199; трасса содержит `1h`.

## 3. Циклы робота

- [ ] 3.1 `LiveAnalysis.step`: таймфреймы сопровождения = таймфреймы привязок ∪ таймфреймы планов открытых сделок инструмента. На таймфрейме без привязок `manage` вызывается на новом текущем закрытом баре без расчёта стратегий и публикации решений. Один вызов на `(instrument, tf, stamp)` (D3).
- [ ] 3.2 Длина кадра `manage` — максимум требований привязок таймфрейма и `management_requirement` профилей открытых сделок этого таймфрейма (D4).
- [ ] 3.3 `LiveAnalysis.register_needs`, `_bootstrap` и `TradingBot._assigned_timeframes` загружают таймфреймы открытых сделок с прогревом их профилей; неготовность видна в `market_data_status` (D3).
- [ ] 3.4 `TradingBot._process`: защитный `protection_timeframe` исключён из таймфреймов сопровождения, исполнение по 1m через `_post_tick` не меняется (D5).
- [ ] 3.5 Unit-тесты циклов: инструмент с привязками 15m и 1h и открытой сделкой на 1h — `manage` для неё срабатывает только на закрытии 1h; привязка на 1h удалена из конфигурации — сделка продолжает сопровождаться на 1h; исторический прогон не считает профиль на 1m.
