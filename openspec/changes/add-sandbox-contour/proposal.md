## Why

Этап С2 документа 2 «Робот на реальном счёте» (версия 12). Разведка С1 показала, что песочница Т-Инвест годится для всей торговли на брокере. Следующий шаг — контур, который живёт рядом с эмуляцией, поднимается после рестарта и сам следит за счётом. Заявок он пока не ставит: сначала нужно увидеть, что контур знает о счёте правду и замечает любое расхождение.

Сегодня ядро умеет держать ровно один торговый контур — эмуляцию: `LiveCore.run_contour` надзирает за её процессом в главном потоке. Контуру на брокере нужен свой процесс, свой ресурс API и свой подъём после рестарта, причём раньше эмуляции.

## What Changes

- **Новый вид контура `sandbox`** — первый контур на брокере. Процесс `run.py --contour sandbox` в папке `data/contours/sandbox/` со своим логом, блокировкой и `status.json`. В С2 он только читает счёт песочницы: ни одной заявки, ни одной свечи.
- **Надзиратель ядра для контура на брокере.** Отдельный поток ядра запускает, подхватывает и поднимает после рестарта процесс песочницы по желаемому из `core.sqlite3`. Эмуляция и её главный поток не меняются. После рестарта песочница поднимается раньше эмуляции.
- **Свой состав из привязок.** Участник состава — привязка (`id` из `[strategies.*]`, инструмент плюс стратегия), а не инструмент. Состав хранится в той же таблице `contour_members` и меняется только командами API. В С2 привязки записываются и показываются, торговать ими контур начнёт на С3.
- **Допуск к старту.** До первого шага контур проверяет:
  - токен песочницы;
  - бот и канал Telegram;
  - счёт робота `My_roBot` (правило С1);
  - отпечаток счёта в своей базе.
  
  Любой отказ — контур не стартует, причина видна в API.
- **Сверщик.** Сверяет позиции, заявки и стоп-заявки счёта с журналом контура при старте и раз в `reconcile_every_min` минут. В С2 журнал пуст, поэтому всё, что есть на счёте, — чужое: инструмент замораживается, в канал «Песочница» уходит тревога. Когда счёт снова совпадает с журналом, заморозка снимается сообщением «расхождение устранено».
- **Ресурс API `/api/v1/sandbox`** по образцу `/api/v1/emulation`:
  - `target`;
  - `bindings` и `bindings/remove`;
  - `reconcile`;
  - `log`.
  
  `GET /api/v1/sandbox/bindings` показывает все привязки конфигурации и где каждая торгует. Маршруты сразу описаны в Swagger 2.1.0 — черновиком `openspec/changes/add-sandbox-contour/openapi.yaml`. В `docs/api/openapi.yaml` он переезжает вместе с обработчиками: контрактные тесты требуют обработчик у каждой операции.
- **Уведомления контура на брокере.** Новый тип события `broker_account`: старт, остановка, тревога сверки, расхождение устранено. Своя доставка в канал «Песочница» ботом «Счёт».
- **Настройки** `[contours.sandbox]`:
  - `telegram_bot_env`;
  - `telegram_channel_env`;
  - `reconcile_every_min`.
- **Отклонение от документа 2 v12.** В документе стартовый состав `bindings` задан в `robot.toml`. Здесь состав, как у эмуляции, задаётся только командами API: один источник правды, без расхождения конфига и базы.

## Capabilities

### New Capabilities

- `broker-contour`: контур на брокере — процесс, допуск к старту, отпечаток счёта, чтение счёта, сверщик, применение целевого состояния на шаге, подъём после рестарта, уведомления. В С2 — вид `sandbox` в режиме «только чтение».

### Modified Capabilities

- `control-api`: ресурс `/api/v1/sandbox`; точка входа `GET /api/v1` показывает песочницу; общие схемы контуров используются контуром на брокере.
- `configuration`: секция `[contours.sandbox]`.
- `notification`: тип события `broker_account` в каталоге.

## Impact

- **Новый пакет `src/broker_contour/`:**
  - `process.py` — цикл процесса;
  - `admission.py` — допуск;
  - `fingerprint.py`;
  - `reconcile.py`;
  - `store.py` — `broker.sqlite3` контура;
  - `notify.py`.
  
  Шлюз и счёт берутся из `src/sandbox` (С1).
- **`src/assembly/`:** надзиратель контура на брокере. `core_state.py` хранит участников-привязок в существующей `contour_members` без смены схемы.
- **`run.py`:** вход `--contour sandbox`, запуск надзирателя до подъёма эмуляции, секреты `TELEGRAM_ACCOUNT_BOT_TOKEN`.
- **API:** `src/data/export_api.py`, `src/bot/control_views.py`, новый `src/bot/sandbox_control.py`, `docs/api/openapi.yaml` 2.1.0 (из черновика change).
- **Уведомления:** `src/events/types.py`, шаблон Telegram, `docs/notification/event-schemas.md`.
- **Настройки:** `src/config_loader.py`, `src/config.py`, `default.toml`.
- **Тесты:** `tests/unit/broker_contour/` с фейковой песочницей из С1, тесты API и надзирателя.
- **Без изменений:** эмуляция, история, приём данных и торговля.
