## 4. Тесты

- [ ] 4.1 Ключ сигнала: сигнал одной привязки в эмуляции и песочнице даёт одинаковый `signal_id`.
- [ ] 4.2 Комиссии:
  - комиссия брокера на два исполнения;
  - только поле комиссии через 15 минут;
  - свежая операция ждёт;
  - повтор после рестарта ничего не меняет;
  - равная сумма — без поправки;
  - старше 7 дней — предупреждение один раз;
  - сбой запроса — сверка продолжается;
  - итоги `…/performance` с `fees_source = broker`.
- [ ] 4.3 Пары:
  - вход хуже на 2 шага;
  - стоп у брокера против стопа по минуте;
  - разный вид выхода;
  - разные лоты и `net_per_lot`;
  - закрыта одна сторона;
  - без шага цены — `steps_unknown`;
  - пара без расхождений.
- [ ] 4.4 Без пары:
  - отказ решения в песочнице;
  - отказ брокера (`REJECTED` без исполнений);
  - неисполненный лимит входа;
  - привязки нет в эмуляции — `not-seen`;
  - привязки эмуляции вне песочницы в отчёт не входят.
- [ ] 4.5 API:
  - контуры остановлены;
  - журнала нет;
  - сводка с `limit` и `earlier`;
  - фильтры;
  - `400` на неизвестный параметр, неверный период, `limit`, неизвестную привязку;
  - ключ экспорта — `401`;
  - ответ по схеме OpenAPI.
- [ ] 4.6 Полный `pytest` и `ruff check src tests run.py`.
