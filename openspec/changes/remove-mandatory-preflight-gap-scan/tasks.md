## 1. Согласование изменения

- [ ] 1.1 Согласовать отмену обязательного предварительного подсчёта разрывов
  по delta-spec `historical-mode`.

## 2. Реализация в роботе

- [ ] 2.1 Убрать сплошной скан ради статистики разрывов из предпроверки
  фиксированных пар, включая резервный путь без `coverage`.
- [ ] 2.2 Убрать аналогичный минутный скан из предпроверки участков
  контрактной цепочки, включая резервный путь без `coverage`.
- [ ] 2.3 Проверить пользовательский вывод: сведения `/coverage` описывают
  только наблюдаемое покрытие, отсутствие отчёта о целостности не выдаётся
  за отсутствие разрывов.

## 3. Проверка и принятие

- [ ] 3.1 Проверить отсутствие чтения внутреннего диапазона ради подсчёта пауз
  для фиксированных пар и цепочки, в том числе без callback `coverage`.
- [ ] 3.2 Проверить сохранение обязательных проверок источника, инструментов,
  прогрева, границ и допустимого завершения контрактов.
- [ ] 3.3 Проверить сохранение переходов через паузы и статистики итогового отчёта.
- [ ] 3.4 Выполнить релевантные тесты и контрольный исторический запуск
  с журналом и наблюдением за расходом ресурсов.
- [ ] 3.5 После принятия синхронизировать основную спецификацию и архивировать
  изменение по процессу OpenSpec.
