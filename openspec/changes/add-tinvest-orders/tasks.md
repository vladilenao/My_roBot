## 4. Торговая часть в контуре

- [ ] 4.3 `TradingBot`: хук опроса между тиками; разбор очереди исполнений не реже раза в `tick_poll_secs`; работа при пустом составе.
- [ ] 4.4 `src/broker_contour/capital.py`: снимок капитала (рубли из `GetPositions`, `liquid_portfolio` рядом), обновление при старте, после своих исполнений и на сверке, один снимок на тик.
- [ ] 4.5 `src/broker_contour/process.py`:
  - при `orders = true` после допуска разбор журнала заявок и непроведённых исполнений, стартовая сверка, затем `TradingContour` на главном потоке;

- [ ] 4.7 Остановка контура: `no_entries` и `close_all` через `TradeManager.stop_contour` с рыночными выходами; самостоятельное завершение без сделок и заявок; `stopped` с числом открытых позиций при штатном выходе.

## 7. Ручная проверка владельцем

- [ ] 7.1 Эмуляция торгует NG всеми стратегиями. `PUT /api/v1/sandbox/target` с `{"mode": "on", "bindings": ["<id одной привязки NG>"]}` → в канале «Песочница» старт с режимом заявок; `GET /api/v1/sandbox` показывает привязку `trading` с контрактом NG.
- [ ] 7.2 Первый сигнал привязки → в канале «Песочница» карточка «ПЕСОЧНИЦА NG» со строками «отправлено, лимит …», «принято брокером, заявка …XXXX», «исполнено N из N по …», позже выход. Сигналы других стратегий NG в канале песочницы не появляются. `python -m src.sandbox account` показывает ту же позицию, сверка `ok`.
- [ ] 7.3 Пока лимитный вход висит у брокера, процесс контура убит (`kill <pid>` из `GET /api/v1/sandbox`), робот перезапущен → в канале «найдена по ключу», в `python -m src.sandbox account` одна заявка с этим входом, дубля нет; если вход исполнился за простой, позиция в журнале совпадает со счётом.
- [ ] 7.4 Срабатывание стопа или цели контуром → рыночная заявка, позиция закрыта или уменьшена, в карточке «стоп исполнен» или «цель 1 взята».
- [ ] 7.5 `python -m src.sandbox buy NG 1` при работающем контуре → тревога по NG, новые входы NG заморожены, выходы работают; после `sell NG 1` — «расхождение устранено».
- [ ] 7.6 `PUT /api/v1/sandbox/target` с `{"mode": "close_all"}` при открытой позиции → входы сняты, позиция закрыта, контур `stopped`, на счёте позиций нет.
- [ ] 7.7 Неделя сделок в песочнице без необъяснённых расхождений сверки.
