## MODIFIED Requirements

### Requirement: Аутентифицированная фабрика клиента
- Система ДОЛЖНА предоставлять функцию `get_client()`, возвращающую аутентифицированный `t_tech.invest.Client` с использованием `TINKOFF_TOKEN`.
- Система ДОЛЖНА предоставлять функцию `client_context(token=None)`, возвращающую контекстный менеджер для клиента API.
- Клиент API ДОЛЖЕН использоваться как контекстный менеджер (`with`) для доступа к атрибуту `instruments`.

#### Scenario: Успешное создание клиента
- **WHEN** вызывается `get_client()` при наличии валидного `TINKOFF_TOKEN`
- **THEN** возвращается экземпляр `t_tech.invest.Client`, готовый к работе с API

#### Scenario: Контекстный менеджер предоставляет instruments
- **WHEN** клиент используется как контекстный менеджер (`with client_context() as client:`)
- **THEN** атрибут `client.instruments` доступен и содержит методы `shares()`, `futures()`, `etfs()`, `currencies()`

#### Scenario: Клиент без контекстного менеджера не имеет instruments
- **WHEN** клиент создаётся без использования `with` (например, `Client(token)`)
- **THEN** атрибут `client.instruments` недоступен и обращение к нему вызывает `AttributeError`

### Requirement: Повтор при ошибке лимита запросов
- Система ДОЛЖНА автоматически повторять API-запросы при ошибке `RESOURCE_EXHAUSTED` (лимит запросов).
- Система ДОЛЖНА использовать экспоненциальную задержку между попытками.
- Система ДОЛЖНА ограничивать количество попыток повтора (по умолчанию 3).
- Система ДОЛЖНА извлекать время сброса лимита из ответа API и использовать его как нижнюю границу задержки.

#### Scenario: API-запрос успешен с первого раза
- **WHEN** API-запрос выполняется без ошибок
- **THEN** функция возвращает результат без задержек и повторов

#### Scenario: Ошибка лимита запросов с повтором
- **WHEN** API-запрос завершается ошибкой `RESOURCE_EXHAUSTED`
- **THEN** система ожидает время сброса лимита (из `ratelimit_reset`) и повторяет запрос

#### Scenario: Превышение максимального количества попыток
- **WHEN** количество попыток повтора исчерпано и ошибка `RESOURCE_EXHAUSTED` сохраняется
- **THEN** функция выбрасывает исключение

#### Scenario: Другие ошибки не повторяются
- **WHEN** API-запрос завершается ошибкой, не связанной с лимитом запросов
- **THEN** функция выбрасывает исключение без повтора

#### Scenario: Экспоненциальная задержка
- **WHEN** происходит повтор из-за лимита запросов
- **THEN** задержка перед следующей попыткой удваивается (10с → 20с → 40с), но не превышает `ratelimit_reset` и `max_delay`
