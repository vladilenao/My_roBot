## ADDED Requirements

### Requirement: Число одновременных прогонов истории
Нормативный уровень: MUST. Ключ `[contours] max_history_runs` ДОЛЖЕН задавать, сколько исторических прогонов ядро ведёт одновременно. Остальные прогоны ждут в очереди.

- Значение — целое от 1 до 8, по умолчанию 2.
- Другое значение или не тот тип ДОЛЖНЫ завершать загрузку `ConfigError` с указанием файла и ключа.
- Вшитый `default.toml` ДОЛЖЕН содержать ключ со значением по умолчанию и комментарием.

Своей секции у истории нет: диапазон, пауза и инструменты приходят в команде, привязки инструментов — общие с эмуляцией.

#### Scenario: Значение по умолчанию
- **WHEN** в `robot.toml` нет ключа `max_history_runs`
- **THEN** ядро ведёт одновременно не больше двух прогонов

#### Scenario: Неверное значение
- **WHEN** `robot.toml` содержит `[contours] max_history_runs = 0`
- **THEN** загрузка завершается `ConfigError` с файлом и ключом `max_history_runs`
