## Why

Этап П5 документа «Ядро и контуры робота» (`docs/architecture/core-contours.md`).
После П4 состав эмуляции фиксируется при запуске. Чтобы добавить газ или
убрать Сбер, контур нужно остановить и запустить заново. Это ждёт закрытия
сделок или закрывает их принудительно, а прогрев и стартовый обзор
повторяются для всех инструментов.

Критерий этапа из документа 1: привязки меняются без перезапуска контура.
Решение владельца: единица состава — инструмент, как при запуске. Инструмент
приходит со всеми своими привязками из `robot.toml`.

## What Changes

- **Новый маршрут** `POST /api/v1/contours/{id}/instruments`:
  - `{"add": ["NG", "SBER"]}` — добавить инструменты. Токены и правила
    разрешения те же, что у `POST /api/v1/contours`. Карточку контракта
    получает ядро.
  - `{"remove": ["NG-12.26"], "mode": "no_entries" | "close_all"}` — убрать
    инструменты. Без `mode` действует `no_entries`: новых входов и доборов по
    инструменту нет, его неисполненные входы снимаются, открытые позиции
    доживают. `close_all` закрывает позиции инструмента на открытии
    следующего бара.

  Ответ — `202` с новым поколением, применение на ближайшей границе тика.
  Повтор — `200` без нового поколения.
- **Желаемый состав в `core.sqlite3`.** Новая таблица `contour_members`:
  инструмент, его карточка и контракт, желаемое (`active` / `removed`),
  режим снятия. Запуск заменяет состав целиком, `add` и `remove` меняют его
  построчно, каждое изменение поднимает поколение контура.
- **Контур меняет состав на границе тика.** Добавленный инструмент проходит
  состояния:
  1. «прогревается» — ядро догревает его пары;
  2. стартовый обзор, как при запуске;
  3. «торгует».

  Убранный инструмент «доживает» или «закрывается», пока по нему есть сделки,
  затем выходит из состава. Повторный `add` доживающего инструмента
  возвращает его к торговле.
- **Менеджер сделок** получает остановку на уровне инструмента. Это те же
  правила, что у остановки контура (П4), но только для сделок одного
  инструмента.
- **Ядро** при `add` догружает потребности нового инструмента: карточку
  контракта, пары паттернов, границы исполнения. Пары убранного инструмента
  ядро продолжает обслуживать до своего рестарта.
- **Состояние в API.** У контура появляется список `members`: инструмент,
  желаемое и фактическое состояние (`warming`, `trading`, `draining`,
  `closing`). Поле `instruments` показывает текущий желаемый активный состав.
  Фактическое берётся из `status.json`.
- **Swagger** (`docs/openapi.yaml`): новый маршрут, схемы, версия
  `1.6.0-proposal`.
- **Документ 1:** состав — инструменты (`contour_members`,
  `/instruments`), а не привязки по id.

Вне этапа:
- снятие отдельной привязки по id;
- снятие пар убранного инструмента с обслуживания ядром до рестарта;
- автоподъём (П6) и история через API (П7).

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `control-api`:
  - маршрут состава;
  - желаемый состав в `core.sqlite3`;
  - `members` и текущий состав в состоянии контура.
- `orchestration` — контур применяет изменения состава на границе тика:
  - прогрев;
  - стартовый обзор добавленного инструмента;
  - дожитие и выход убранного.
- `trade-management` — запрет входов, снятие входов и закрытие позиций на
  уровне одного инструмента.

## Impact

- **Код:**
  - `src/assembly/core_state.py`: `contour_members`;
  - `src/assembly/contour_control.py`: применение состава;
  - `src/bot/live_analysis.py`: обзор одного инструмента;
  - `src/bot/trading_bot.py`: добавление и удаление инструмента;
  - `src/trade_management/manager.py`: остановка по инструменту;
  - `src/assembly/core.py`: команды состава в главном потоке ядра;
  - `src/bot/launch_control.py`, `src/data/export_api.py`, `run.py`.
- **Данные:** новая таблица в `core.sqlite3` (`CREATE TABLE IF NOT EXISTS`),
  поля `members` в `status.json`. Миграции существующих данных не нужны.
- **API:** новый маршрут, Swagger `1.6.0-proposal`.
- **Тесты:**
  - добавление с прогревом и обзором;
  - снятие в двух режимах;
  - возврат доживающего;
  - повтор;
  - отказы разрешения;
  - конфликт с остановкой контура;
  - контракт нового фьючерса без доступа контура к брокеру.
