# Дельта: snapshot-testing

## MODIFIED Requirements

### Requirement: Динамическая параметризация по папкам кейсов
Каждый файл теста в `tests/snapshot/` соответствует одной стратегии и ДОЛЖЕН автоматически обнаруживать свои кейсы во всех папках `tests/snapshot/data/*/<ИНСТРУМЕНТ>_<ТАЙМФРЕЙМ>/` по точному имени файла эталона `<strategy_name>_expected_signals.csv`. Имя папки кейса — имя кейса. Добавление инструмента или кейса НЕ ДОЛЖНО требовать правки кода тестов. Поиск ДОЛЖЕН выполняться по точному имени файла (без wildcard-суффикса), чтобы стратегия не подхватывала эталоны других стратегий.

#### Scenario: Новый кейс подхватывается автоматически
- **WHEN** в `tests/snapshot/data/` добавлена папка `BTC_15m/` с `candles.csv` и `macd_rsi_stoch_expected_signals.csv`
- **THEN** при следующем прогоне pytest стратегия `macd_rsi_stoch` выполняет тест-кейс `BTC_15m`

#### Scenario: Пустая папка данных
- **WHEN** в `tests/snapshot/data/` нет ни одного файла `macd_rsi_stoch_expected_signals.csv`
- **THEN** параметризация даёт ноль кейсов; прогон стратегии завершается без ошибок

#### Scenario: Изоляция стратегий друг от друга
- **WHEN** в кейсе лежат эталоны нескольких стратегий (`macd_rsi_stoch_expected_signals.csv`, `rsi_divergence_expected_signals.csv`)
- **THEN** каждая стратегия сравнивает только свой файл; чужие эталоны игнорируются
