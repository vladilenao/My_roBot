# Дизайн: перечень имён стратегий и валидация привязок

## Context

Имена стратегий существуют только как ключи реестра в рантайме. При заполнении `STRATEGY_ASSIGNMENTS` IDE не подсказывает значения, а опечатка проявляется как бесконечные «Ошибка стратегии …» в цикле (изоляция отказов глотает исключение каждые 9 секунд). Обсуждение с пользователем зафиксировало вариант «2+3»: статический Literal-перечень + fail-fast валидация.

## Goals / Non-Goals

**Goals:**
- Автокомплит и статическая подсветка опечаток при заполнении конфига.
- Мгновенный понятный отказ при невалидных привязках вместо тихих повторов в цикле.
- Реестр остаётся единственным источником истины; ручной перечень не может тихо протухнуть.

**Non-Goals:**
- Генерация Literal кодогенератором из реестра.
- Импорт реестра/пакетов стратегий из `src.config` (вес и побочные эффекты).
- Валидация кортежей `instruments`, передаваемых явно, — предметом является только словарь привязок.

## Decisions

- **D1. Отдельный модуль `src/strategies/names.py`.** Только `from typing import Literal`; никакой связи с реестром. Позволяет `src.config` аннотировать словарь, не подтягивая pandas_ta/пакеты стратегий. Проверяется сценарием «Лёгкость импорта». Лёгкость обеспечивается ленивой регистрацией в родительском пакете (см. D7): Python исполняет `__init__.py` пакета при любом импорте подмодуля, поэтому module-level импорт стратегий в `src/strategies/__init__.py` тянул бы pandas_ta даже через `import src.strategies.names`.
- **D2. `StrategyName = Literal["macd_rsi_stoch"]` — ручной перечень.** Обновляется при добавлении/переименовании стратегии (это и так требует создать пакет). Дрейф перечня контролируется unit-тестом консистентности через `typing.get_args`.
- **D3. Тест консистентности требует точного равенства множеств** (`get_args(StrategyName) == set(реестр)`), а не надмножества: пропущенное имя лишает автокомплита, устаревшее — вводит в заблуждение. Равенство дисциплинирует оба случая.
- **D4. Помощники в реестре:** `strategy_names()` → отсортированный список; `validate_assignments(assignments)` → ValueError со списком неизвестных (sorted) и доступных (sorted) имён при первом же нарушении. Функция чистая, без побочных эффектов — удобно тестировать на monkeypatch-словаре `_registry` (паттерн уже есть в test_registry).
- **D5. Точка вызова — первая строка тела `run_bot()` после fallback-инициализации instruments.** Покрывает оба пути запуска (интерактивный выбор и fallback); `validate_assignments` сама гарантирует регистрацию всех пакетов через `_ensure_registered()` (D7), поэтому реестр полон к моменту проверки независимо от порядка импортов. Явные `instruments` не валидируются — они содержат тикеры, а не имена стратегий; резолв стратегий всё равно идёт по конфиг-словарю.
- **D6. Семантика отказа — жёсткий crash.** Ошибка конфигурации ≠ отказ стратегии в рантайме: изоляция отказов (spec strategy-contract) продолжает действовать для исключений compute/decide, но невалидная конфигурация должна останавливать запуск. Спеки разведены: fail-fast живёт в orchestration («Бесконечный цикл бота») и strategy-contract («Привязка…»).
- **D7. Ленивая регистрация пакетов стратегий.** Module-level импорт `MacdRsiStochStrategy` из `src/strategies/__init__.py` заменяется на `_ensure_registered()`: при первом обращении к любой функции доступа (`get_strategy`, `all_strategies`, `strategy_names`, `validate_assignments`) однократно импортируются пакеты стратегий и выставляется флаг `_packages_loaded`. Идемпотентность — по флагу, а не по пустоте `_registry`: паттерн monkeypatch пустого словаря в test_registry не должен провоцировать повторные попытки импорта (повторный import — no-op из-за sys.modules). Все потребители уже ходят через аксессоры (runner, snapshot-тесты, скрипт скачивания), на побочный эффект импорта `src.strategies` никто не полагается.

## Risks / Trade-offs

- [Ручной Literal может расходиться с реестром] → тест равенства множеств ловит оба направления дрейфа до мержа.
- [Ленивая загрузка смещает стоимость импорта pandas/pandas_ta к первому обращению к реестру] → единовременная цена при старте run_bot до цикла, незаметна на фоне сетевых запросов.
- [Тесты с очищенным monkeypatch-`_registry` не должны триггерить перезагрузку пакетов] → флаг `_packages_loaded` вместо проверки пустоты словаря (D7); тест консистентности явно регистрирует MacdRsiStochStrategy вручную.
- [Валидация в run_bot ломает существующие тесты, где assignments патчат частично] → обновить заглушки ASSIGNMENTS в test_runner (все имена должны быть зарегистрированы либо get_strategy замокан).
- [Каждая новая стратегия требует правки names.py] → осознанный компромисс против кодогенерации; шаг документирован в задачах будущих смен.

## Migration Plan

names.py → ленивая регистрация в `__init__.py` → аннотация конфига → помощники реестра → вызов в runner → обновление тестов → полный прогон. Откат тривиален (revert одного коммита).
