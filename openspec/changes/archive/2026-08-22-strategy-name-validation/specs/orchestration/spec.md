# Дельта: orchestration

## MODIFIED Requirements

### Requirement: Бесконечный цикл бота
Система ДОЛЖНА предоставлять функцию `run_bot(instruments=None)`, выполняющую бесконечный цикл. Перед запуском цикла `run_bot` ДОЛЖНА валидировать привязки `STRATEGY_ASSIGNMENTS` против реестра стратегий; при наличии неизвестных имён запуск ДОЛЖЕН завершаться ошибкой до первой итерации. Набор стратегий для каждого инструмента ДОЛЖЕН определяться `STRATEGY_ASSIGNMENTS`; инструмент без привязки пропускается с записью в лог.

#### Scenario: Запуск с инструментами
- **WHEN** `run_bot(instruments=[...])` вызывается
- **THEN** начинается бесконечный цикл обработки инструментов и их назначенных стратегий

#### Scenario: Запуск без аргументов (fallback)
- **WHEN** `run_bot()` вызывается без аргументов
- **THEN** используется конфигурация по умолчанию: `[(TICKER, TICKER, INSTRUMENT_TYPE)]` со стратегиями из `STRATEGY_ASSIGNMENTS`

#### Scenario: Fail-fast при невалидных привязках
- **WHEN** `run_bot()` вызывается, а `STRATEGY_ASSIGNMENTS` содержит незарегистрированное имя стратегии
- **THEN** выбрасывается ошибка до входа в цикл; ни один инструмент не обрабатывается, запросы данных не выполняются
