# Перечень имён стратегий и валидация привязок

## Why

Имена стратегий существуют только в рантайме (ключи реестра), поэтому при заполнении `STRATEGY_ASSIGNMENTS` в `src/config.py` IDE не подсказывает допустимые значения, а опечатка не проявляется сразу: неизвестное имя ловится изоляцией отказов в цикле, и бот «работает», бесконечно печатая ошибку каждые 9 секунд. Нужен статический перечень для автокомплита и fail-fast проверка привязок при старте.

## What Changes

- Новый лёгкий модуль `src/strategies/names.py` с типом `StrategyName = Literal["macd_rsi_stoch"]` — единственный ручной перечень имён; модуль импортирует только `typing`, чтобы `src.config` не тянул тяжёлые зависимости.
- Ленивая регистрация в реестре `src/strategies/__init__.py`: module-level импорт пакетов стратегий заменяется на `_ensure_registered()` с флагом идемпотентности. Без этого импорт подмодуля `names` исполнял бы `__init__.py` пакета (так устроен Python) и всё равно подтягивал бы pandas_ta — лёгкость модуля имён была бы фикцией.
- Аннотация `STRATEGY_ASSIGNMENTS: dict[str, list[StrategyName]]` — IDE подсказывает имена и подсвечивает опечатки.
- Помощники реестра: `strategy_names()` (отсортированные ключи) и `validate_assignments(assignments)` (ValueError со списком неизвестных и доступных имён).
- Вызов `validate_assignments(STRATEGY_ASSIGNMENTS)` первой строкой `run_bot()` до бесконечного цикла: неизвестное имя теперь мгновенный crash с понятным сообщением вместо тихих повторов.
- Unit-тесты: консистентность Literal с реестром (`get_args`), поведение `strategy_names`/`validate_assignments`, fail-fast в `run_bot`.

### Modified Capabilities
- `strategy-contract`: новое требование «Статический перечень имён стратегий» (модуль names.py, Literal, аннотация конфига, проверяемая консистентность с реестром) + требование «Реестр стратегий» дополняется ленивой идемпотентной загрузкой пакетов стратегий при первом обращении к аксессорам + требование «Привязка инструментов к стратегиям» дополняется fail-fast валидацией значений против реестра.
- `orchestration`: «Бесконечный цикл бота» — перед стартом цикла привязки валидируются; невалидная конфигурация останавливает запуск с диагностикой.

## Impact

- Код: новый `src/strategies/names.py`; правки `src/strategies/__init__.py` (ленивая регистрация `_ensure_registered()` вместо module-level импорта, новые `strategy_names`/`validate_assignments`), `src/config.py` (аннотация + импорт из names), `src/scheduler/runner.py` (одна строка валидации).
- Тесты: дополнения в `tests/unit/test_registry.py`, `tests/unit/test_runner.py`, новый тест консистентности Literal↔реестр и subprocess-тест лёгкости импорта.
- Риски минимальны: валидация выполняется до старта цикла и сама гарантирует регистрацию всех пакетов стратегий (ленивая загрузка при первом обращении к аксессору); легитимные конфигурации проходят без изменений.
