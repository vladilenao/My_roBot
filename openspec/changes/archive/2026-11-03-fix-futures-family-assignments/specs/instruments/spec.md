## ADDED Requirements

### Requirement: Привязки фьючерса по семейству контракта
Нормативный уровень: MUST. Привязки фьючерса из `[strategies.future.*]` ДОЛЖНЫ находиться по семейству контракта во всех местах выбора привязок — торговля контура, спрос ядра на таймфреймы, предпроверка прогона истории. Если в карточке инструмента нет семейства, его ДОЛЖНО определять по биржевому тикеру и короткому имени тем же правилом, что и для карточек брокера (`RIZ6`, `RTS-12.26` → `RTS`; `SRZ6`, `SBRF-12.26` → `SBRF`). Поиск ДОЛЖЕН идти сначала по ключу семейства, затем по его коду. Только если семейство не определяется, допустим поиск по двум первым буквам тикера.

#### Scenario: Контракт RTS без семейства в карточке
- **GIVEN** в конфигурации привязки `[strategies.future.RTS]`, в составе эмуляции RIZ6 с коротким именем `RTS-12.26` и `family = null`
- **WHEN** контур выбирает привязки инструмента
- **THEN** выбраны привязки `RTS`, а ядро запрашивает их таймфреймы

#### Scenario: Семейство SBRF записано кодом
- **GIVEN** в конфигурации привязки записаны под `[strategies.future.SR]`, инструмент SRZ6 без семейства
- **WHEN** контур выбирает привязки
- **THEN** выбраны привязки `SR`

#### Scenario: Семейство из карточки
- **GIVEN** в карточке NGZ6 `family = "NG"`
- **WHEN** контур выбирает привязки
- **THEN** выбраны привязки `NG`, как до исправления
