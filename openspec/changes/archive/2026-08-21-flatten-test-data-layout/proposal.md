# Плоская структура тестовых данных и правило наименования эталонов

## Why

Папка кейса сейчас кодирует тройку (стратегия, инструмент, таймфрейм): при появлении второй стратегии на том же инструменте/таймфрейме фикстуру свечей придётся дублировать целиком. Кроме того, имя файла эталона (`expected_signals.csv`) не содержит стратегию, из-за чего правило связи «тест ↔ данные» нигде не зафиксировано явно.

## What Changes

- **BREAKING** (только для тестовой инфраструктуры): структура `tests/data/<strategy>/<case>/` заменяется на плоскую `tests/data/<case>/`, где кейс = `<ИНСТРУМЕНТ>_<ТАЙМФРЕЙМ>`; уровень стратегии убран.
- Эталон переименован: вместо безымянного `expected_signals.csv` — `<стратегия>_expected_signals.csv` рядом с общим `candles.csv`; несколько стратегий могут делить одни свечи кейса.
- Зафиксировано правило наименования: стратегия = `tests/strategies/test_<имя>.py`; кейс = папка `tests/data/<ИНСТРУМЕНТ>_<ТАЙМФРЕЙМ>/` с ровно одним `candles.csv`; эталон = `<имя_стратегии>_expected_signals.csv` (точное совпадение имени, без префиксов).
- Тест стратегии ищет кейсы по точному имени файла эталона во всех папках кейсов (`tests/data/*/<strategy>_expected_signals.csv`) вместо скана подпапок своей стратегии.
- Скрипт скачивания пишет кейс в `tests/data/<case>/`, а эталон называет по параметру стратегии.
- Существующий кейс `NG_1h` мигрирует на новую структуру.
- Правило наименования добавлено в контекст проекта (`openspec/config.yaml`) для единообразия будущих артефактов.

## Capabilities

### New Capabilities

_(нет)_

### Modified Capabilities

- `snapshot-testing`: изменяются требования «Динамическая параметризация по папкам кейсам» (скан по файлам эталонов во всех кейсах) и «Эталонный файл сигналов» (путь и имя `<стратегия>_expected_signals.csv`).
- `test-data`: изменяются требования «Структура хранения фикстур» (плоская структура, кейс = пара инструмент/таймфрейм), «Скрипт скачивания тестовых данных» (путь вывода и имя эталона по стратегии); уточняется правило глубины при нескольких стратегиях на одном кейсе.

## Impact

- **Затронуто**: `tools/download_snapshot_data.py` (пути и имя эталона), `tests/strategies/test_macd_rsi_stoch.py` (скан кейсов и загрузка), перенос `tests/data/macd_rsi_stoch/NG_1h/` → `tests/data/NG_1h/`, главные спеки обеих capabilities при архивации дельт.
- **Не затронуто**: рабочий код `src/**`, `run.py`, логика расчёта сигналов, формат CSV-файлов (столбцы прежние).
- **Совместимость**: старая структура исчезает; миграция одноразовая, кейс один.
