# Тестовые данные: скачивание и хранение

## MODIFIED Requirements

### Requirement: Скрипт скачивания тестовых данных
Система ДОЛЖНА предоставлять отдельный скрипт (вне pytest-прогона) для однократного скачивания свечей и записи их в файл фикстур. Скрипт ДОЛЖЕН принимать параметры: тикер, тип инструмента, таймфрейм и целевую стратегию/кейс. Свечи ДОЛЖНЫ записываться в `tests/data/<case>/candles.csv`, а эталон — в `tests/data/<case>/<strategy_name>_expected_signals.csv`.

#### Scenario: Скачивание фикстуры Природный газ 1h
- **WHEN** скрипт запущен для тикера NG (тип future), таймфрейм 1h, стратегия `macd_rsi_stoch`, кейс `NG_1h`
- **THEN** свечи записываются в `tests/data/NG_1h/candles.csv`, а эталон — в `tests/data/NG_1h/macd_rsi_stoch_expected_signals.csv`

### Requirement: Структура хранения фикстур
Фикстуры ДОЛЖНЫ храниться по плоской структуре: кейс — папка `tests/data/<ИНСТРУМЕНТ>_<ТАЙМФРЕЙМ>/` (например `NG_1h`) с ровно одним файлом входа `candles.csv`; эталоны стратегий лежат рядом с ним под именами `<strategy_name>_expected_signals.csv`. Уровень стратегии в путях НЕ ДОПУСКАЕТСЯ. Структура ДОЛЖНА поддерживать произвольное число стратегий на общих свечах и произвольное число кейсов без правки кода тестов. Глубина истории `candles.csv` выбирается при скачивании так, чтобы удовлетворить все стратегии кейса; если новой стратегии нужно больше истории, кейс скачивается заново, а эталоны регенерируются штатным механизмом.

#### Scenario: Добавление нового кейса
- **WHEN** создана новая папка `tests/data/BTC_15m/` с корректными файлами
- **THEN** кейс подхватывается тестами автоматически при следующем прогоне

#### Scenario: Общие свечи для нескольких стратегий
- **WHEN** вторая стратегия добавляет в существующий кейс свой файл `<другая_стратегия>_expected_signals.csv`
- **THEN** обе стратегии тестируются на одном `candles.csv` без дублирования фикстуры свечей

#### Scenario: Запрет уровня стратегии
- **WHEN** в `tests/data/` появляется подпапка, названная именем стратегии, без файла `candles.csv`
- **THEN** такая структура считается нарушением правила наименования; тесты её не обнаруживают как кейс
