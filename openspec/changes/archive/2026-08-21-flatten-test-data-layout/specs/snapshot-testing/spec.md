# Snapshot-тестирование торговых сигналов

## MODIFIED Requirements

### Requirement: Динамическая параметризация по папкам кейсов
Каждый файл теста в `tests/strategies/` соответствует одной стратегии и ДОЛЖЕН автоматически обнаруживать свои кейсы во всех папках `tests/data/*/<ИНСТРУМЕНТ>_<ТАЙМФРЕЙМ>/` по точному имени файла эталона `<strategy_name>_expected_signals.csv`. Имя папки кейса — имя кейса. Добавление инструмента или кейса НЕ ДОЛЖНО требовать правки кода тестов. Поиск ДОЛЖЕН выполняться по точному имени файла (без wildcard-суффикса), чтобы стратегия не подхватывала эталоны других стратегий.

#### Scenario: Новый кейс подхватывается автоматически
- **WHEN** в `tests/data/` добавлена папка `BTC_15m/` с `candles.csv` и `macd_rsi_stoch_expected_signals.csv`
- **THEN** при следующем прогоне pytest стратегия `macd_rsi_stoch` выполняет тест-кейс `BTC_15m`

#### Scenario: Пустая папка данных
- **WHEN** в `tests/data/` нет ни одного файла `macd_rsi_stoch_expected_signals.csv`
- **THEN** параметризация даёт ноль кейсов; прогон стратегии завершается без ошибок

#### Scenario: Изоляция стратегий друг от друга
- **WHEN** в кейсе лежат эталоны нескольких стратегий (`macd_rsi_stoch_expected_signals.csv`, `rsi_divergence_expected_signals.csv`)
- **THEN** каждая стратегия сравнивает только свой файл; чужие эталоны игнорируются

### Requirement: Эталонный файл сигналов
Эталон ДОЛЖЕН храниться рядом с фикстурой свечей и называться `<strategy_name>_expected_signals.csv` (имя файла кодирует стратегию; префиксы вроде `test_` НЕ ДОЛЖНЫ использоваться). Обязательные столбцы: `datetime` (ISO без часового пояса), `signal` (`BUY`|`SELL`), `price` (float). В эталон включаются ТОЛЬКО свечи с консенсусным решением — все три суммы строго одного знака; HOLD-свечи не записываются. Несколько эталонов разных стратегий МОГУТ делить один `candles.csv` кейса.

#### Scenario: Консенсусная покупка
- **WHEN** `macd_sum > 0` И `rsi_sum > 0` И `stoch_sum > 0` на свече t
- **THEN** строка t присутствует в эталоне с `signal=BUY` и `price=close(t)`

#### Scenario: Консенсусная продажа
- **WHEN** все три суммы строго отрицательные на свече t
- **THEN** строка t присутствует в эталоне с `signal=SELL` и `price=close(t)`

#### Scenario: Отсутствие консенсуса
- **WHEN** суммы имеют разные знаки или нули
- **THEN** строка отсутствует в эталоне
