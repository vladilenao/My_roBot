# Дельта: orchestration

## MODIFIED Requirements

### Requirement: Формат уведомления
Сообщение ДОЛЖНО формироваться форматтером, внедрённым в нотификатора (`DecisionFormatter`), из решения стратегии: префикс `[instrument_label]` и текст решения. Раннер НЕ ДОЛЖЕН сам формировать тексты и использовать модульные функции `format_decision`/`send_signal`. Диагностическая строка с сырыми суммами сигналов из общего движка УДАЛЯЕТСЯ — суммы специфичны для стратегий.

#### Scenario: Формат сообщения
- **WHEN** итерация завершается успешно с решением BUY
- **THEN** доставленное сообщение содержит `[instrument_label] 🚀 ПОКУПАТЬ! Цена: X`

### Requirement: Конвейер обработки на каждой итерации
На каждой итерации для каждого инструмента: загрузить свечи (один запрос на тикер) → для каждой назначенной стратегии из реестра: рассчитать сигналы (`compute`) → принять решение (`decide`) → передать решение нотификатору (`notify_decision`). Нотификатор ДОЛЖЕН создаваться один раз до входа в цикл через фабрику по конфигурации.

#### Scenario: Нормальная итерация
- **WHEN** данные доступны
- **THEN** полный конвейер выполняется для каждой пары «инструмент × назначенная стратегия»; решение доставляется одним вызовом нотификатора

#### Scenario: Единственный экземпляр нотификатора
- **WHEN** `run_bot` запускается
- **THEN** нотификатор создаётся один раз до цикла и переиспользуется для всех инструментов и стратегий
