# Дельта: configuration

## ADDED Requirements

### Requirement: Выбор канала уведомлений
Система ДОЛЖНА предоставлять строковую константу `NOTIFIER`, выбирающую единственный активный канал уведомлений; допустимые значения — `"telegram"` и `"console"`, значение по умолчанию — `"telegram"`. Константа ДОЛЖНА быть импортируемой через `from src.config import NOTIFIER`. Активным может быть только один канал — список каналов в конфигурации НЕ ДОЛЖЕН поддерживаться.

#### Scenario: Чтение константы
- **WHEN** модуль читает `NOTIFIER`
- **THEN** возвращается одно строковое значение допустимого канала

#### Scenario: Импорт константы
- **WHEN** выполняется `from src.config import NOTIFIER`
- **THEN** значение успешно импортируется
