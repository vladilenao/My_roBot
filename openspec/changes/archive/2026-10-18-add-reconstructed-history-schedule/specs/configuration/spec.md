## ADDED Requirements

### Requirement: Настройка расписания исторического прогона
Нормативный уровень: MUST.
Система ДОЛЖНА читать необязательную секцию `[historical.schedule]` файла `robot.toml` (или вшитого `default.toml`):

| Ключ | Тип | По умолчанию |
|---|---|---|
| `use_reconstructed` | логическое | `true` |

Без секции или без ключа ДОЛЖНО применяться значение по умолчанию. Незнакомый ключ или значение не того типа ДОЛЖНЫ завершать загрузку `ConfigError` с указанием файла и ключа. Вшитый `default.toml` ДОЛЖЕН содержать секцию со значением по умолчанию и комментарием. Значение ДОЛЖНО записываться в отчёт исторического прогона.

#### Scenario: Значение по умолчанию
- **WHEN** секции `[historical.schedule]` нет
- **THEN** исторический прогон применяет восстановленное расписание для сессионной защиты

#### Scenario: Неверный тип
- **WHEN** задано `use_reconstructed = "yes"`
- **THEN** загрузка завершается `ConfigError` с файлом и ключом `historical.schedule.use_reconstructed`
