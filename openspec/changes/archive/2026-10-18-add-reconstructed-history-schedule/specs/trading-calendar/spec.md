## ADDED Requirements

### Requirement: Происхождение дня расписания
Нормативный уровень: MUST.
Каждая версия дня расписания и каждая привязка инструмента к режиму торгов ДОЛЖНЫ нести происхождение: `broker` — день наблюдён у брокера (в том числе через ленту робота в эмуляторе), `reconstructed` — день восстановлен историческим источником по правилам сессий. У восстановленного дня ДОЛЖНА храниться версия правил. День исторического источника без поля происхождения ДОЛЖЕН считаться `broker`. Восстановленный день без версии правил и день с неизвестным происхождением ДОЛЖНЫ отвергаться с диагностикой источника. Версия дня ДОЛЖНА по-прежнему вычисляться из исходного содержания дня и сверяться с заявленной.

Восстановленные дни ДОЛЖНЫ приниматься только от исторического источника и НЕ ДОЛЖНЫ записываться в постоянное хранилище рыночных данных робота.

По умолчанию календарь ДОЛЖЕН отдавать потребителям только дни `broker`. Восстановленный день ДОЛЖЕН быть доступен только по явному запросу потребителя и только для даты без дня `broker`. Ожидание свечей, сверка покрытия, доказательство планового отсутствия свечи, проверка правых границ и представление графиков НЕ ДОЛЖНЫ использовать восстановленные дни. Восстановленная привязка МОЖЕТ использоваться для выбора режима торгов в любом виде календаря.

#### Scenario: Старый эмулятор без поля происхождения
- **WHEN** исторический источник вернул дни без `provenance`
- **THEN** дни принимаются как `broker`, поведение календаря не меняется

#### Scenario: Восстановленный день не доказывает отсутствие свечи
- **WHEN** для 2025-05-01 есть только восстановленный неторговый день, а минутных свечей за дату нет
- **THEN** сверка покрытия не ставит `scheduled_closed`, минуты остаются с прежним статусом неизвестной фазы

#### Scenario: Брокерский день главнее
- **WHEN** для даты есть день `broker` и восстановленный день
- **THEN** любой вид календаря отдаёт день `broker`

#### Scenario: Неизвестное происхождение
- **WHEN** исторический источник вернул день с `provenance = "guess"`
- **THEN** страница расписания не применяется, причина недоступности источника видна в отчёте прогона
