## ADDED Requirements

### Requirement: Открытие актуальной рыночной базы без записи
Нормативный уровень: MUST. Ядро и контуры открывают рыночную базу одновременно, пока другой процесс в неё пишет. Открытие базы, у которой схема актуальна, служебные значения заданы и нет удержаний UID прежней версии, НЕ ДОЛЖНО брать блокировку записи и НЕ ДОЛЖНО ждать пишущий процесс. Снятие удержаний прежней версии ДОЛЖНО брать блокировку записи только при найденных удержаниях. Версия схемы ДОЛЖНА записываться только при отличии, служебное значение по умолчанию — только при отсутствии.

#### Scenario: Контур стартует, пока ядро пишет
- **WHEN** другой процесс держит блокировку записи рыночной базы, а схема базы актуальна и удержаний нет
- **THEN** процесс открывает базу без ожидания и без ошибки `database is locked`, служебные значения не меняются

#### Scenario: Устаревшая версия схемы
- **WHEN** в базе записана прежняя версия схемы или нет служебного значения
- **THEN** при открытии версия схемы обновляется, недостающее значение записывается

#### Scenario: Удержание прежней версии при открытии
- **WHEN** в базе есть удержание UID, сохранённое прежней версией робота
- **THEN** при открытии удержание снимается под блокировкой записи, инцидент сохраняется
