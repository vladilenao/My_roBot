## ADDED Requirements

### Requirement: Снятие инструмента из состава контура
Нормативный уровень: MUST. Менеджер сделок ДОЛЖЕН поддерживать остановку одного инструмента в двух режимах. Эти правила совпадают с остановкой контура, но применяются только к сделкам этого инструмента.

- **«Без входов».** Менеджер ДОЛЖЕН:
  - отклонять новые входы и доборы по инструменту с причиной `instrument-removing`; сигнал при этом публикуется как отклонённый;
  - снимать его неисполненные входы действием `CancelEntry` с причиной `instrument-remove`;
  - сопровождать его открытые позиции по плану.
- **«Закрыть всё».** Дополнительно менеджер ДОЛЖЕН закрывать открытые позиции инструмента действием `CloseTrade` с причиной `instrument-remove`.

Сделки других инструментов НЕ ДОЛЖНЫ затрагиваться. Если по сделке уже есть заявка снятия или закрытия, второе действие НЕ ДОЛЖНО создаваться. Снятие остановки инструмента ДОЛЖНО возвращать допуск входов. Менеджер ДОЛЖЕН сообщать число открытых позиций и неисполненных входов отдельно по инструменту.

#### Scenario: Сигнал по убираемому инструменту
- **GIVEN** SBER убирается в режиме «без входов», NG торгует
- **WHEN** стратегии дают сигналы на вход по SBER и по NG
- **THEN** вход по SBER отклонён с причиной `instrument-removing`, вход по NG допускается как обычно

#### Scenario: Закрыть позиции одного инструмента
- **GIVEN** открыты позиции NG и SBER
- **WHEN** SBER убирается в режиме «закрыть всё»
- **THEN** закрытие создаётся только для SBER, позиция NG сопровождается

#### Scenario: Возврат инструмента
- **GIVEN** SBER убирается в режиме «без входов»
- **WHEN** остановка SBER снята
- **THEN** новые входы по SBER снова допускаются
