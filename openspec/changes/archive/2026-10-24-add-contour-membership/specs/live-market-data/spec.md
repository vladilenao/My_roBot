## ADDED Requirements

### Requirement: Снятие пар без спроса контуров
Нормативный уровень: MUST. Ядро ДОЛЖНО снимать с обслуживания живую пару, которую оно зарегистрировало по спросу контуров, если выполнены оба условия:

- пары нет в объединённом спросе ни одного контура;
- инструмент пары не держится объединёнными обязательствами незавершённых сделок ни по ключу инструмента, ни по UID пары.

Снятие ДОЛЖНО выполняться не раньше чем через `[contours] demand_release_secs` после того, как спрос пропал. По умолчанию это 900 секунд. Если спрос вернулся раньше, пара ДОЛЖНА остаться.

При снятии пара ДОЛЖНА уйти из живых пар кэша ядра и из сохранённого состава, чтобы не вернуться после рестарта. Её пары паттернов ДОЛЖНЫ перестать ставиться в очередь. Свечи и покрытие в рыночной базе ДОЛЖНЫ сохраниться. Снятие ДОЛЖНО записываться в журнал ядра с именем инструмента и таймфреймом.

#### Scenario: Убранный инструмент без сделок
- **GIVEN** контур удалил строки спроса BR-11.26, сделок по нему нет
- **WHEN** проходит 900 секунд
- **THEN** ядро снимает пары BR-11.26 1m и 5m, в журнале строка о снятии, свечи в базе остаются

#### Scenario: Спрос вернулся до срока
- **GIVEN** строки спроса NG-12.26 пропали при запуске контура
- **WHEN** через минуту стартовый обзор снова записал спрос NG-12.26
- **THEN** пары NG-12.26 не снимаются и не прогреваются заново

#### Scenario: Пару держит сделка
- **GIVEN** спроса на SBER нет, но по SBER открыта позиция и есть обязательство
- **WHEN** проходит выдержка
- **THEN** пары SBER остаются у ядра
