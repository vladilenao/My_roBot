## Why

После П7 все торговые контуры живут в одной оболочке `/api/v1/contours`:
эмуляция и прогоны истории — один список с `oneOf` по `kind`. У них разный
жизненный цикл, поэтому общий объект получился широким и полным `null`, а
коды ответов различаются по виду контура внутри одного маршрута:

- `POST /api/v1/contours` запускает эмуляцию (201/202/409) или ставит
  прогон в очередь (всегда 202);
- `POST …/stop` требует `mode` у эмуляции и не требует у истории;
- `POST …/instruments` с `add` или `remove` — по сути вызов процедуры;
- наружу выходят внутренние слова: `desired`, `actual`, `generation`.

Скоро появится третий контур — боевая торговля (документ 2). В общий `oneOf`
его пришлось бы втискивать так же.

Проект нового контракта обсуждён с владельцем 24.10:
`docs/api/openapi-draft.yaml` и `docs/api/README.md`. Маршруты
`/api/v1/contours` ещё не выходили в релизе, на них никто не опирается.

Решения владельца (24.10):

- **Свой ресурс у каждого контура.** Эмуляция — `/api/v1/emulation`, одна
  на робота. История — `/api/v1/history`, коллекция прогонов. Боевая
  торговля потом встанет рядом на тех же общих схемах.
- **Прежние `/api/v1/contours…` удаляются** сразу, без периода `deprecated`.
- **Слова оператора.** Целевое состояние — `target`, текущее — `current`,
  номер — `revision`. Режим торговли — одно поле `mode`: `on`,
  `no_entries`, `close_all`.
- **Одно имя инструмента в эмуляции.** Контракт — короткое имя
  (`NG-12.26`), акция — тикер (`SBER`) в запуске, добавлении, составе и
  удалении. Код семейства (`NG`) эмуляция не принимает; удобство
  «без списка — всё с привязками» остаётся. В истории код семейства
  остаётся: там это автоматическая цепочка контрактов.
- **Удаление пачкой в теле**, а не по одному в адресе.
- **Рыночные данные и отчёт кластеров не меняются** (вариант А): экспорт
  уже в релизе, его читает Historical Broker API Emulator.
- **Ответы — JSON со ссылками и доступными действиями** (`_links`,
  `_actions`), ошибки — `problem+json` с прежними кодами.
- **Контракты — в `docs/api/`**, перенос — в этом же изменении.
- **Справочник инструментов** `/api/v1/instruments` — отдельным следующим
  изменением.

## What Changes

- **Эмуляция** — `/api/v1/emulation`:
  - `GET /api/v1/emulation` — одно состояние: `state`, `target`, `current`,
    `launch`, `process`, `instruments` (состав), `_links`, `_actions`;
    заголовок `ETag` — ревизия;
  - `PUT /api/v1/emulation/target` — режим торговли:
    `{"mode": "on", "instruments": [...]}` запускает,
    `{"mode": "no_entries"}` и `{"mode": "close_all"}` останавливают;
    `GET` — текущее целевое состояние;
  - `POST /api/v1/emulation/instruments` `{"instruments": [...]}` —
    добавить пачкой;
  - `POST /api/v1/emulation/instruments/remove`
    `{"instruments": [...], "mode": ...}` — убрать пачкой;
  - `GET /api/v1/emulation/instruments` и `…/instruments/{name}` — состав
    и один участник;
  - `GET /api/v1/emulation/log` — журнал.
- **История** — `/api/v1/history`:
  - `GET` — идущие, ждущие и последние завершённые, `?state=`, `?limit=`;
  - `POST` — поставить прогон в очередь;
  - `GET /{id}`, `POST /{id}/stop`, `GET /{id}/report` (итог отдельно от
    хода), `GET /{id}/log`;
  - `id` прогона — имя его папки, `20261024-101500`, без префикса
    `history-`.
- **Точка входа** `GET /api/v1` — сводка робота и ссылки на разделы по
  правам ключа; принимает оба ключа.
- **Защита от одновременных команд** — `If-Match` с ревизией, при
  несовпадении `412 REVISION_CHANGED`.
- **Ошибки управления** — `application/problem+json`: `type`, `title`,
  `status`, `code`, `detail`. Экспорт и кластеры — прежний
  `{code, message}`.
- **Имена инструментов в эмуляции** — только тикер акции и короткое имя
  контракта; код семейства и биржевой тикер — `422` с подсказкой
  короткого имени.
- **Консоль.** «Робот ждёт команду запуска: PUT …/api/v1/emulation/target»,
  «Повторить запуск: PUT /api/v1/emulation/target {…}», подсказка при
  прежних параметрах называет `PUT /api/v1/emulation/target` и
  `POST /api/v1/history`.
- **Контракты в `docs/api/`:**
  - `docs/openapi.yaml` → `docs/api/openapi.yaml` версии `2.0.0` — из
    проекта, без маршрутов, которых сервер не выполняет (`/api/v1/live`,
    справочник);
  - `docs/market-events.asyncapi.yaml` → `docs/api/`;
  - `docs/api/README.md` — обзор контрактов, решения — `v2-decisions.md`.
- **Удаляется:** `/api/v1/contours` со всеми вложенными маршрутами.

Вне изменения:

- справочник `/api/v1/instruments` — следующее изменение;
- контур «Счёт» `/api/v1/live` — документ 2;
- непрозрачный курсор рыночных данных — отдельно, вместе с эмулятором;
- внутренние имена `core.sqlite3` и `status.json` (`desired`, `actual`,
  `generation`) не меняются;
- устаревший текст требования «Включение локального API» в
  `cluster-report` о запуске без ключей — здесь меняются только пути.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `control-api`:
  - ресурсы `/api/v1/emulation` и `/api/v1/history` вместо
    `/api/v1/contours`;
  - `target`, `current`, `revision`, `mode` в ответах и командах;
  - состав пачкой: добавить и убрать;
  - точка входа, ссылки и действия, `ETag`/`If-Match`, `problem+json`;
  - `id` прогона без префикса, итог прогона отдельным ресурсом.
- `instruments` — в эмуляции только тикер акции и короткое имя контракта.
- `orchestration`, `historical-mode` — маршруты в требованиях и сценариях.
- `market-data-export`, `cluster-report`, `market-structure-patterns` —
  расположение контрактов в `docs/api/`, имена тегов.

## Impact

- **Код:**
  - `src/data/export_api.py` — маршруты, путь контракта,
    `problem+json`, `ETag`;
  - `src/bot/launch_control.py` — разбор команд эмуляции и истории,
    состав пачкой, ссылки и действия, представления ответов;
  - `src/bot/launch.py` — разбор имён для эмуляции (`classify_tokens`),
    эквивалентная команда и подсказки консоли;
  - `src/assembly/history_runs.py` — `id` по имени папки, итог отдельно;
  - `run.py`, `run.spec` — строки консоли, путь контракта в дистрибутиве.
- **Документы:** `docs/api/*`, ссылки в `docs/market-data/*`,
  `docs/trade-management/signal-pipeline.md`, `docs/market-events.md`,
  `docs/database.md`, `default.toml`, `README.txt`, `CHANGELOG.md`,
  `docs/architecture/core-contours.md`.
- **Данные:** без миграций. Строки `history_runs` прежней версии
  показываются по имени папки.
- **Поведение для владельца:** сохранённые запросы Yaak на
  `/api/v1/contours` перестают работать — их нужно перевести на новые
  маршруты.
