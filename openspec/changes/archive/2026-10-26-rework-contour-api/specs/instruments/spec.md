## MODIFIED Requirements

### Requirement: Инструменты из параметров запуска
Нормативный уровень: MUST. Инструменты ДОЛЖНЫ задаваться списком имён без учёта регистра в поле `instruments` команды API: запуска эмуляции (`PUT /api/v1/emulation/target` с `mode = on`), добавления в её состав (`POST /api/v1/emulation/instruments`) и прогона истории (`POST /api/v1/history`). Без поля в запуске эмуляции и в прогоне истории ДОЛЖНО применяться значение `all`; добавление в состав требует список. Командная строка и меню инструменты больше не задают.

**Эмуляция** — одно имя инструмента во всех командах, то же, что `name` участника в составе:

- тикер акции — эта акция;
- короткое имя контракта (`NG-12.26`) — этот контракт;
- `all` или поле не задано (только в запуске) — все акции из секций `[strategies.share.*]` и по одному контракту каждого семейства из `[strategies.future.*]` по правилу ближайшего контракта.

Код семейства или его биржевой префикс (`NG`, `RTS` или `RI`, `SBRF` или `SR`) и биржевой тикер контракта (`NGZ6`) ДОЛЖНЫ в эмуляции отклоняться. Причина ДОЛЖНА называть короткое имя: для кода семейства — ближайшего допустимого контракта, для биржевого тикера — этого контракта.

**История:**

- `all` — все акции и все семейства фьючерсов конфигурации, семейства — автоматической цепочкой;
- тикер акции — эта акция;
- код семейства или его биржевой префикс — автоматическая цепочка контрактов семейства;
- контракт коротким именем или биржевым тикером — фиксированный контракт.

Ближайший контракт — ближайший по экспирации стандартный контракт из списка активных фьючерсов, до экспирации которого больше `contract_expiry_block_days` суток. Выбор ДОЛЖЕН печататься коротким именем с числом суток до экспирации.

Имя, у которого нет привязок в конфигурации, ДОЛЖНО отклоняться. Семейство и его же контракт в одной команде истории ДОЛЖНЫ отклоняться как конфликт. Любое отклонённое имя ДОЛЖНО давать ответ `422` со списком отказов без запуска торговли.

**Проверка у источника.**

- В эмуляции каждый разрешённый инструмент ДОЛЖЕН проверяться у брокера до ответа.
- В истории до ответа проверяются только привязки и конфликт. Отказ эмулятора данных по разрешённому имени ДОЛЖЕН завершать прогон в состоянии `failed` с отказами, без торговли прогона.

Выбранный инструмент ДОЛЖЕН, как и прежде, включать все свои привязки конфигурации. Инструмент, названный и в эмуляции, и в истории, ДОЛЖЕН в обоих торговаться по одним и тем же привязкам.

#### Scenario: Все инструменты из привязок
- **GIVEN** в конфигурации есть привязки для акции SBER и семейств NG и BR
- **WHEN** приходит `PUT /api/v1/emulation/target` с `{"mode": "on"}` без `instruments`
- **THEN** торгуются SBER, один контракт NG и один контракт BR, выбранные по правилу ближайшего контракта

#### Scenario: Ближайший контракт пропускается из-за экспирации
- **GIVEN** `contract_expiry_block_days = 2`, у NG до экспирации ближайшего контракта NG-11.26 осталось одни сутки, у следующего NG-12.26 — 31 сутки
- **WHEN** приходит запуск эмуляции без `instruments`
- **THEN** выбирается NG-12.26, и в консоли печатается `NG → NG-12.26, до экспирации 31 сутки`

#### Scenario: Код семейства в эмуляции
- **GIVEN** ближайший допустимый контракт NG — NG-12.26
- **WHEN** приходит запуск эмуляции или добавление в состав с `["NG"]`
- **THEN** ответ `422`, причина — «Код семейства не принимается — укажите контракт; ближайший допустимый — NG-12.26», состав и целевое состояние не меняются

#### Scenario: Биржевой тикер в эмуляции
- **WHEN** приходит запуск эмуляции с `["NGZ6"]`
- **THEN** ответ `422`, причина называет короткое имя NG-12.26

#### Scenario: Семейство в истории
- **WHEN** приходит `POST /api/v1/history` с `"instruments": ["NG"]`
- **THEN** NG торгуется автоматической цепочкой контрактов

#### Scenario: Явный контракт
- **WHEN** приходит запуск эмуляции с `["NG-03.27"]`
- **THEN** торгуется контракт NG-03.27, правило ближайшего контракта не применяется

#### Scenario: Инструмент без привязок
- **GIVEN** у акции AFLT нет секции `[strategies.share.AFLT]`
- **WHEN** приходит запуск эмуляции с `["SBER", "AFLT"]`
- **THEN** ответ `422` называет AFLT и причину, торговля не начинается

#### Scenario: Конфликт семейства и контракта
- **WHEN** приходит `POST /api/v1/history` с `"instruments": ["NG", "NG-12.26"]`
- **THEN** ответ `422` называет конфликт семейства и фиксированного контракта, прогон не ставится в очередь

#### Scenario: Неизвестный инструмент в меню
- **WHEN** в запуске эмуляции названы SBER и опечатка `SBEER`
- **THEN** ответ `422` называет `SBEER`, торговля не начинается ни по SBER, ни по `SBEER`; меню выбора, где опечатка пропускалась, больше нет
