## ADDED Requirements

### Requirement: Пакет состояний покрытия без изменений не пишет в базу
Нормативный уровень: MUST. После перезапуска сверка заново проходит промежутки всего ряда пары, состояния которых уже записаны прошлым запуском. Сверка ряда ДОЛЖНА передавать состояния всех новых промежутков пары одним пакетом. Пакет состояний ДОЛЖЕН читать текущие состояния своих минут без блокировки записи. Если ни одна строка пакета не меняется и префикс покрытия не продвигается, пакет НЕ ДОЛЖЕН брать блокировку записи и НЕ ДОЛЖЕН добавлять записи в ленту изменений. Иначе пакет ДОЛЖЕН записать изменённые строки и пересчитать префикс в одной транзакции. Правила записи не меняются: `received` не понижается, итог по данным источника не возвращается в ожидание, совпадающие состояние и основание не пишутся повторно.

#### Scenario: Повторная сверка после перезапуска
- **WHEN** ядро перезапущено и сверка проходит ряд пары, все состояния промежутков которого уже записаны, а другой процесс держит блокировку записи
- **THEN** сверка завершается без ожидания блокировки, состояния и лента изменений не меняются

#### Scenario: В пакете есть новое состояние
- **WHEN** пакет содержит минуту без записанного состояния и минуты, уже записанные с тем же состоянием
- **THEN** в одной транзакции пишется только новая минута, в ленте изменений появляется одна запись, префикс покрытия пересчитывается

#### Scenario: Пакет не понижает итог
- **WHEN** пакет помечает ожиданием минуту, у которой записано `received` или итог по данным источника
- **THEN** состояние минуты не меняется и в ленту изменений не попадает
