## ADDED Requirements

### Requirement: Окно глубины расчёта совпадает с полным рядом
Нормативный уровень: MUST. Для каждого кейса стратегий с фикстурой длиннее `analysis_depth + 50` свечей тест ДОЛЖЕН проверять каждый бар после `analysis_depth + 50`: решение стратегии на последних `analysis_depth` свечах до этого бара равно решению по всему префиксу фикстуры до него. Эталоны событий при этом НЕ ДОЛЖНЫ меняться.

#### Scenario: Сошедшееся окно
- **GIVEN** кейс `NG_1h` (500 свечей) и `analysis_depth = 150`
- **WHEN** тест сверяет решения macd_rsi_stoch на барах 200–499
- **THEN** решения на окне 150 и по всему префиксу совпадают на каждом баре

#### Scenario: Глубина уменьшена
- **WHEN** разработчик ставит в тесте глубину 50
- **THEN** тест падает на первом расходящемся баре и называет кейс, стратегию и бар
