## MODIFIED Requirements

### Requirement: Контракт Strategy
Каждая стратегия ДОЛЖНА реализовать контракт: атрибуты `NAME` (уникальный идентификатор — ключ реестра и имя файла эталона) и `STRATEGY_WINDOW` (собственное окно агрегации); методы `compute(df)` — боевой расчёт сигнальных колонок поверх DataFrame свечей, `decide(ta)` — решение на последней свече, возвращающее `Decision` (`SignalType`, цена), `expected_events(ta)` — события BUY/SELL за всю историю для эталона snapshot-тестов, `required_history()` — минимальная глубина истории (окно + прогрев индикаторов стратегии). Стратегия ДОЛЖНА принимать `StrategyConfig` через конструктор. Потребители ДОЛЖНЫ работать со стратегиями только через этот контракт.

#### Scenario: Единый интерфейс для любой стратегии
- **WHEN** движок обрабатывает очередную стратегию из реестра
- **THEN** используются только методы контракта без проверок типа конкретной стратегии

#### Scenario: Окно принадлежит стратегии
- **WHEN** у стратегии задан `STRATEGY_WINDOW` через `StrategyConfig`
- **THEN** агрегация и `required_history()` рассчитываются от этого значения

#### Scenario: Стратегия принимает StrategyConfig
- **WHEN** создаётся `MacdRsiStochStrategy(config)`
- **THEN** параметры индикаторов и окно берутся из `config`, а не из хардкода

### Requirement: Изолированный пакет стратегии
Каждая стратегия ДОЛЖНА располагаться в собственном файле `src/strategies/<имя>.py`. Стратегия ДОЛЖНА владеть своей математикой, правилом событий и окном; глобальные параметры расчёта стратегий в `src.config` НЕ ДОЛЖНЫ существовать. Добавление новой стратегии НЕ ДОЛЖНО требовать правки движка, unit-тестов других стратегий, snapshot-раннера или скрипта скачивания.

#### Scenario: Добавление новой стратегии
- **WHEN** создан новый файл стратегии с регистрацией в реестре и привязка добавлена в соответствующий словарь (`SHARE_STRATEGIES` или `FUTURE_STRATEGIES`)
- **THEN** стратегия работает в боте, покрывается единым snapshot-раннером и доступна скрипту скачивания без правки их кода

## REMOVED Requirements

### Requirement: Изолированный пакет стратегии (подпапки)
**Reason**: Структура `src/strategies/<имя>/` с подпапками `indicators/` и `signals/` заменяется одиночным файлом `src/strategies/<имя>.py`. Общие модули `indicators/` и `signals.py` вынесены на верхний уровень.
**Migration**: Вместо подпапок используйте один файл `<имя>.py` + общие модули `src/strategies/indicators/` и `src/strategies/signals.py`.
