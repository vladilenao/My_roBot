## MODIFIED Requirements

### Requirement: Привязка инструментов к стратегиям
Конфигурация ДОЛЖНА предоставлять два словаря привязок «многие ко многим»:
- `SHARE_STRATEGIES` — точный тикер нефьючерсного инструмента → список привязок;
- `FUTURE_STRATEGIES` — двухбуквенный код базового актива в верхнем регистре → список привязок; запись действует на любой контракт этого актива.

Привязка ДОЛЖНА содержать имя стратегии и профиль фильтрации (по умолчанию `"basic_levels"`). Включение или выключение стратегии на инструменте ДОЛЖНО выполняться правкой конфигурации без изменения кода стратегий. Дублирование имени стратегии внутри одного инструмента ДОПУСТИМО при различных профилях фильтрации; идентичность привязки — кортеж (инструмент, стратегия, профиль). Имена стратегий и имена профилей фильтрации ДОЛЖНЫ валидироваться против соответствующих реестров до старта основного цикла; неизвестное имя ДОЛЖНО вызывать ошибку с перечнем неизвестных и доступных имён.

#### Scenario: Несколько стратегий на тикере
- **WHEN** инструменту назначены две стратегии и данные загружены
- **THEN** обе стратегии обрабатывают одни и те же свечи независимо друг от друга

#### Scenario: Фьючерсная привязка действует на любой контракт актива
- **WHEN** в `FUTURE_STRATEGIES` есть запись `"NG"`
- **THEN** любой контракт базового актива NG получает назначенные ей привязки без дополнительной настройки

#### Scenario: Тикер без привязки пропускается
- **WHEN** тикер отсутствует в словаре своего класса инструментов или его список пуст
- **THEN** запрос данных для него не выполняется, в лог пишется запись о пропуске

#### Scenario: Невалидная привязка останавливает запуск
- **WHEN** в любом из словарей `SHARE_STRATEGIES` или `FUTURE_STRATEGIES` указано имя незарегистрированной стратегии
- **THEN** выбрасывается ошибка с перечнем неизвестных и доступных имён; основной цикл не запускается

#### Scenario: Неизвестный профиль фильтрации останавливает запуск
- **WHEN** в любой привязке указано имя незарегистрированного профиля фильтрации
- **THEN** выбрасывается ошибка с перечнем неизвестных и доступных профилей; основной цикл не запускается

#### Scenario: Дубли стратегии с разными профилями
- **WHEN** инструменту назначена одна и та же стратегия дважды с разными профилями фильтрации
- **THEN** обе привязки обрабатываются в цикле как независимые задачи с общим инстансом стратегии

### Requirement: Формирование уведомлений отдельным классом
Тексты уведомлений ДОЛЖЕН формировать общий класс `DecisionFormatter` в пакете `src/notifier`, внедряемый в нотификаторы через конструктор: перевод `Decision` в сообщение (эмодзи, округление цены до 3 знаков, блоки инструмента, таймфрейма, времени бара и стратегии). Контекст задачи — профиль фильтрации и признак отклонения фильтром — ДОЛЖЕН передаваться форматтеру параметрами вызова. Наблюдаемое поведение сообщений: `● <инструмент> (<таймфрейм>) HH:MM | <стратегия> [<профиль>] ➜ <статус>`; статусы: ПОКУПКА — «🟢 ПОКУПКА (BUY) — Цена: X», ПРОДАЖА — «🔴 ПРОДАЖА (SELL) — Цена: X», УДЕРЖАНИЕ — «⏳ Нет сигнала.», отклонение фильтром — «❌ Отклонено фильтром.» (без цены).

#### Scenario: Сообщение о покупке
- **WHEN** форматтер получает `SignalType.BUY`, цену 3.14159, стратегию `macd_rsi_stoch`, label «NG» и профиль «raw»
- **THEN** сообщение содержит `[raw] ➜ 🟢 ПОКУПКА (BUY) — Цена: 3.142`

#### Scenario: Сообщение об отклонении фильтром
- **WHEN** форматтер получает признак отклонения фильтром
- **THEN** сообщение содержит статус `❌ Отклонено фильтром.` и не содержит цены
