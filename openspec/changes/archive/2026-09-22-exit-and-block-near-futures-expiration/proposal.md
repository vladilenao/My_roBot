## Why

Фьючерсный контракт имеет дату экспирации: вблизи неё падает ликвидность, а с наступлением экспирации робот несёт риск принудительного расчёта/деградации данных. Сейчас робот входит в позиции и сопровождает их вплоть до экспирации, не учитывая горизонт до неё.

## What Changes

- Метаданные контракта (`ContractMeta`) дополняются датой экспирации; значение заполняется из API Тильды (`load_futures_contracts`) для фьючерсных инструментов, для акций остаётся `None`.
- Новый конфигурационный ключ `[trading] contract_expiry_block_days` (календарные сутки до момента экспирации, дефолт `2`).
- **Вход**: фьючерс с оставшимся горизонтом `≤ contract_expiry_block_days` календарных суток до экспирации отклоняет новые входы и доборы на уровне допуска с причиной `contract-expiring`; причина человекочитаема и машиночитаема.
- **Отмена запланированных входов**: незаполненный вход в фазе `ENTRY_PENDING` по такому контракту отменяется командой `CancelEntry` с причиной `contract-expiring`.
- **Закрытие позиций**: открытые/наращиваемые/сокращаемые позиции по такому контракту закрываются командой `CloseTrade` с причиной `contract-expiring` независимо от сигналов стратегии.
- Решение о близости экспирации вычисляется на каждом тике из статичной даты экспирации и текущего времени — перезагрузка метаданных не требуется.

## Capabilities

### New Capabilities

- нет

### Modified Capabilities

- `trade-management`: входной допуск отклоняет контракты вблизи экспирации; запланированные входы отменяются; открытые позиции принудительно закрываются.
- `configuration`: новый ключ `contract_expiry_block_days` секции `[trading]` с дефолтом `2` и валидацией неотрицательного целого.

## Impact

- `src/portfolio/models.py` — `ContractMeta.expiration_date`.
- `src/api/instruments.py` — заполнение даты экспирации из ответа API.
- `src/trade_management/manager.py` — новый отказ допуска, проход отмены `ENTRY_PENDING` и проход закрытия живых позиций по экспирации.
- `src/config.py`, `src/config_loader.py`, `default.toml` — ключ `contract_expiry_block_days`.
- Unit-тесты допуска/управления; изменений брокерской симуляции и схемы SQLite нет.
