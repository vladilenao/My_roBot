## 2. Правило в менеджере

- [x] 2.1 `TradeManager.manage`: профиль считается только для сделок с `plan.timeframe == timeframe`. `_cancel_stale_entries`, `_close_expiring` и `drain_contract` работают, как раньше. Без `timeframe` профиль не считается (D1).
- [x] 2.2 Неизвестный или пустой `plan.timeframe`: пропуск на любом кадре, трасса и предупреждение `management-timeframe-unknown` не чаще раза на сделку за запуск (D2).
- [x] 2.3 `_manage_owned` и обработка противоположного сигнала: сигнал применяется к сделке только при совпадении таймфрейма, иначе трасса `management-timeframe-mismatch` (D6).
- [x] 2.4 Трасса `profile.<name>.manage` содержит вход `timeframe` (D7).
- [x] 2.5 Unit-тесты по сценариям требования «Сопровождение на таймфрейме плана»: свой бар переносит стоп; чужой бар не меняет стоп, состояние и экстремум `atr_trend`; неизвестный таймфрейм; сигнал связки с другого таймфрейма; ранее подтянутый стоп 1.1205 не ослабляется кандидатом 1.1199; трасса содержит `1h`.

## 3. Циклы робота

- [x] 3.1 `LiveAnalysis.step`: таймфреймы сопровождения = таймфреймы привязок ∪ таймфреймы планов открытых сделок инструмента. На таймфрейме без привязок `manage` вызывается на новом текущем закрытом баре без расчёта стратегий и публикации решений. Один вызов на `(instrument, tf, stamp)` (D3).
- [x] 3.2 Длина кадра `manage` — максимум требований привязок таймфрейма и `management_requirement` профилей открытых сделок этого таймфрейма (D4).
- [x] 3.3 `LiveAnalysis.register_needs` и `_bootstrap` загружают таймфреймы незавершённых сделок с прогревом их профилей (`TradeManager.management_obligations`, `TradingBot._management_needs`); неготовность видна в `market_data_status` (D3).
- [x] 3.4 `TradingBot._process`: к таймфреймам сопровождения добавлены таймфреймы планов сделок; вызов на защитном 1m сохранён для действий вне бара, профиль на нём не считается благодаря D1 (D5).
- [x] 3.5 Unit-тесты циклов: инструмент с привязками 15m и 1h и открытой сделкой на 1h — `manage` для неё срабатывает только на закрытии 1h; привязка на 1h удалена из конфигурации — сделка продолжает сопровождаться на 1h; исторический прогон не считает профиль на 1m.
