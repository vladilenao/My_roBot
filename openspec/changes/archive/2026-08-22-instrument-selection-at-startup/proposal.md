## Why

Сейчас бот жёстко привязан к одному инструменту (`TICKER="NGU6"`, `INSTRUMENT_TYPE="future"`), заданному в конфигурации. Это не позволяет пользователю выбирать набор инструментов для анализа без перекомпиляции. Необходимо дать возможность при запуске приложения интерактивно выбрать несколько инструментов (фьючерсы и акции) для параллельного мониторинга, с валидацией их существования и явной привязкой сигналов к конкретному инструменту.

## What Changes

- Добавляется интерактивный ввод списка инструментов при запуске приложения (тикер + тип: share/future)
- Реализуется валидация каждого введённого инструмента через API; при ошибке — повторный запрос
- Оркестрация переключается с обработки одного инструмента на цикл по списку выбранных инструментов
- Формат уведомлений расширяется: к каждому сообщению добавляется имя и тип инструмента

## Capabilities

### New Capabilities

- `instrument-selection`: Интерактивный ввод и валидация торговых инструментов при старте приложения

### Modified Capabilities

- `api-client`: Добавлена функция `client_context()` — контекстный менеджер для доступа к `client.instruments`
- `orchestration`: Бесконечный цикл теперь обходит список выбранных инструментов вместо одного фиксированного
- `signals`: Сообщения о сигналах содержат идентификатор инструмента (тикер + тип)
- `configuration`: Параметры `TICKER` и `INSTRUMENT_TYPE` более не используются как фиксированные константы для запуска; вместо этого список инструментов формируется интерактивно

## Impact

- `src/scheduler/runner.py` — основной цикл переписывается для обработки списка инструментов
- `src/config.py` — удаляются/деприкачатся `TICKER` и `INSTRUMENT_TYPE` как единственные входные параметры
- `src/notifier/sender.py` — формат сообщения расширяется именем инструмента
- `src/signals/generator.py` — `make_decision` принимает дополнительный параметр с именем инструмента
- `run.py` — перед запуском цикла вызывается этап выбора инструментов
- `src/api/client.py` — добавлена функция `client_context()` для контекстного менеджера
- `src/instruments/selector.py` — интерактивный ввод и валидация (использует `client_context`)
