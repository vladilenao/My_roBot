## MODIFIED Requirements

### Requirement: Конвейер обработки на каждой итерации
- На каждой итерации система ДОЛЖНА выполнять конвейер обработки для КАЖДОГО инструмента из списка выбранных: загрузить свечи, рассчитать индикаторы, агрегировать сигналы, определить текущую цену, принять решение, отправить уведомление с указанием инструмента.

#### Scenario: Нормальная итерация с данными
- **WHEN** `run_bot()` выполняет итерацию со списком из двух инструментов
- **THEN** для каждого инструмента система загружает свечи, вычисляет индикаторы, агрегирует сигналы, принимает решение и отправляет отформатированное сообщение с именем инструмента

#### Scenario: Один инструмент из списка недоступен
- **WHEN** при обработке одного из инструментов загрузка свечей возвращает пустой DataFrame
- **THEN** система выводит "Нет данных для {ticker}", пропускает этот инструмент и продолжает обработку следующего

### Requirement: Использование конфигурации
- Система ДОЛЖНА использовать список инструментов, сформированный на этапе выбора, вместо фиксированных `TICKER` и `INSTRUMENT_TYPE` из конфигурации.
- Система ДОЛЖНА использовать `TIMEFRAME`, `SIGNAL_WINDOW`, `SLEEP_SECONDS` из `src.config`.

#### Scenario: Конфигурация применяется к загрузке
- **WHEN** `run_bot()` выполняет итерацию со списком `[("SBER", "share"), ("NGU6", "future")]`
- **THEN** `load_candles` вызывается для каждого инструмента с соответствующими `ticker` и `instrument_type`, а `TIMEFRAME` берётся из конфигурации

### Requirement: Формат уведомления
- Сообщение уведомления SHALL содержать идентификатор инструмента (тикер и тип) в начале сообщения, за которым следуют значения сумм индикаторов и текст решения.
- Сообщение ДОЛЖНО включать значения сумм индикаторов в формате `"📊 Сигналы: MACD={macd_sum}, RSI={rsi_sum}, Stoch={stoch_sum}"`, за которым следует текст решения на новой строке.

#### Scenario: Формат сообщения
- **WHEN** итерация завершается успешно
- **THEN** отправляемое сообщение содержит строку "📊 Сигналы:" с тремя значениями сумм и текст решения на следующей строке

#### Scenario: Формат сообщения для конкретного инструмента
- **WHEN** итерация завершается успешно для инструмента `SBER share`
- **THEN** отправляемое сообщение начинается с "[SBER share]" и содержит "📊 Сигналы: MACD={macd_sum}, RSI={rsi_sum}, Stoch={stoch_sum}" и текст решения

### Requirement: Точка входа
- Точка входа `run.py` ДОЛЖНА перед запуском бесконечного цикла вызывать этап выбора инструментов и передать результат в `run_bot()`.

#### Scenario: Запуск через run.py
- **WHEN** `run.py` выполняется как `python run.py`
- **THEN** система запрашивает у пользователя список инструментов, валидирует их и запускает `run_bot()` с выбранным списком
