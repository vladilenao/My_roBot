## MODIFIED Requirements

### Requirement: Параметры стратегии
- Система ДОЛЖНА предоставлять следующие параметры стратегии: `SIGNAL_WINDOW=5`, `SLEEP_SECONDS=9`, `TIMEFRAME="1h"`.
- Параметры `TICKER` и `INSTRUMENT_TYPE` ДОЛЖНЫ оставаться доступными как значения по умолчанию, но более не являются основным способом задания инструментов — вместо этого список инструментов формируется интерактивно при запуске.

#### Scenario: Чтение параметров по умолчанию
- **WHEN** модуль импортирует `SIGNAL_WINDOW`, `SLEEP_SECONDS` или `TIMEFRAME` из `src.config`
- **THEN** возвращаются значения по умолчанию (5, 9, "1h" соответственно)

#### Scenario: TICKER и INSTRUMENT_TYPE как fallback
- **WHEN** интерактивный выбор инструментов не используется (например, в тестах)
- **THEN** `TICKER` и `INSTRUMENT_TYPE` доступны как константы со значениями по умолчанию (`"NGU6"`, `"future"`)
