## ADDED Requirements

### Requirement: Системный поиск адреса брокера
Нормативный уровень: MUST.
Робот ДОЛЖЕН до загрузки gRPC задавать `GRPC_DNS_RESOLVER=native`, чтобы подключения к брокеру искали адрес системным поиском адресов, а не резолвером c-ares. Значение, заданное в окружении снаружи, НЕ ДОЛЖНО меняться. Процессы контуров ДОЛЖНЫ получать ту же настройку.

#### Scenario: Первый DNS-сервер сети не отвечает
- **WHEN** первый DNS-сервер из настроек сети не отвечает, а система находит адрес брокера через другой
- **THEN** новое подключение gRPC к брокеру находит адрес, и контур стартует

#### Scenario: Резолвер задан снаружи
- **WHEN** робот запущен с `GRPC_DNS_RESOLVER=ares` в окружении
- **THEN** робот это значение не меняет

#### Scenario: Процесс контура
- **WHEN** ядро запускает процесс контура
- **THEN** в процессе контура `GRPC_DNS_RESOLVER` равен значению ядра
