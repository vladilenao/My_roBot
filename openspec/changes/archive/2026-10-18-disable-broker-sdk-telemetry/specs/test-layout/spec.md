## ADDED Requirements

### Requirement: Тесты не открывают клиент брокера
Нормативный уровень: MUST.
Тесты НЕ ДОЛЖНЫ создавать настоящий `Client`/`AsyncClient` SDK брокера и НЕ ДОЛЖНЫ вызывать `sentry_sdk.init`; общая фикстура ДОЛЖНА завершать такой тест с причиной и подсказкой подменить `src.api.client.Client` или передать свой `ClientProvider`. Тест с маркером `real_broker_sdk` МОЖЕТ создать настоящий клиент SDK с поддельным токеном и адресом без сети; запрет `sentry_sdk.init` на него распространяется.

#### Scenario: Устаревшая подмена клиента
- **WHEN** тест подменяет не тот модуль и код создаёт настоящий `Client` SDK
- **THEN** тест завершается с причиной «Настоящий Client SDK брокера в тестах запрещён»
