## MODIFIED Requirements

### Requirement: Параметры стратегии
Система ДОЛЖНА предоставлять: `SLEEP_SECONDS=9`, `TIMEFRAME="1h"` и два словаря привязок стратегий:
- `SHARE_STRATEGIES` — точный тикер нефьючерсного инструмента → список имён активных стратегий;
- `FUTURE_STRATEGIES` — двухбуквенный код базового актива в верхнем регистре (`"NG"`) → список имён активных стратегий, без привязки к конкретному контракту.

Глобальный параметр `SIGNAL_WINDOW` ДОЛЖЕН быть удалён — окно расчёта принадлежит каждой стратегии. Словарь `STRATEGY_ASSIGNMENTS` ДОЛЖЕН быть удалён.

#### Scenario: Чтение параметров
- **WHEN** модуль импортирует параметры
- **THEN** возвращаются значения по умолчанию; `SIGNAL_WINDOW` и `STRATEGY_ASSIGNMENTS` отсутствуют

#### Scenario: Привязка инструментов к стратегиям
- **WHEN** модуль читает `SHARE_STRATEGIES` и `FUTURE_STRATEGIES`
- **THEN** для каждого ключа доступен список имён стратегий, зарегистрированных в реестре; ключи `SHARE_STRATEGIES` — точные тикеры, ключи `FUTURE_STRATEGIES` — базовые активы в верхнем регистре без суффикса контракта
