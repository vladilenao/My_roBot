## ADDED Requirements

### Requirement: Передача подтверждённых ориентиров формации
Нормативный уровень: MUST.
Событие AB=CD ДОЛЖНО передавать устойчивый pattern_id, сторону, точки A/B/C, цель D, границу отмены C и время подтверждения. Ориентиры доступны не ранее закрытия правого окна подтверждения свинга C. Профиль НЕ ДОЛЖЕН получать форму, выбранную с использованием будущих свечей; новая формация не заменяет молча план открытой сделки.

#### Scenario: Вход после подтверждения C
- **WHEN** правое окно C закрыто и вход расположен между C и D в направлении сделки
- **THEN** событие содержит данные именно этой подтверждённой формации для pattern_targets

#### Scenario: Не подтверждённый экстремум
- **WHEN** C видна на полной истории, но правое окно ещё не было доступно на рассматриваемом баре
- **THEN** на этом баре ориентиры не могут использоваться для плана
