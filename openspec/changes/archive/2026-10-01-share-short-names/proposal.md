# Короткие имена акций

## Why
Правило именования запрещает показывать пользователю сырой биржевой тикер, чтобы в текст не попал код контракта фьючерса (`NGV6`). Для акций запрет не имеет смысла: у акции нет отдельного кода контракта, а её тикер (`SBER`, `GAZP`, `LKOH`) — и есть короткое имя, которое пользователь сам выбирает из списка. Из-за сплошного запрета каждый лог по акции печатал заглушку `контракт не указан` вместо названия — ��ри том, что торговая логика работала штатно.

## What Changes
- **Короткое имя акции ДОЛЖНО** совпадать с её тикером: тикер акции является коротким именем, а не скрываемым биржевым кодом.
- Правило «сырой тикер пользователю не показывается» **ОСТАЁТСЯ** в силе для фьючерсов, ETF, валют и любых инструментов с отдельным кодом контракта.
- Источник короткого имени остаётся прежним: явный 4-й элемент кортежа `(label, ticker, type, short_name)`, а при его отсутствии — тикер только для акций.

## Impact
- Affected specs: `notification`, `logging`
- Affected code: `src/instruments/model.py`, `src/instruments/selector.py`, `run.py` (карта имён), `src/history/report.py` (заглушка остаётся для неизвестных контрактов)
- Affected tests: `tests/unit/instruments/test_model.py`, `tests/unit/instruments/test_selector.py`, `tests/unit/test_run.py`
- Боевое поведение меняется только в тексте вывода: вместо `контракт не указан` печатается `SBER`. Торговые решения, фильтры, размеры и журнал не меняются.
