# Короткое имя контракта в логах

## MODIFIED Requirements

### Requirement: Проверяемый аудит торговых вычислений
Нормативный уровень: MUST.
Все вычисления, влияющие на вход, фильтр, план, размер, сопровождение и результат, ДОЛЖНЫ иметь воспроизводимую трассу: входные значения с единицами, границы данных и время доступности, параметры и версия алгоритма, формула/правило, промежуточные значения, неокруглённый и округлённый результат, причина выбора/отказа. Для индикаторных расчётов ДОЛЖНЫ сохраняться исходное окно либо ссылка на сохранённый неизменный набор данных плюс seed рекуррентного расчёта; одного хеша недостаточно. Трассы связываются calculation_id, assignment_id, trade_id, signal_id, command_id и event_id при наличии, а также существующими service_uid/correlation_id. Пользовательские логи используют короткое имя контракта и МСК: для фьючерсов — имя контракта (`NG-10.26`), для акций — тикер акции (`SBER`), который для акции является коротким именем. Скрывать биржевой код контракта ДОЛЖНЫ инструменты с отдельным кодом (фьючерсы, ETF, валюты); для акций такой код отсутствует и заглушка `контракт не указан` не выводится. Секреты не записываются.

#### Scenario: Проверка количества вручную
- **WHEN** риск разрешил два контракта
- **THEN** по трассе доступны цена/стоп, шаг/стоимость шага, расходы, каждый лимит, занятые резервы, расчёт floor и причина ограничения

#### Scenario: Лог по акции называет акцию
- **WHEN** бот пишет лог по тику акции `SBER` с таймфреймом `15m`
- **THEN** в строке лога указано `SBER`, а не `контракт не указан`

#### Scenario: Имя контракта найдено в каталоге
- **WHEN** инструмент выбран вводом тикера вручную и в каталоге источника есть его название
- **THEN** лог использует короткое имя из каталога, а биржевой код остаётся скрытым

#### Scenario: Лог по фьючерсу скрывает биржевой код
- **WHEN** бот пишет лог по фьючерсу с тикером `NGU6`
- **THEN** в строке лога указано короткое имя контракта, а биржевой код отсутствует

#### Scenario: Проверка ATR
- **WHEN** стоп рассчитан по ATR
- **THEN** доступны закрытые OHLC/предыдущий close, период, seed, последовательность TR/сглаживания либо их сохранённая проверяемая трасса, ATR, множитель и округление стопа

#### Scenario: Отказ от переноса
- **WHEN** кандидат трейлинга ухудшает защиту
- **THEN** лог содержит прежний стоп, кандидат, правило монотонности и причину сохранения прежнего уровня
