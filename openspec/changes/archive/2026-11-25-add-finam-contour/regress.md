# Ручная проверка add-finam-contour (tasks 8.x)

**Где:** тестовый робот из PyCharm на ветке `feature/finam-contour`, API на `8102`; UI — ветка `feature/ui-finam-contour` (UI-сервер 5180 отдаёт `frontend/dist`, сборка уже сделана). ПРОМ (`8101`, `~/Desktop/my_roBot_app`) не трогать.

**Что смотреть:**
- карточки «Счёта Финам» — в новом канале Финама;
- лог контура — `data/contours/finam/bot_debug.log`;
- состояние — `GET /api/v1/finam` или страница «Счёт Финам» в UI.

Контур `finam` только читает счёт: заявок он не ставит ни при каком шаге.

## Подготовка

1. **Бот и канал Финама.** В Telegram:
   - создать бота у `@BotFather`;
   - создать канал «Счёт Финам»;
   - добавить в канал бота администратором с правом публикации.
2. **`.env` тестового робота** — добавить две строки, значения не показывать никому:

   | Переменная | Что |
   |---|---|
   | `TELEGRAM_FINAM_BOT_TOKEN` | токен нового бота |
   | `TELEGRAM_FINAM_CHANNEL_ID` | id канала (`-100…`) |

   `FINAM_SECRET_TOKEN` и `FINAM_ACCOUNT_ID` уже есть с разведки Ф0. `TINKOFF_TOKEN` нужен для коротких имён инструментов.
3. **Запуск.** В `robot.toml` секцию `[contours.finam]` не трогать: `orders = true` робот не примет. Остановить тестовый робот, переключить PyCharm на `feature/finam-contour`, запустить.
4. **Лог ядра.** Видна строка «Контур finam …» между `account` и `sandbox`. В логах контуров нет `ImportError`, `AttributeError`, `TypeError`.

## 8.1 Старт и допуск

| Шаг | Действие | Ожидание |
|---|---|---|
| а | Запустить «Счёт Финам»: кнопка «Запустить «Счёт Финам»» в UI или `PUT /api/v1/finam/target` с `{"mode": "on"}` | В канале Финама — карточка старта с меткой «СЧЁТ ФИНАМ» и последними 4 знаками счёта |
| б | `GET /api/v1/finam` | `state = running`, `broker = finam`, `current.account_link = ok`, `current.admission.access_level` — права токена (`full_access` у токена Ф0), `limits` — квоты 200 |
| в | Деньги и позиции в `current` | Как в терминале Финама: пустой счёт — `rub = 0.00`, `liquid_portfolio = null`; с деньгами — сумма строк денег |
| г | Лог контура через 20 мин | Нет `UNAUTHENTICATED`: JWT обновляется стримом. Ни секрета, ни номера счёта, ни JWT в логе нет (поиск по `bot_debug.log`) |

## 8.2 Сверка и расхождение

| Шаг | Действие | Ожидание |
|---|---|---|
| а | `GET /api/v1/finam/reconcile` | `result = ok`, `items` пустые |
| б | В терминале Финама поставить руками лимитную заявку далеко от рынка (например, покупка 1 Si на 5 % ниже) | В течение минуты в канале Финама — тревога сверки по этому инструменту, в `GET /api/v1/finam` — `frozen` с коротким именем (`Si-12.26`) |
| в | Снять заявку в терминале | Следующая сверка: сообщение «расхождение устранено», `frozen` пуст |

## Чего ждать в окне обслуживания

С 05:00 до 06:15 МСК API Финама может быть недоступен. Это нормально:
- тревоги нет;
- в `GET /api/v1/finam` — `account_link = maintenance`;
- при старте в окне контур ждёт со статусом «окно обслуживания брокера».

Тревога «Счёт недоступен» вне окна — настоящая.
