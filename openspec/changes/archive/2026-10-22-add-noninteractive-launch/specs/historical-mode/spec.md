## MODIFIED Requirements

### Requirement: Выбор режима при старте
Нормативный уровень: MUST. Режим работы ДОЛЖЕН задаваться до запуска торговли одним из двух способов: параметрами запуска или меню. Режимов два: эмуляция (торговля на живых данных с симулятором исполнения, прежде называлась «боевой») и историческая торговля.

Параметры запуска: `--mode emulation` или `--mode history`. Для истории ДОЛЖНЫ задаваться `--from` и `--to` в формате `ГГГГ-ММ-ДД ЧЧ:ММ` (без зоны — UTC) и МОЖЕТ задаваться `--pause` (по умолчанию прежнее значение паузы). Флаг `--no-prompt` ДОЛЖЕН означать `--mode emulation`. Эмуляция МОЖЕТ вместо списка инструментов ждать команды локального API (`--wait-command`, правила — в спецификации `control-api`). При запуске с параметрами система НЕ ДОЛЖНА задавать ни одного вопроса. Ошибка в параметрах (неизвестный режим, нет обязательной даты, неразборчивая дата, начало не раньше конца, отрицательная пауза, параметры истории в режиме эмуляции) ДОЛЖНА печатать причину и завершать процесс с кодом `2` без запуска торговли.

Без параметра режима система ДОЛЖНА показать меню: эмуляция или историческая торговля. Для эмуляции меню ДОЛЖНО спросить, выбирать инструменты сейчас или ждать команды API; для истории — начало, конец и паузу, как прежде. Меню ДОЛЖНО только собирать те же параметры запуска, дальше запуск ДОЛЖЕН идти тем же путём, что и с параметрами. В начале любого запуска система ДОЛЖНА печатать и записывать в журнал эквивалентную команду, по которой запуск можно повторить без вопросов. Контракты в ней ДОЛЖНЫ записываться коротким именем, а не биржевым тикером.

#### Scenario: Выбран боевой режим
- **WHEN** пользователь запускает робота без параметров и выбирает в меню эмуляцию (прежний боевой режим)
- **THEN** вопросы о диапазоне не задаются, торговля запускается на живых данных, а в начале печатается эквивалентная команда с `--mode emulation`

#### Scenario: Выбран исторический режим
- **WHEN** пользователь запускает робота без параметров и выбирает историческую торговлю
- **THEN** система запрашивает начало диапазона, конец диапазона и паузу между тиками, торговля не запускается до получения ответов, а затем печатается эквивалентная команда с `--mode history --from --to --pause`

#### Scenario: История параметрами без вопросов
- **WHEN** робот запущен с `--mode history --from "2026-09-01 10:00" --to "2026-09-08 10:00" --pause 0`
- **THEN** ни одного вопроса не задаётся, прогон идёт по этому диапазону с нулевой паузой

#### Scenario: Ошибка в параметрах
- **WHEN** робот запущен с `--mode history --from "2026-09-08 10:00" --to "2026-09-01 10:00"`
- **THEN** печатается, что начало должно быть раньше конца, процесс завершается с кодом `2`, торговля не запускается и вопросы не задаются

#### Scenario: Запуск без вопросов по старому флагу
- **WHEN** робот запущен с `--no-prompt`
- **THEN** запускается эмуляция, вопросы о режиме и об инструментах не задаются

#### Scenario: Повтор запуска из меню
- **WHEN** пользователь прошёл меню истории и скопировал напечатанную эквивалентную команду
- **THEN** запуск по этой команде получает те же режим, диапазон, паузу и инструменты без вопросов
