## ADDED Requirements

### Requirement: Остановка контура запрещает входы и закрывает сделки
Нормативный уровень: MUST. Менеджер сделок ДОЛЖЕН поддерживать два режима остановки торгового контура.

- **«Без входов».** Менеджер ДОЛЖЕН:
  - отклонять каждый новый вход с причиной `contour-stopping`; сигнал при этом публикуется как отклонённый;
  - снимать каждый неисполненный вход действием `CancelEntry` с причиной `contour-stop`;
  - сопровождать открытые позиции по их плану;
  - не допускать увеличение позиции.
- **«Закрыть всё».** Дополнительно к «без входов» менеджер ДОЛЖЕН закрывать каждую открытую позицию действием `CloseTrade` с причиной `contour-stop`. В эмуляции закрытие исполняется на открытии следующего бара.

Если по сделке уже есть заявка снятия или закрытия, второе действие НЕ ДОЛЖНО создаваться. Решения ДОЛЖНЫ попадать в трассу решений с кодом причины. Менеджер ДОЛЖЕН сообщать число открытых позиций и неисполненных входов для завершения контура.

#### Scenario: Сигнал во время остановки
- **GIVEN** контур в режиме «без входов»
- **WHEN** стратегия по SBER даёт сигнал на вход
- **THEN** вход отклонён с причиной `contour-stopping`, заявка не создаётся

#### Scenario: Закрыть всё
- **GIVEN** открыты позиции NG и SBER, у NG уже есть заявка закрытия по стопу
- **WHEN** применяется «закрыть всё»
- **THEN** закрытие создаётся только для SBER, NG закрывается своей заявкой, на открытии следующего бара обе позиции закрыты

#### Scenario: Добор во время остановки
- **GIVEN** контур в режиме «без входов», у позиции NG план предусматривает добор
- **WHEN** наступает условие добора
- **THEN** добор не допускается, позиция сопровождается без увеличения
