## MODIFIED Requirements

### Requirement: Параметры стратегии
Система ДОЛЖНА предоставлять: `SLEEP_SECONDS`, `TIMEFRAME` и два словаря привязок стратегий:
- `SHARE_STRATEGIES` — точный тикер нефьючерсного инструмента → список привязок;
- `FUTURE_STRATEGIES` — двухбуквенный код базового актива в верхнем регистре (`"NG"`) → список привязок, без привязки к конкретному контракту.

Каждая привязка ДОЛЖНА содержать имя стратегии, профиль фильтрации (по умолчанию `"basic_levels"`) и таймфрейм. Таймфрейм привязки ДОЛЖЕН вычисляться каскадом: ключ `tf` инлайн-записи → ключ `timeframe` таблицы тикера → глобальный `TIMEFRAME` из раздела робота. Привязки ДОЛЖНЫ задаваться в `robot.toml` таблицами тикеров (`[strategies.share.<ТИКЕР>]`, `[strategies.future.<БАЗА>]`) с массивом `strategies`; при отсутствии файла — вшитыми дефолтами. Дублирование имени стратегии внутри одного тикера ДОЛЖНО быть допустимым при различных профилях фильтрации или различных таймфреймах. Глобальные `SIGNAL_WINDOW` и `STRATEGY_ASSIGNMENTS` по-прежнему ДОЛЖНЫ отсутствовать.

#### Scenario: Чтение параметров
- **WHEN** модуль импортирует параметры
- **THEN** возвращаются значения из `robot.toml` (или вшитые дефолты); `SIGNAL_WINDOW` и `STRATEGY_ASSIGNMENTS` отсутствуют

#### Scenario: Привязка инструментов к стратегиям
- **WHEN** модуль читает `SHARE_STRATEGIES` и `FUTURE_STRATEGIES`
- **THEN** для каждого ключа доступен список привязок; каждая привязка содержит имя стратегии, профиль фильтрации и таймфрейм; ключи `SHARE_STRATEGIES` — точные тикеры, ключи `FUTURE_STRATEGIES` — базовые активы в верхнем регистре без суффикса контракта

#### Scenario: Дубли стратегии с разными профилями
- **WHEN** в таблице тикера одна и та же стратегия указана дважды с разными профилями фильтрации
- **THEN** обе привязки присутствуют в списке и различаются профилем

#### Scenario: Дубли стратегии с разными таймфреймами
- **WHEN** в таблице тикера одна и та же стратегия указана дважды с разными `tf`
- **THEN** обе привязки присутствуют в списке и различаются таймфреймом

#### Scenario: Каскад таймфрейма — tf инлайна
- **WHEN** инлайн-запись стратегии содержит `tf = "15m"`, а таблица тикера — `timeframe = "1h"`
- **THEN** привязка получает таймфрейм `"15m"`

#### Scenario: Каскад таймфрейма — timeframe тикера
- **WHEN** инлайн-запись не содержит `tf`, а таблица тикера содержит `timeframe = "15m"`
- **THEN** привязка получает таймфрейм `"15m"`

#### Scenario: Каскад таймфрейма — глобальный дефолт
- **WHEN** ни инлайн-запись, ни таблица тикера не задают таймфрейм
- **THEN** привязка получает глобальный `TIMEFRAME` из раздела робота

### Requirement: Гибридная запись привязки стратегий
В таблице тикера массив `strategies` ДОЛЖЕН принимать элементы двух форм: строку с именем стратегии (профиль фильтрации и таймфрейм — дефолтные по каскаду) либо инлайн-таблицу с обязательным ключом `name` и опциональными ключами `filter` и `tf`. Таблица тикера ДОЛЖНА принимать опциональный ключ `timeframe`. Значения `tf` и `timeframe` ДОЛЖНЫ быть ключами словаря `TIMEFRAMES`. Любые иные ключи инлайн-таблицы, таблицы тикера и секций стратегий ДОЛЖНЫ отклоняться с `ConfigError` с указанием файла и ключа. Прежний плоский синтаксис `<ТИКЕР> = [...]` ДОЛЖЕН отклоняться с `ConfigError`. Элемент массива иного типа либо инлайн-таблица без ключа `name` ДОЛЖНЫ отклоняться с `ConfigError`.

#### Scenario: Строка — привязка с дефолтным профилем
- **WHEN** элемент массива `strategies` — строка `"flat_triangle"`
- **THEN** привязка содержит имя `flat_triangle` и профиль `"basic_levels"`

#### Scenario: Инлайн-таблица с переопределением профиля
- **WHEN** элемент массива — `{ name = "macd_rsi_stoch", filter = "raw" }`
- **THEN** привязка содержит имя `macd_rsi_stoch` и профиль `raw`

#### Scenario: Инлайн-таблица с переопределением таймфрейма
- **WHEN** элемент массива — `{ name = "macd_rsi_stoch", filter = "raw", tf = "15m" }`
- **THEN** привязка содержит имя `macd_rsi_stoch`, профиль `raw` и таймфрейм `"15m"`

#### Scenario: Инлайн-таблица без имени стратегии
- **WHEN** элемент массива — `{ filter = "raw" }` без ключа `name`
- **THEN** загрузка конфигурации завершается `ConfigError`

#### Scenario: Неизвестный ключ отклоняется
- **WHEN** инлайн-таблица или таблица тикера содержит незнакомый ключ (например, `window`)
- **THEN** загрузка конфигурации завершается `ConfigError` с указанием файла и ключа

#### Scenario: Недопустимый таймфрейм отклоняется
- **WHEN** ключ `tf` или `timeframe` содержит значение вне словаря `TIMEFRAMES` (например, `"2h"`)
- **THEN** загрузка конфигурации завершается `ConfigError` с перечнем допустимых таймфреймов

#### Scenario: Прежний плоский синтаксис отклоняется
- **WHEN** секция `[strategies.share]` содержит запись вида `SBER = ["macd_rsi_stoch"]`
- **THEN** загрузка конфигурации завершается `ConfigError`
