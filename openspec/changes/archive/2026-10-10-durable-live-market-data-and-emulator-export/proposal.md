## Why

В текущем режиме My Robot держит свечи в памяти: после перезапуска невозможно
восстановить точный набор виденных им данных, а поздняя свеча с временем раньше
последней загруженной отбрасывается. Для последовательной свечной симуляции и
пополнения Historical Broker API Emulator нужен долговечный журнал рыночных
данных с явным состоянием пропусков и подтверждаемой передачей изменений.

## What Changes

- My Robot продолжает получать текущие рыночные данные напрямую от брокера;
  реальная отправка торговых заявок в объём изменения не входит.
- Контур получения сверяет завершённость свечей, расписание и торговый статус
  инструмента, восстанавливает пропуски и хранит неразрешённые интервалы явно.
- Отдельная локальная SQLite-БД робота сохраняет свечи, их версии, состояние
  интервалов и независимые границы получения, обработки и экспорта.
- `MarketDataCache` становится быстрым представлением данных из локального
  хранилища; он не объявляет поздние/исправленные свечи новыми рыночными
  событиями и не скрывает неразрешённые пропуски от симулятора.
- Для Historical Broker API Emulator появляется версионированный HTTP API
  изменений с подтверждаемым курсором и OpenAPI (Swagger) контрактом.
  Эмулятор переносит данные в собственную БД; его независимая дозагрузка у
  брокера остаётся нужна, пока робот выключен.
- Документация объясняет схему, модель полноты, подключение эмулятора,
  восстановление и поведение при сбоях.

## Capabilities

### New Capabilities

- `live-market-data`: долговечное получение, хранение и проверка покрытия
  рыночных данных в текущем режиме.
- `market-data-export`: внешний поток подтверждённых изменений и фиксация
  прогресса потребителя для Historical Broker API Emulator.

### Modified Capabilities

- `data-cache`: готовность и кадры текущего режима опираются на сохранённые
  завершённые свечи и состояние покрытия, включая поздние версии.
- `execution`: симуляция не проходит неразрешённые интервалы как подтверждённое
  отсутствие свечей и восстанавливает курсор после сбоя без повторного исполнения.

## Impact

- My Robot: `src/data/loader.py`, `src/data/cache.py`, новые компоненты
  хранения/сверки/экспорта, сборка в `run.py`, курсоры свечной симуляции.
- Новый локальный файл БД рыночных данных в каталоге состояния робота;
  схема `trades.sqlite3` не становится архивом всех свечей.
- Новый внешний HTTP API с обязательным `docs/market-data/openapi.yaml` и
  текстовым руководством для Historical Broker API Emulator.
- Historical Broker API Emulator должен реализовать отдельный потребитель
  экспорта; его код находится вне данного репозитория. Исторический режим
  My Robot сохраняет чтение через существующий `HistoricalClient`.
