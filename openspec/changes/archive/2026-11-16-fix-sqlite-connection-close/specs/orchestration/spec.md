## ADDED Requirements

### Requirement: Процесс робота бережёт открытые файлы
Нормативный уровень: MUST. Короткое соединение SQLite, которое хранилище открывает на одну операцию, ДОЛЖНО закрываться при выходе из операции, а не оставаться сборщику мусора. Выход из операции ДОЛЖЕН сохранять прежнюю транзакционную семантику: успешная операция фиксируется, операция с исключением откатывается. Каждый процесс робота (ядро, контур, прогон истории) ДОЛЖЕН при запуске поднимать мягкий предел открытых файлов до 8192, если он ниже и жёсткий предел это позволяет. Если поднять предел не удалось, процесс ДОЛЖЕН записать предупреждение и продолжить запуск. На платформе без такого предела шаг ДОЛЖЕН пропускаться.

#### Scenario: Сотни коротких операций подряд
- **WHEN** хранилище рыночных данных выполнило 500 коротких операций чтения и записи
- **THEN** число открытых процессом файлов базы не выросло: после каждой операции её соединение закрыто

#### Scenario: Операция с ошибкой
- **WHEN** внутри короткой операции записи возникло исключение
- **THEN** запись откатывается, соединение закрывается, исключение доходит до вызывающего

#### Scenario: Запуск из «Терминала» macOS
- **WHEN** робот запущен с мягким пределом 256 открытых файлов и жёстким без ограничения
- **THEN** процесс поднимает мягкий предел до 8192 до открытия баз и прогрева инструментов

#### Scenario: Жёсткий предел ниже 8192
- **WHEN** жёсткий предел процесса 4096, мягкий 256
- **THEN** мягкий предел поднимается до 4096, запуск продолжается

#### Scenario: Предел уже выше
- **WHEN** мягкий предел процесса 1048576
- **THEN** предел не меняется
