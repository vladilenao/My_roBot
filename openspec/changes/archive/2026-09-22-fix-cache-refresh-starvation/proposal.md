# Fix cache refresh starvation

## Why

`MarketDataCache.refresh_if_new_candle` при `force=True` (ожидание появления с опозданием опубликованного бара) с глобальным `data_refresh_min_interval` за каждый интервал обновляет только **первый** кадр таймфрейма, остальные кадры «голодают» и навсегда остаются устаревшими. Жёсткий гейт готовности `has_fresh_closed_bar` (по всем кадрам) из-за этого никогда не открывается: в проде после анализа бара 11:15 робот не выдал анализов 15m 11:30 и 11:45 — тики молча заморозились в ожидании бара (между анализами прошло 46 минут).

## What Changes

- В `refresh_if_new_candle` за один вызов (одно окно троттлинга) обновлять ровно одну наиболее **отстающую** пару «инструмент — ТФ», а не первый кадр в порядке регистрации.
- Порядок приоритета: пары с самым старым закрытым баром обновляются первыми; свежие пары (уже имеющие свежий закрытый бар) вхолостую не перезапрашиваются и лимит на них не тратится.
- Пары, пропущенные дозагрузок из-за интервального лимита, НЕ помечаются отслеженными для текущей границы: они остаются кандидатами на следующее окно и в конечном счёте обновляются.
- Поведение для `force=False` и тему rate-limit паузы (`_retry_after`) не меняются.
- Обновить unit-тесты `tests/unit/data/test_cache.py`: новый тест на равномерную дозагрузку всех кадров ТФ при троттлинге и на приоритет отстающих.

## Capabilities

### New Capabilities
- нет

### Modified Capabilities
- `data-cache`: меняется поведение инкрементальной/форс-дозагрузки кадров — лимит интервала между обращениями к API распределяется между всеми кадрами таймфрейма, каждый кадр с данными гарантированно обновляется за ограниченное число окон, приоритет у отстающих; пропущенные по лимиту кадры не считаются обновлёнными.

## Impact

- `src/data/cache.py` — переработка цикла дозагрузки в `refresh_if_new_candle` (выбор кандидатов, приоритизация, один кадр за вызов).
- `tests/unit/data/test_cache.py` — новые/обновлённые unit-тесты.
- Никаких изменений конфигурации и внешнего API: параметры `data_refresh_min_interval`, `data_backfill_window_seconds` и семантика `has_fresh_closed_bar` сохраняются.
