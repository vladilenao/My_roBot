## ADDED Requirements

### Requirement: Настройка сессионной защиты внутридневных сделок
Нормативный уровень: MUST.
Система ДОЛЖНА читать необязательную секцию `[trading.intraday]` файла `robot.toml` (или вшитого `default.toml`):

| Ключ | Тип | По умолчанию |
|---|---|---|
| `enabled` | логическое | `true` |
| `max_timeframe` | известный таймфрейм | `15m` |
| `entry_sessions` | список без повторов из `morning`, `main`, `evening`, `weekend`; может быть пустым | `["morning", "main"]` |
| `no_entry_before_close_min` | целое ≥ 0 | `60` |
| `flatten_before_close_min` | целое ≥ 0, не больше `no_entry_before_close_min` | `20` |
| `keep_if_tp1_and_breakeven` | логическое | `true` |

Без секции или без ключа ДОЛЖНО применяться значение по умолчанию. Незнакомый ключ, значение не того типа, неизвестный таймфрейм, неизвестное или повторённое имя сессии, отрицательное или нецелое число минут и `flatten_before_close_min > no_entry_before_close_min` ДОЛЖНЫ завершать загрузку `ConfigError` с указанием файла и ключа. Вшитый `default.toml` ДОЛЖЕН содержать секцию со значениями по умолчанию и комментариями к каждому ключу.

#### Scenario: Значения по умолчанию
- **WHEN** секции `[trading.intraday]` нет
- **THEN** правило включено, внутридневные — сделки до `15m` включительно, вход разрешён в утренней и основной сессиях до рубежа за 60 минут, закрытие — за 20 минут до конца блока, перенос позиции с первой фиксацией и безубытком разрешён

#### Scenario: Пустой список сессий
- **WHEN** задано `entry_sessions = []`
- **THEN** конфигурация загружается, а любой внутридневной вход отклоняется с причиной `intraday-session-closed`

#### Scenario: Неизвестная сессия
- **WHEN** задано `entry_sessions = ["main", "night"]`
- **THEN** загрузка завершается `ConfigError` с указанием файла и ключа `entry_sessions`

#### Scenario: Рубеж закрытия позже рубежа входа
- **WHEN** задано `no_entry_before_close_min = 10` и `flatten_before_close_min = 20`
- **THEN** загрузка завершается `ConfigError` с указанием файла и ключа `flatten_before_close_min`

#### Scenario: Незнакомый ключ
- **WHEN** в секции задан ключ `horizon`
- **THEN** загрузка завершается `ConfigError` с указанием файла и ключа
