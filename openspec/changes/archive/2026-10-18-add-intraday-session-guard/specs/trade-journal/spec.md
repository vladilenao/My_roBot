## ADDED Requirements

### Requirement: Причины сессионной защиты в русском виде
Нормативный уровень: MUST.
Пользовательские CSV журнала ДОЛЖНЫ выводить вместо кодов сессионной защиты согласованные русские переводы:

| Код | Перевод |
|---|---|
| `intraday-session-end` | закрытие перед концом торговой сессии |
| `intraday-carry-break-even` | безубыток для переноса через перерыв |
| `intraday-session-closed` | вход вне разрешённой сессии |
| `intraday-close-near` | слишком близко к концу сессии |
| `session-schedule-unknown` | расписание торгов неизвестно |

#### Scenario: Закрытие перед концом сессии в ленте
- **WHEN** внутридневная позиция закрыта командой `CloseTrade` с причиной `intraday-session-end`
- **THEN** колонка «Причина» строки ленты и поле «Финальная причина» карточки содержат «закрытие перед концом торговой сессии»

#### Scenario: Отмена ожидающего входа на рубеже
- **WHEN** незаполненный вход отменён командой `CancelEntry` с причиной `intraday-session-end`
- **THEN** описанием события является «Заявка отменена», а в колонке «Причина» выводится «закрытие перед концом торговой сессии»

#### Scenario: Перенос стопа для переноса позиции
- **WHEN** стоп перенесён командой `MoveStop` с причиной `intraday-carry-break-even`
- **THEN** колонка «Причина» строки ленты содержит «безубыток для переноса через перерыв»
