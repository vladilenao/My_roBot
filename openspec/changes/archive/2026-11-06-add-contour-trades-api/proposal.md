## Why

UI робота (отдельный репозиторий `UI`) на экранах «Эмуляция» и «Песочница» показывает карточку «Позиции и сделки». Владелец выбрал её вид 31.10.2026:

- переключатель периода «День · Неделя · Месяц · Всё»;
- полоса итогов: результат, нереализованный результат, комиссия, число сделок и доля прибыльных, средняя сделка, максимальная просадка;
- кривая накопленного результата: закрытые сделки ступеньками, пунктирный хвост с учётом открытых позиций;
- вкладки «Позиции» и «Сделки», у песочницы ещё «Сверка».

Сейчас эта карточка — заглушка. Робот знает всё нужное: журнал сделок контура (`trades.sqlite3` в папке контура) хранит сделки с привязкой, исполнения, стопы, цели, комиссии, причины выхода и виртуальный счёт эмуляции. Но API отдаёт только число открытых позиций (`current.open_positions`) у эмуляции и лоты на счёте брокера у песочницы. Пожелание UI — `UI/docs/api/trading.md`, пробелы № 2 и № 10 в `UI/docs/api/gaps.md`.

## What Changes

- **Новые ресурсы только на чтение.** У эмуляции и песочницы они одинаковые:
  - `…/positions` — открытые сделки журнала: привязка, сторона, лоты, средняя цена входа, последняя цена, стоп, цели, нереализованный результат;
  - `…/trades` — закрытые сделки за окно: цены входа и выхода, причина выхода, результат, комиссия. Фильтр по инструменту; листание назад по `_links.earlier`, как у свечей;
  - `…/performance` — итоги периода и кривая накопленного результата. Периоды: `day`, `week`, `month`, `all` или явные `from` и `to`.
- **Виртуальный счёт эмуляции** — `GET /api/v1/emulation/account`: начальный депозит, баланс, зафиксированный результат, комиссии.
- **Ссылки.** Ответы `GET /api/v1/emulation` и `GET /api/v1/sandbox` получают `_links.positions`, `_links.trades` и `_links.performance`; эмуляция — ещё `_links.account`. По ним UI узнаёт, что робот новые ресурсы поддерживает.
- **Решения владельца** (31.10.2026):
  - «день» — торговый день биржи с 19:00 МСК накануне;
  - цена для нереализованного результата — закрытие последней `1m` из рыночной базы ядра;
  - меток на графике — фильтр `instrument` у `…/trades`, отдельного вызова нет;
  - прогоны Истории — позже, на тех же схемах.
- **Только чтение, без участия процесса контура.** Ядро читает журнал контура напрямую в режиме только чтения, как уже читает `broker.sqlite3` для сверки и журнал эмуляции для отчёта кластеров. Ответ есть и у остановленного контура.
- **Swagger** — черновик `openspec/changes/add-contour-trades-api/openapi.yaml`, версия 2.4.0. В `docs/api/openapi.yaml` он переезжает вместе с обработчиками.

## Capabilities

### New Capabilities

- `contour-trading-api`: позиции, закрытые сделки, итоги с кривой результата и виртуальный счёт контура по журналу сделок — поля, периоды, расчёты, имена, ссылки, ограничения чтения.

### Modified Capabilities

- `control-api`: «Ошибки API управления» — код `JOURNAL_UNAVAILABLE` (`503`, журнал контура не читается) и маршруты `/api/v1/sandbox…` в перечне. Требование изменено поверх версии из `add-candles-api`: архивировать после него.

Остальное подчиняется действующим требованиям `control-api` без изменений:

- новые маршруты лежат под `/api/v1/emulation…` и `/api/v1/sandbox…`;
- «Доступ к управлению» и «Ресурс контура „Песочница“» задают ключ, `Host` и запрет CORS.

Ограничение «Состояние контура» — «ответ НЕ ДОЛЖЕН содержать сделки, баланс» — сохраняется: сделки и баланс лежат в отдельных ресурсах, в состоянии только ссылки на них.

## Impact

- **Новый `src/bot/trades_view.py`:**
  - чтение журнала контура только на чтение;
  - сборка позиций, сделок и итогов;
  - границы периода;
  - перевод биржевого тикера в короткое имя по `instrument_names` журнала;
  - привязка из конфигурации.
- **`src/trade_journal/`:** чтение исполнений и выходов сделки — общая часть с `CsvExporter` (средние цены, сценарий выхода, причины), без изменения CSV-проекций.
- **`src/data/market_store.py`:** последняя завершённая `1m` инструмента по тикеру (если готового чтения нет).
- **`src/data/export_api.py`:** маршруты `GET …/positions`, `…/trades`, `…/performance` для эмуляции и песочницы, `GET /api/v1/emulation/account`.
- **`src/bot/launch_control.py`, `src/bot/sandbox_control.py`:** `_links` в состоянии контура.
- **Контракт:** `docs/api/openapi.yaml` 2.4.0, `docs/api/README.md`.
- **Тесты:** `tests/unit/bot/` — ресурсы, периоды, расчёты, имена, пустой и отсутствующий журнал, только чтение, контрактный тест на 2.4.0.
- **Без изменений:** торговля, журнал и его схема, CSV-проекции, Telegram, приём данных, свечи, история.
