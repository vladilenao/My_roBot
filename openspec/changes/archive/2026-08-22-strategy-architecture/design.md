# Дизайн: архитектура масштабирования стратегий

## Context

Исследование (сессия /opsx-explore) зафиксировало: стратегия размазана по трём слоям, логика консенсуса продублирована трижды, реестра нет. Пользователь выбрал вариант A (пакеты-стратегии) с анатомией `indicators/`+`signals/` внутри каждого пакета, реестр явный (не автоскан), SignalType/Decision в base.py, форматирование в notifier, m2m через STRATEGY_ASSIGNMENTS, единый snapshot-раннер. См. proposal.md.

## Goals / Non-Goals

**Goals:**
- Стратегия = самодостаточный подключаемый модуль; добавление новой — новый пакет + строка реестра + строка конфига.
- Один источник логики событий стратегии (`expected_events`), используемый движком, тестом и скриптом.
- Сохранение наблюдаемого поведения сообщений и зелёного состояния всех тестов.

**Non-Goals:**
- Сила сигнала / details в Decision (отложено пользователем).
- Генерация STRATEGY_ASSIGNMENTS интерактивным селектором.
- Реализация новых стратегий (только каркас + перенос существующей).
- Изменение потолка 300 свечей и форматов файлов фикстур.

## Decisions

- **D1. Анатомия пакета.** `src/strategies/<name>/`: `__init__.py` (@register), `strategy.py` (класс контракта), `indicators/`, `signals/`. Выбрано пользователем; плоский файл-модуль (вариант B) и декларативный YAML (вариант C) отклонены.
- **D2. Явный реестр вместо автоскана файловой системы.** Детерминированный порядок, ошибки на импорте, а не в рантайме — соответствует духу детерминизма проекта.
- **D3. Контракт в base.py:** Protocol `Strategy` + Enum `SignalType` + dataclass `Decision(signal_type, price)`. Поле details/strength не вводится (Non-Goal).
- **D4. Форматирование — только в `notifier/formatter.py`.** Эмодзи, округление цены до 3 знаков, префикс label. `make_decision` удаляется; наблюдаемые тексты сохраняются дословно.
- **D5. Глубина скачивания: 300 + валидация.** Дефолт запроса остаётся `HARD_LIMIT=300` (зафиксировано сменой default-download-depth). Новое: скрипт запрашивает у стратегии `required_history()` и после загрузки проверяет достаточность строк после прогрева; иначе — выход с ошибкой без записи файлов. Формула глубины от окна НЕ возвращается.
- **D6. Пропуск незапривязанных тикеров:** тикер отсутствует в `STRATEGY_ASSIGNMENTS` или список пуст → skip с записью в лог (решение пользователя).
- **D7. Распускание старых пакетов через `git mv`:** математика `calculator.py` → `macd_rsi_stoch/indicators/{macd,rsi,stochastic}.py`; агрегация из `generator.py` → `macd_rsi_stoch/signals/aggregate.py`; тексты решений → `notifier/formatter.py`. Общие будущие индикаторы будут выделяться осознанно по мере появления второго потребителя (YAGNI).
- **D8. Единый snapshot-раннер:** `test_strategies.py` собирает параметры glob'ом `<case>/*_expected_signals.csv`, параметризация `(case, strategy_name)`, диспетчеризация `get_strategy(name)`; общий `helper.py` (чтение CSV, сравнение `assert_frame_equal(rtol)`, first_divergence, запись эталона). Файл `test_macd_rsi_stoch.py` удаляется; правило «файл на стратегию» отменяется (спека snapshot-testing и context config.yaml обновляются).
- **D9. Исправление опечатки «наeach»** в заголовке требования orchestration выполняется парой REMOVED (Reason/Migration) + ADDED с корректным названием.
- **D10. Кэш DataFrame на тикер в движке:** один запрос свечей обрабатывается всеми назначенными стратегиями; try/except вокруг каждой пары «стратегия×тикер».

## Risks / Trade-offs

- [Активная смена instrument-selection-at-startup держит устаревшие несинхронизированные дельты на orchestration/signals/configuration] → заархивировать/выровнять её ДО архивации этой смены; иначе при её синхронизации устаревшие блоки перезапишут свежие требования.
- [Перенос математики может сдвинуть float-поведение при копировании] → перенос через git mv без редактирования формул; snapshot-тесты фиксируют эквивалентность.
- [Единый раннер размывает правило файла-на-стратегию] → компенсируется шаблоном имени эталона и реестром; спека обновлена явно.
- [Удаление диагностической строки сумм из сообщений меняет вывод бота] → отражено в дельте orchestration («Формат уведомления») осознанно.

## Migration Plan

Каркас (base.py, реестр) → пакет macd_rsi_stoch (git mv + класс) → formatter → движок → snapshot-раннер → скрипт скачивания → чистка и верификация (полный pytest, идемпотентность скачивания, grep мёртвых импортов). Откат — revert коммитов по группам задач.
