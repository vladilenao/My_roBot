# Дельта: configuration

## MODIFIED Requirements

### Requirement: Параметры стратегии
Система ДОЛЖНА предоставлять: `SLEEP_SECONDS=9`, `TIMEFRAME="1h"` и словарь `STRATEGY_ASSIGNMENTS` (тикер → список имён активных стратегий). Глобальный параметр `SIGNAL_WINDOW` ДОЛЖЕН быть удалён — окно расчёта принадлежит каждой стратегии.

#### Scenario: Чтение параметров
- **WHEN** модуль импортирует параметры
- **THEN** возвращаются значения по умолчанию; `SIGNAL_WINDOW` отсутствует

#### Scenario: Привязка инструментов к стратегиям
- **WHEN** модуль читает `STRATEGY_ASSIGNMENTS`
- **THEN** для каждого тикера доступен список имён стратегий, зарегистрированных в реестре
