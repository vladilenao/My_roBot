# Дельта: test-data

## MODIFIED Requirements

### Requirement: Скрипт скачивания тестовых данных
Система ДОЛЖНА предоставлять отдельный скрипт (вне pytest-прогона) для однократного скачивания свечей и записи их в файл фикстур. Скрипт ДОЛЖЕН принимать параметры: тикер, тип инструмента, таймфрейм, имя стратегии (ключ реестра) и кейс. Свечи ДОЛЖНЫ записываться в `tests/snapshot/data/<case>/candles.csv`. Эталон ДОЛЖЕН вычисляться методом `expected_events()` выбранной из реестра стратегии и записываться в `tests/snapshot/data/<case>/<strategy_name>_expected_signals.csv`; собственная математика эталона в скрипте НЕ ДОПУСКАЕТСЯ. Перед записью файлов скрипт ДОЛЖЕН запросить у стратегии `required_history()` и убедиться, что после прогрева индикаторов остаётся достаточно строк для окна стратегии; иначе файлы НЕ ЗАПИСЫВАЮТСЯ, работа завершается ошибкой. Дефолтная глубина запроса остаётся равной абсолютному потолку 300 свечей (см. «Жёсткий лимит глубины истории»).

#### Scenario: Скачивание фикстуры Природный газ 1h
- **WHEN** скрипт запущен для тикера NGU6 (тип future), таймфрейм 1h, стратегия `macd_rsi_stoch`, кейс `NG_1h`
- **THEN** свечи записываются в `tests/snapshot/data/NG_1h/candles.csv`, а эталон — в `tests/snapshot/data/NG_1h/macd_rsi_stoch_expected_signals.csv`, рассчитанный методом `expected_events()` этой стратегии

#### Scenario: Недостаточная история для окна стратегии
- **WHEN** после прогрева индикаторов строк меньше, чем требует `required_history()` стратегии
- **THEN** ни `candles.csv`, ни эталон не записываются; выводится ошибка с указанием требуемой и фактической глубины
