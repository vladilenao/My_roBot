# Дельта: signals

## MODIFIED Requirements

### Requirement: Агрегация сигналов за скользящее окно
Агрегация сигналов индикаторов ДОЛЖНА выполняться внутри пакета стратегии: скользящее окно размером `STRATEGY_WINDOW` стратегии суммирует значения её сигнальных колонок по всей истории. Общие функции агрегации с жёстко заданными именами колонок (`get_last_signals`) НЕ ДОЛЖНЫ существовать вне пакетов стратегий.

#### Scenario: Окно из 5 свечей
- **WHEN** DataFrame содержит ≥5 строк и `STRATEGY_WINDOW=5`
- **THEN** каждая сумма — арифметическая сумма последних 5 значений соответствующей сигнальной колонки

#### Scenario: Окно больше данных
- **WHEN** DataFrame содержит 7 строк, окно стратегии равно 10
- **THEN** окно уменьшается до 7, суммы по всем строкам

### Requirement: Принятие решения о покупке
Решение ПОКУПКА вырабатывает метод `decide()` конкретной стратегии и возвращает `SignalType.BUY`. Для стратегии `macd_rsi_stoch` правилом остаётся строгий консенсус трёх сумм.

#### Scenario: Все индикаторы бычьи
- **WHEN** `macd_sum > 0 AND rsi_sum > 0 AND stoch_sum > 0` на последней свече
- **THEN** `decide()` возвращает `SignalType.BUY` с текущей ценой; текст сообщения формирует formatter

### Requirement: Принятие решения о продаже
Решение ПРОДАЖА вырабатывает метод `decide()` конкретной стратегии и возвращает `SignalType.SELL`. Для стратегии `macd_rsi_stoch` правилом остаётся строгий консенсус трёх сумм.

#### Scenario: Все индикаторы медвежьи
- **WHEN** `macd_sum < 0 AND rsi_sum < 0 AND stoch_sum < 0` на последней свече
- **THEN** `decide()` возвращает `SignalType.SELL` с текущей ценой; текст сообщения формирует formatter

### Requirement: Принятие решения об удержании
Решение УДЕРЖАНИЕ во всех остальных случаях возвращает `SignalType.HOLD`.

#### Scenario: Смешанные сигналы
- **WHEN** не все суммы одного знака
- **THEN** `decide()` возвращает `SignalType.HOLD`; текст «Отдыхаем, сигналов нет.» формирует formatter

#### Scenario: Нулевые сигналы
- **WHEN** все суммы равны 0
- **THEN** возвращается `SignalType.HOLD`

### Requirement: Формат сообщения с instrument_label
Формирование сообщений выполняет модуль `src/notifier/formatter.py`: функция форматирования ДОЛЖНА принимать решение (`Decision`) и опциональный `instrument_label`, добавляя префикс `[instrument_label] `. Функция `make_decision` НЕ ДОЛЖНА существовать.

#### Scenario: С label
- **WHEN** formatter вызван с `instrument_label="NG (Природный газ) — NG-9.26"`
- **THEN** сообщение начинается с `[NG (Природный газ) — NG-9.26]`

#### Scenario: Без label
- **WHEN** formatter вызван с пустым `instrument_label`
- **THEN** префикс `[...]` не добавляется

### Requirement: Формат цены
Округление цены в сообщениях выполняет formatter: цена в сообщениях ПОКУПКА/ПРОДАЖА округляется до 3 знаков после запятой.

#### Scenario: Округление цены
- **WHEN** цена решения равна 3.14159
- **THEN** в сообщении `3.142`

### Requirement: Эмодзи в сообщениях
Эмодзи принадлежат formatter: ПОКУПКА — "🚀 ПОКУПАТЬ!"; ПРОДАЖА — "📉 ПРОДАВАТЬ!"; УДЕРЖАНИЕ — "😴 Отдыхаем, сигналов нет.".

#### Scenario: Эмодзи присутствуют
- **WHEN** formatter получает любое из трёх решений
- **THEN** соответствующее эмодзи присутствует в тексте
