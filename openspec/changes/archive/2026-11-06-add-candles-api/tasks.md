  - 06.11: 500 свечей, последние 7 завершённых 15m совпадают с `GetCandles` брокера по OHLC и объёму. Текущей свечи с `complete: false` нет: в `candle_current` живой контур пишет свечу только по закрытии (незавершённых строк нет с 12.10), поэтому API по правилу «последняя предварительная строка ряда» отдавать нечего — у брокера в тот же момент была 08:30 МСК с `is_complete=false`. Принято владельцем 06.11 как есть: API отдаёт незавершённую свечу по спеке, если она есть в базе; текущая свеча на живом графике — отдельным change позже.
