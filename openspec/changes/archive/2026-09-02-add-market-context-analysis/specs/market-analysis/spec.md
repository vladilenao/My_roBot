## Purpose

Вычисляет рыночный контекст инструмента: направление и силу тренда (EMA + ADX) и горизонтальные уровни поддержки/сопротивления (фракталы + кластеризация) по DataFrame свечей. Является stateless-калькулятором, результат которого кэшируется на уровне MarketContextCache.

## ADDED Requirements

### Requirement: Анализатор тренда
Система ДОЛЖНА предоставлять анализатор тренда, вычисляющий направление (восходящий/нисходящий/боковой) и силу (0.0–1.0) по DataFrame свечей. Направление определяется пересечением короткой и длинной EMA; сила — нормализованным ADX. Параметры (длины EMA, период ADX) задаются через конструктор.

#### Scenario: Восходящий тренд
- **WHEN** короткая EMA выше длинной и ADX ≥ 25
- **THEN** анализатор возвращает направление `up` и силу > 0.0

#### Scenario: Нисходящий тренд
- **WHEN** короткая EMA ниже длинной и ADX ≥ 25
- **THEN** анализатор возвращает направление `down` и силу > 0.0

#### Scenario: Боковой тренд
- **WHEN** ADX < 25
- **THEN** анализатор возвращает направление `flat` и силу 0.0, независимо от положения EMA

#### Scenario: Достаточная глубина истории
- **WHEN** DataFrame содержит меньше баров, чем суммарный прогрев EMA и ADX
- **THEN** анализатор возвращает результат по имеющимся данным (без ошибки)

### Requirement: Калькулятор уровней S/R
Система ДОЛЖНА предоставлять калькулятор горизонтальных уровней поддержки/сопротивления, определяющий ключевые ценовые зоны по DataFrame свечей. Уровни определяются фрактальными разворотами и группируются по ценовой близости; каждому уровню присваивается тип (support/resistance) и сила (количество касаний).

#### Scenario: Определение уровней
- **WHEN** DataFrame содержит достаточно данных для фрактальной детекции
- **THEN** калькулятор возвращает отсортированный список уровней с типом и силой

#### Scenario: Минимальное число касаний
- **WHEN** уровень подтверждён менее чем `min_touches` касаниями
- **THEN** уровень исключается из результата

#### Scenario: Ограничение числа уровней
- **WHEN** обнаружено больше подтверждённых уровней, чем `max_levels`
- **THEN** возвращаются только ближайшие к текущей цене уровни в количестве `max_levels`

#### Scenario: Нет подтверждённых уровней
- **WHEN** ни один уровень не прошёл фильтр `min_touches` (или данных меньше, чем требуется для фрактальной детекции)
- **THEN** калькулятор возвращает пустой список уровней, не подменяя его фиктивными уровнями

### Requirement: Модели рыночного контекста
Система ДОЛЖНА предоставлять неизменяемые модели данных: `TrendDirection` (enum: up/down/flat), `TrendResult` (направление + сила + значения EMA), `SRType` (enum: support/resistance), `SRLevel` (цена + тип + сила + метка) и `MarketContext` (TrendResult + list[SRLevel] + текущая цена). Все модели — frozen dataclass.

#### Scenario: Неизменяемость результатов
- **WHEN** TrendResult или MarketContext создан
- **THEN** изменение его полей вызывает FrozenInstanceError
