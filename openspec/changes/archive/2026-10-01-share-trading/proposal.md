# Торговля акциями

## Why
Метаданные контрактов загружались только для фьючерсов (`load_futures_contracts`). У акции, выбранной в интерфейсе, не было `ContractMeta`, поэтому входной допуск обрывался на `no-contract-metadata` ещё до планирования сделки: сигнал BUY по акции доходил до журнала с отказом «Нет метаданных контракта для инструмента». Ни размер позиции, ни стоп, ни прибыль/убыток по акции посчитать было нельзя.

Формулы расчёта в системе уже универсальны и работают по `price_step` и `step_cost`. Для акции достаточно задать эти величины из каталога: `step_cost = price_step × lot` — цена одного лота, поэтому `(изменение цены / price_step) × step_cost` даёт прибыль или убыток в рублях за лот. Отдельная логика расчёта P&L и риска не нужна, нужны метаданные.

## What Changes
- **Метаданные акций** ДОЛЖНЫ загружаться отдельным вызовом `client.instruments.shares()` для выбранных тикеров акций.
- Для акции метаданные ДОЛЖНЫ содержать `price_step` = минимальный шаг цены, `step_cost` = `price_step × lot`, `go_buy`/`go_sell` = 0 (у акции нет гарантийного обеспечения) и `expiration_date` = `None` (акция не экспирируется).
- Акции без пригодных метаданных (нулевой шаг цены или нулевой лот) ДОЛЖНЫ исключаться с предупреждением; тикер без метаданных остаётся с отказом допуска `no-contract-metadata`.
- Метаданные акций и фьючерсов ДОЛЖНЫ объединяться в единую карту, а источник данных ДОЛЖЕН соответствовать режиму запуска: исторический — клиент провайдера истории, боевой — токен.
- Отказ одного типа инструментов (например, недоступен каталог акций) НЕ ДОЛЖЕН отменять метаданные другого типа.
- Проверка близкой экспирации для акций ДОЛЖНА пропускаться: дата экспирации отсутствует, и неделя блокировки к акции не применяется.

## Impact
- Affected specs: `api-client`, `trade-management`, `risk-management`
- Affected code: `src/api/instruments.py` (`load_share_contracts`), `run.py` (`_load_contracts_metadata`, `_build_runtime`, `_launch`)
- Affected tests: `tests/unit/api/test_instruments.py`, `tests/unit/test_run.py`, `tests/unit/broker/test_journal_broker.py`, `tests/unit/trade_management/test_signal_pipeline.py`
- Боевое поведение: акции, выбранные в интерфейсе, получают полный торговый цикл — допуск, риск-размер по цене лота, стоп, тейк, P&L в рублях и учёт в журнале и отчёте.
