## MODIFIED Requirements

### Requirement: Инструменты из параметров запуска
Нормативный уровень: MUST. Инструменты ДОЛЖНЫ задаваться списком токенов без учёта регистра в поле `instruments` команды API: запуска эмуляции (`POST /api/v1/contours`), изменения её состава и прогона истории (`POST /api/v1/contours` с `kind = history`). Правила разрешения ДОЛЖНЫ быть одинаковыми для всех команд. Без поля ДОЛЖНО применяться значение `all`. Командная строка и меню инструменты больше не задают.

Токены:
- `all` — все акции из секций `[strategies.share.*]` и все семейства фьючерсов из `[strategies.future.*]` конфигурации;
- тикер акции — эта акция;
- код семейства фьючерсов или его биржевой префикс (`NG`, `RTS` или `RI`, `SBRF` или `SR`) — в эмуляции один контракт семейства по правилу ниже, в истории автоматическая цепочка контрактов семейства;
- контракт коротким именем (`NG-12.26`) или биржевым тикером — этот контракт; в истории — фиксированный контракт.

Для семейства в эмуляции ДОЛЖЕН выбираться ближайший по экспирации стандартный контракт из списка активных фьючерсов, до экспирации которого больше `contract_expiry_block_days` суток. Выбор ДОЛЖЕН печататься коротким именем с числом суток до экспирации.

Токен, у которого нет привязок в конфигурации, ДОЛЖЕН отклоняться. Семейство и его же контракт в одной команде ДОЛЖНЫ отклоняться как конфликт. Любой отклонённый токен ДОЛЖЕН давать ответ `422` со списком отказов без запуска торговли.

**Проверка у источника.**

- В эмуляции каждый разрешённый инструмент ДОЛЖЕН проверяться у брокера до ответа.
- В истории до ответа проверяются только привязки и конфликт. Отказ эмулятора данных по разрешённому токену ДОЛЖЕН завершать прогон в состоянии `failed` с отказами, без торговли прогона.

Выбранный инструмент ДОЛЖЕН, как и прежде, включать все свои привязки конфигурации. Инструмент, названный и в эмуляции, и в истории, ДОЛЖЕН в обоих торговаться по одним и тем же привязкам.

#### Scenario: Все инструменты из привязок
- **GIVEN** в конфигурации есть привязки для акции SBER и семейств NG и BR
- **WHEN** приходит `POST /api/v1/contours` с `{"kind": "emulation"}` без `instruments`
- **THEN** торгуются SBER, один контракт NG и один контракт BR, выбранные по правилу ближайшего контракта

#### Scenario: Ближайший контракт пропускается из-за экспирации
- **GIVEN** `contract_expiry_block_days = 2`, у NG до экспирации ближайшего контракта NG-11.26 осталось одни сутки, у следующего NG-12.26 — 31 сутки
- **WHEN** приходит команда запуска эмуляции с `["NG"]`
- **THEN** выбирается NG-12.26, и в консоли печатается `NG → NG-12.26, до экспирации 31 сутки`

#### Scenario: Семейство в истории
- **WHEN** приходит `POST /api/v1/contours` с `"kind": "history"` и `"instruments": ["NG"]`
- **THEN** NG торгуется автоматической цепочкой контрактов

#### Scenario: Явный контракт
- **WHEN** приходит команда запуска эмуляции с `["NG-03.27"]`
- **THEN** торгуется контракт NG-03.27, правило ближайшего контракта не применяется

#### Scenario: Инструмент без привязок
- **GIVEN** у акции AFLT нет секции `[strategies.share.AFLT]`
- **WHEN** приходит команда запуска эмуляции с `["SBER", "AFLT"]`
- **THEN** ответ `422` называет AFLT и причину, торговля не начинается

#### Scenario: Конфликт семейства и контракта
- **WHEN** приходит `POST /api/v1/contours` с `"kind": "history"` и `"instruments": ["NG", "NG-12.26"]`
- **THEN** ответ `422` называет конфликт семейства и фиксированного контракта, прогон не ставится в очередь

#### Scenario: Неизвестный инструмент в меню
- **WHEN** в команде запуска эмуляции названы SBER и опечатка `SBEER`
- **THEN** ответ `422` называет `SBEER`, торговля не начинается ни по SBER, ни по `SBEER`; меню выбора, где опечатка пропускалась, больше нет
