## ADDED Requirements

### Requirement: Консольные сообщения о заявке называют инструмент, а не внутренний идентификатор
Нормативный уровень: MUST.
Консольные шаблоны событий заявки ДОЛЖНЫ выводить короткое имя инструмента и НЕ ДОЛЖНЫ выводить внутренний числовой идентификатор заявки (`order_id`), даже если он присутствует в payload события.

Сообщение о приёме заявки (`order_accepted`) ДОЛЖНО иметь вид `📝 Ордер: Заявка <сторона> <объём> <инструмент> по <цена> принята` без хвоста `(id=…)`.

Сообщение об отмене заявки (`trade_cancelled`) ДОЛЖНО иметь вид `❌ Отмена: Заявка <инструмент> отменена (<причина>)`, сохраняя русский перевод причины; для причины истечения срока заявки — `❌ Отмена: Заявка <инструмент> истекла по TTL`. Если короткое имя инструмента неизвестно, выводится заглушка `контракт не указан`.

Событие `trade_cancelled`, публикуемое брокером напрямую, ДОЛЖНО нести короткое имя инструмента наравне с событиями отмены, публикуемыми владельцем lifecycle.

#### Scenario: Приём заявки без идентификатора
- **WHEN** консоль получает `order_accepted` по SELL 7 контрактов ED-12.26 по 1.1255 с заполненным `order_id`
- **THEN** сообщение равно `📝 Ордер: Заявка SELL 7 ED-12.26 по 1.1255 принята` и не содержит числового `order_id`

#### Scenario: Отмена по таймауту входа
- **WHEN** консоль получает `trade_cancelled` по ED-12.26 с причиной `entry-timeout`
- **THEN** сообщение равно `❌ Отмена: Заявка ED-12.26 отменена (вход не исполнен в отведённое время)`

#### Scenario: Истечение заявки по TTL
- **WHEN** консоль получает `trade_cancelled` по NG-10.26 с причиной `ttl`
- **THEN** сообщение равно `❌ Отмена: Заявка NG-10.26 истекла по TTL`

#### Scenario: Отмена, идущая от брокера, несёт инструмент
- **WHEN** брокер отменяет заявку напрямую или снимает её по истечении срока
- **THEN** публикуемое событие `trade_cancelled` содержит короткое имя инструмента, и консольный текст показывает его, а не `None` и не пустоту

#### Scenario: Сырой биржевой тикер не выводится
- **WHEN** отменяется фьючерс с коротким именем `ED-12.26` и биржевым кодом `EDZ6`
- **THEN** консольное сообщение содержит `ED-12.26` и не содержит `EDZ6`
