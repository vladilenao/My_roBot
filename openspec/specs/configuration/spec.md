# Конфигурация

## Purpose

Централизованное управление всей конфигурацией времени выполнения: секреты, загружаемые из `.env`, маппинг таймфреймов и параметры стратегии. Этот модуль является единым источником истины для констант, потребляемых всеми остальными модулями.

## Requirements

### Requirement: Загрузка переменных окружения
- Система ДОЛЖНА загружать переменные окружения из файла `.env` в корне проекта с помощью `python-dotenv`.

#### Scenario: Переменные окружения загружаются при импорте
- **WHEN** другой модуль импортирует `src.config`
- **THEN** файл `.env` считывается и все три константы токенов (`TINKOFF_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`) заполняются значениями из окружения

#### Scenario: Отсутствие файла `.env`
- **WHEN** файл `.env` не существует в корне проекта
- **THEN** константы токенов устанавливаются в `None` и исключение при импорте не выбрасывается

### Requirement: Экспорт секретов
- Система ДОЛЖНА предоставлять следующие секреты в виде констант уровня модуля: `TINKOFF_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`.

#### Scenario: Токены доступны как константы
- **WHEN** модуль `src.config` импортирован
- **THEN** константы `TINKOFF_TOKEN`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID` доступны для чтения

### Requirement: Маппинг таймфреймов
- Система ДОЛЖНА предоставлять словарь `TIMEFRAMES`, отображающий строковые ключи (`1m`, `5m`, `15m`, `1h`, `1d`, `1w`, `1M`) в значения перечисления `CandleInterval` из `t_tech.invest`.

#### Scenario: Допустимый ключ таймфрейма
- **WHEN** потребитель ищет допустимый ключ таймфрейма (например `"1h"`) в `TIMEFRAMES`
- **THEN** возвращается соответствующее значение перечисления `CandleInterval`

#### Scenario: Недопустимый ключ таймфрейма
- **WHEN** потребитель ищет недопустимый ключ таймфрейма в `TIMEFRAMES`
- **THEN** выбрасывается `KeyError`

### Requirement: Параметры стратегии
- Система ДОЛЖНА предоставлять следующие параметры стратегии со значениями по умолчанию: `SIGNAL_WINDOW=5`, `SLEEP_SECONDS=9`, `INSTRUMENT_TYPE="future"`, `TIMEFRAME="1h"`, `TICKER="NGU6"`.

#### Scenario: Чтение параметров по умолчанию
- **WHEN** модуль импортирует `SIGNAL_WINDOW`, `SLEEP_SECONDS`, `INSTRUMENT_TYPE`, `TIMEFRAME` или `TICKER` из `src.config`
- **THEN** возвращаются значения по умолчанию (5, 9, "future", "1h", "NGU6" соответственно), если они не переопределены в окружении

### Requirement: Импортируемость констант
- Все константы ДОЛЖНЫ быть импортируемыми напрямую из `src.config` другими модулями.

#### Scenario: Прямой импорт из модуля
- **WHEN** другой модуль выполняет `from src.config import TICKER`
- **THEN** значение `TICKER` успешно импортируется без ошибок
