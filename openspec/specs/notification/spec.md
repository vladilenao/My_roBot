# Уведомления

## Purpose

Доставляет сообщения с торговыми сигналами во внешний канал (Telegram Bot API) и всегда выводит их в stdout. Когда Telegram не настроен — выводит предупреждение и пропускает HTTP-запрос.

## Requirements

### Requirement: Основная функция отправки
- Система ДОЛЖНА предоставлять функцию `send_signal(text)`.

#### Scenario: Сообщение выводится в stdout
- **WHEN** `send_signal` вызывается с любым текстом
- **THEN** текст выводится в stdout

### Requirement: Проверка конфигурации Telegram
- Если `TELEGRAM_BOT_TOKEN` или `TELEGRAM_CHANNEL_ID` не заданы (None/пустые), система ДОЛЖНА вывести предупреждение в stdout и пропустить HTTP-запрос.

#### Scenario: Telegram не настроен
- **WHEN** `TELEGRAM_BOT_TOKEN` равен `None`
- **THEN** выводится предупреждение "Telegram не настроен", HTTP-запрос не выполняется

### Requirement: Ранний возврат (early return)
- После проверки конфигурации функция ДОЛЖНА выполнить `return`, пропуская весь код отправки ниже.

#### Scenario: Функция завершается после проверки
- **WHEN** Telegram не настроен
- **THEN** функция печатает предупреждение, печатает текст, и завершается через `return` без выполнения HTTP-запроса

### Requirement: Отправка через Telegram Bot API (mёртвый код)
- Код отправки HTTP POST на `https://api.telegram.org/bot{token}/sendMessage` присутствует в функции, но位于 `return`之后 и НЕ выполняется.
- HTTP-запрос имеет таймаут 10 секунд.

#### Scenario: Код отправки недостижим
- **WHEN** функция достигает оператора `return`
- **THEN** HTTP-код ниже `return` никогда не выполняется

### Requirement: Обработка ошибок HTTP (mёртвый код)
- Код обработки HTTP 200/non-200 присутствует, но недостижим.

#### Scenario: Код обработки ошибок недостижим
- **WHEN** функция завершается через `return`
- **THEN** обработка HTTP-ошибок не выполняется

### Requirement: Гарантированный вывод в stdout
- Текст сообщения ВСЕГДА выводится в stdout независимо от конфигурации Telegram.

#### Scenario: Вывод при отсутствии Telegram
- **WHEN** Telegram не настроен
- **THEN** текст выводится в stdout после предупреждения

#### Scenario: Вывод при настроенном Telegram (будущее)
- **WHEN** Telegram будет настроен
- **THEN** текст будет выведен в stdout (код отправки в Telegram по-прежнему недостижим из-за `return`)
