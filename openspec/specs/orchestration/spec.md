# Оркестрация

## Purpose

Запускает главный цикл бота, который непрерывно загружает рыночные данные, вычисляет индикаторы, генерирует сигналы, принимает решения и отправляет уведомления с фиксированным интервалом. Является центральным координатором всех модулей.

## Requirements

### Requirement: Бесконечный цикл бота
- Система ДОЛЖНА предоставлять функцию `run_bot()`, выполняющую бесконечный цикл.

#### Scenario: Запуск цикла
- **WHEN** вызывается `run_bot()`
- **THEN** начинается бесконечный цикл, повторяющий конвейер обработки

### Requirement: Конвейер обработки на каждой итерации
- На каждой итерации система ДОЛЖНА выполнять следующий конвейер по порядку: загрузить свечи, рассчитать индикаторы, агрегировать сигналы, определить текущую цену, принять решение, отправить уведомление, перейти в спящий режим.

#### Scenario: Нормальная итерация с данными
- **WHEN** `run_bot()` запускается И свечные данные доступны
- **THEN** система загружает свечи, вычисляет индикаторы, агрегирует сигналы, принимает решение, отправляет отформатированное сообщение и переходит в спящий режим на `SLEEP_SECONDS`

### Requirement: Использование конфигурации
- Система ДОЛЖНА использовать следующие значения конфигурации из `src.config`: `TICKER`, `INSTRUMENT_TYPE`, `TIMEFRAME`, `SIGNAL_WINDOW`, `SLEEP_SECONDS`.
- Система ДОЛЖНА передавать `start_date=None` и `end_date=None` в `load_candles` (по умолчанию последние 30 дней).

#### Scenario: Конфигурация применяется к загрузке
- **WHEN** `run_bot()` выполняет итерацию
- **THEN** `load_candles` вызывается с `TICKER`, `INSTRUMENT_TYPE`, `TIMEFRAME` из конфигурации и `start_date=None`, `end_date=None`

### Requirement: Обработка пустых данных
- Если загруженный DataFrame пуст, система ДОЛЖНА вывести "Нет данных – пропускаем итерацию", перейти в спящий режим на `SLEEP_SECONDS` и продолжить следующую итерацию.

#### Scenario: Итерация с пустыми данными
- **WHEN** `load_candles` возвращает пустой DataFrame
- **THEN** система выводит "Нет данных", переходит в спящий режим на `SLEEP_SECONDS` и переходит к следующей итерации без вычисления индикаторов

### Requirement: Формат уведомления
- Сообщение уведомления ДОЛЖНО включать значения сумм индикаторов в формате `"📊 Сигналы: MACD={macd_sum}, RSI={rsi_sum}, Stoch={stoch_sum}"`, за которым следует текст решения на новой строке.

#### Scenario: Формат сообщения
- **WHEN** итерация завершается успешно
- **THEN** отправляемое сообщение содержит строку "📊 Сигналы:" с тремя значениями сумм и текст решения на следующей строке

### Requirement: Спящий режим между итерациями
- После отправки уведомления (или пропуска из-за пустых данных) система ДОЛЖНА перейти в спящий режим на `SLEEP_SECONDS` перед следующей итерацией.

#### Scenario: Интервал сна между итерациями
- **WHEN** итерация завершается (успешно или с ошибкой)
- **THEN** система ждёт ровно `SLEEP_SECONDS` (по умолчанию 9) перед началом следующей итерации

### Requirement: Корректное завершение по Ctrl+C
- Система ДОЛЖНА перехватывать `KeyboardInterrupt` и выводить "Бот остановлен" перед выходом из цикла.

#### Scenario: Корректное завершение работы
- **WHEN** пользователь нажимает Ctrl+C во время любой итерации
- **THEN** система перехватывает `KeyboardInterrupt`, выводит сообщение о завершении и чисто выходит из цикла

### Requirement: Устойчивость к ошибкам
- Система ДОЛЖНА перехватывать общее `Exception` на каждой итерации, выводить ошибку, перейти в спящий режим на `SLEEP_SECONDS` и продолжать цикл.

#### Scenario: Устойчивость к ошибкам
- **WHEN** во время любой итерации возникает необработанное исключение (например, таймаут API, ошибка вычисления)
- **THEN** система выводит сообщение об ошибке, переходит в спящий режим на `SLEEP_SECONDS` и продолжает следующую итерацию

### Requirement: Точка входа
- Точка входа `run.py` ДОЛЖНА вызывать `run_bot()` при выполнении как `__main__`.

#### Scenario: Запуск через run.py
- **WHEN** `run.py` выполняется как `python run.py`
- **THEN** вызывается `run_bot()` и цикл бота запускается
