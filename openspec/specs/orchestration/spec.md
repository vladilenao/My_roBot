# Оркестрация

## Purpose

Запускает главный цикл бота, который непрерывно для каждого выбранного инструмента: загружает рыночные данные, вычисляет индикаторы, агрегирует сигналы, принимает решения и отправляет уведомления с фиксированным интервалом. Является центральным координатором всех модулей.

## Requirements

### Requirement: Точка входа
- `run.py` ДОЛЖНА вызывать `select_instruments()` для интерактивного выбора, затем `run_bot(instruments)`.

#### Scenario: Запуск через run.py
- **WHEN** `python run.py` выполняется
- **THEN** вызывается `select_instruments()`, результат передаётся в `run_bot(instruments)`
### Requirement: Бесконечный цикл бота
Система ДОЛЖНА предоставлять функцию `run_bot(instruments=None)`, выполняющую бесконечный цикл. Набор стратегий для каждого инструмента ДОЛЖЕН определяться `STRATEGY_ASSIGNMENTS`; инструмент без привязки пропускается с записью в лог.

#### Scenario: Запуск с инструментами
- **WHEN** `run_bot(instruments=[...])` вызывается
- **THEN** начинается бесконечный цикл обработки инструментов и их назначенных стратегий

#### Scenario: Запуск без аргументов (fallback)
- **WHEN** `run_bot()` вызывается без аргументов
- **THEN** используется конфигурация по умолчанию: `[(TICKER, TICKER, INSTRUMENT_TYPE)]` со стратегиями из `STRATEGY_ASSIGNMENTS`
### Requirement: Поддержка двух форматов инструментов
- Система ДОЛЖНА поддерживать и 3-кортежи `(display_name, ticker, instrument_type)`, и 2-кортежи `(ticker, instrument_type)`.

#### Scenario: 3-кортеж (текущий формат)
- **WHEN** элемент кортежа содержит 3 значения
- **THEN** `instrument_label = display_name`, `ticker` и `instrument_type` извлекаются отдельно

#### Scenario: 2-кортеж (legacy формат)
- **WHEN** элемент кортежа содержит 2 значения
- **THEN** `ticker` и `instrument_type` извлекаются напрямую, `instrument_label = f"{ticker} {instrument_type}"`
### Requirement: Обработка пустых данных
- Если DataFrame пуст, система ДОЛЖНА вывести сообщение и перейти к следующему инструменту.

#### Scenario: Пустые данные
- **WHEN** `load_candles` вернул пустой DataFrame
- **THEN** выводится "Нет данных" и итерация пропускается для данного инструмента
### Requirement: Формат уведомления
Сообщение ДОЛЖНО формироваться модулем `notifier/formatter` из решения стратегии: префикс `[instrument_label]` и текст решения. Диагностическая строка с сырыми суммами сигналов из общего движка УДАЛЯЕТСЯ — суммы специфичны для стратегий.

#### Scenario: Формат сообщения
- **WHEN** итерация завершается успешно с решением BUY
- **THEN** сообщение содержит `[instrument_label] 🚀 ПОКУПАТЬ! Цена: X`
### Requirement: Спящий режим
- После обработки всех инструментов система ДОЛЖНА перейти в спящий режим на `SLEEP_SECONDS`.

#### Scenario: Пауза между итерациями
- **WHEN** все инструменты обработаны
- **THEN** система ждёт `SLEEP_SECONDS` перед следующей итерацией
### Requirement: Корректное завершение по Ctrl+C
- Система ДОЛЖНА перехватывать `KeyboardInterrupt` и выводить "Бот остановлен".

#### Scenario: Остановка пользователем
- **WHEN** пользователь нажимает Ctrl+C
- **THEN** выводится "Бот остановлен" и цикл завершается
### Requirement: Устойчивость к ошибкам
Система ДОЛЖНА перехватывать исключения на уровне отдельной стратегии и всего цикла, выводить ошибку и продолжать работу.

#### Scenario: Ошибка в итерации
- **WHEN** возникает необработанное исключение в цикле
- **THEN** выводится сообщение об ошибке, пауза `SLEEP_SECONDS`, цикл продолжается

#### Scenario: Отказ одной стратегии
- **WHEN** `compute()` или `decide()` одной стратегии выбросил исключение
- **THEN** остальные стратегии этого тикера обрабатываются штатно, отказ зафиксирован в логе
### Requirement: Конвейер обработки на каждой итерации
На каждой итерации для каждого инструмента: загрузить свечи (один запрос на тикер) → для каждой назначенной стратегии из реестра: рассчитать сигналы (`compute`) → принять решение (`decide`) → отформатировать уведомление → отправить.

#### Scenario: Нормальная итерация
- **WHEN** данные доступны
- **THEN** полный конвейер выполняется для каждой пары «инструмент × назначенная стратегия»
