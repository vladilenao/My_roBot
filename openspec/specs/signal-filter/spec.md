# Фильтр сигналов

## Purpose

Фильтрует торговые сигналы по именованным профилям фильтрации: фасад выбирает конкретный фильтр фабричным методом по имени профиля привязки (по умолчанию `basic_levels` — блокировка против тренда). Является чистым трансформером Decision — не зависит от ExecutionPort и не выполняет доставку.

## Requirements

### Requirement: Жёсткий фильтр по тренду
Профиль фильтрации `basic_levels` ДОЛЖЕН при противоречии тренда и сигнала заменять тип сигнала на HOLD. Противоречие: тренд `down` + сигнал BUY, или тренд `up` + сигнал SELL. При тренде `flat` или совпадении направления — сигнал пропускается без изменений.

#### Scenario: Сигнал против тренда
- **WHEN** профиль `basic_levels`, тренд `down` и сигнал BUY (или тренд `up` и сигнал SELL)
- **THEN** фильтр возвращает Decision с типом HOLD

#### Scenario: Сигнал по тренду
- **WHEN** профиль `basic_levels`, тренд `up` и сигнал BUY (или тренд `down` и сигнал SELL)
- **THEN** фильтр возвращает Decision с тем же типом сигнала, обогащённый полями тренда из MarketContext

#### Scenario: Боковой тренд
- **WHEN** профиль `basic_levels` и тренд `flat`
- **THEN** фильтр пропускает любой сигнал (BUY/SELL) без изменений

#### Scenario: HOLD не фильтруется
- **WHEN** входной Decision имеет тип HOLD
- **THEN** фильтр возвращает его без изменений при любом профиле

### Requirement: Обогащение контекстом тренда
Профиль `basic_levels` ДОЛЖЕН добавлять к Decision метаданные тренда: `trend_direction` (строковое значение направления) и `trend_confidence` (сила тренда 0.0–1.0). При HOLD по фильтру confidence ДОЛЖНА быть 0.0. Профиль `raw` НЕ ДОЛЖЕН обогащать Decision.

#### Scenario: Сигнал пропущен
- **WHEN** сигнал не заблокирован фильтром профиля `basic_levels`
- **THEN** Decision содержит `trend_direction` и `trend_confidence` из текущего MarketContext

#### Scenario: Сигнал заблокирован
- **WHEN** сигнал заменён на HOLD из-за противоречия тренду
- **THEN** Decision содержит `trend_direction` из MarketContext и `trend_confidence = 0.0`

### Requirement: Чистый трансформер
Фасад фильтрации ДОЛЖЕН быть stateless frozen dataclass с методом `apply(decision, ctx, profile_name) → Decision`; выбор конкретного фильтра ДОЛЖЕН выполняться внутри фасада фабричным методом по имени профиля. Фильтр НЕ ДОЛЖЕН зависеть от ExecutionPort, нотификатора или MarketDataCache. Фильтр НЕ ДОЛЖЕН выполнять доставку результатов.

#### Scenario: Независимость от порта исполнения
- **WHEN** фильтр применяется к Decision
- **THEN** ни один ExecutionPort не вызывается, доставка не выполняется

#### Scenario: Выбор фильтра фабричным методом
- **WHEN** вызвано `apply(decision, ctx, profile_name="raw")`
- **THEN** фасад конструирует фильтр профиля `raw` по имени и делегирует ему решение

### Requirement: Реестр профилей фильтрации
Система ДОЛЖНА предоставлять реестр профилей фильтрации, содержащий профили `raw` и `basic_levels`. Профиль по умолчанию — `basic_levels`. Запрос неизвестного имени профиля ДОЛЖЕН завершаться ошибкой с перечнем доступных профилей. Добавление нового профиля ДОЛЖНО выполняться регистрацией класса фильтра в реестре без изменения главного цикла робота.

#### Scenario: Профиль по умолчанию
- **WHEN** привязка не задаёт профиль фильтрации
- **THEN** применяется профиль `basic_levels`

#### Scenario: Неизвестный профиль
- **WHEN** запрошен профиль с незарегистрированным именем
- **THEN** выбрасывается ошибка с перечнем доступных профилей

#### Scenario: Расширение реестра
- **WHEN** в реестр зарегистрирован новый класс фильтра
- **THEN** профиль доступен по имени в привязках без изменения главного цикла робота

### Requirement: Профиль raw
Профиль фильтрации `raw` ДОЛЖЕН пропускать любое решение без изменений: тип сигнала сохраняется, обогащение полями тренда НЕ ДОЛЖНО выполняться.

#### Scenario: Сигнал против тренда проходит
- **WHEN** профиль `raw`, тренд `down` и сигнал BUY
- **THEN** фильтр возвращает Decision с типом BUY

#### Scenario: Без обогащения
- **WHEN** профиль `raw` применён к любому решению
- **THEN** поля `trend_direction` и `trend_confidence` остаются без изменений
