# Агрегация сигналов и принятие решений

## Purpose

Агрегирует сигналы индикаторов по свечам за скользящее окно и вырабатывает финальное торговое решение (ПОКУПКА, ПРОДАЖА или УДЕРЖАНИЕ) на основе консенсуса всех трёх индикаторов. Поддерживает опциональную привязку к конкретному инструменту через `instrument_label`.

## Requirements

### Requirement: Агрегация сигналов за скользящее окно
- Система ДОЛЖНА предоставлять функцию `get_last_signals(data_ta, window=5)`, возвращающую `(macd_sum, rsi_sum, stoch_sum)`.

#### Scenario: Окно из 5 свечей
- **WHEN** DataFrame содержит ≥5 строк и `window=5`
- **THEN** каждая сумма — арифметическая сумма последних 5 значений

#### Scenario: Окно больше данных
- **WHEN** DataFrame содержит 7 строк, `window=10`
- **THEN** `window` уменьшается до 7, суммы по всем строкам

### Requirement: Принятие решения о покупке
- **ПОКУПКА** когда все три суммы строго положительные.

#### Scenario: Все индикаторы бычьи
- **WHEN** `macd_sum > 0 AND rsi_sum > 0 AND stoch_sum > 0`
- **THEN** возвращается сообщение о ПОКУПКЕ с текущей ценой

### Requirement: Принятие решения о продаже
- **ПРОДАЖА** когда все три суммы строго отрицательные.

#### Scenario: Все индикаторы медвежьи
- **WHEN** `macd_sum < 0 AND rsi_sum < 0 AND stoch_sum < 0`
- **THEN** возвращается сообщение о ПРОДАЖЕ с текущей ценой

### Requirement: Принятие решения об удержании
- **УДЕРЖАНИЕ** во всех остальных случаях.

#### Scenario: Смешанные сигналы
- **WHEN** не все суммы одного знака
- **THEN** возвращается "Отдыхаем, сигналов нет."

#### Scenario: Нулевые сигналы
- **WHEN** все суммы равны 0
- **THEN** возвращается УДЕРЖАНИЕ

### Requirement: Формат сообщения с instrument_label
- Функция `make_decision(macd_sum, rsi_sum, stoch_sum, current_price, instrument_label="")` ДОЛЖНА поддерживать опциональный параметр `instrument_label`.

#### Scenario: С label
- **WHEN** `instrument_label="NG (Природный газ) — NG-9.26"`
- **THEN** сообщение начинается с `[NG (Природный газ) — NG-9.26]`

#### Scenario: Без label
- **WHEN** `instrument_label=""` (по умолчанию)
- **THEN** префикс `[...]` не добавляется

### Requirement: Формат цены
- Цена в сообщениях ПОКУПКА/ПРОДАЖА округляется до 3 знаков после запятой.

#### Scenario: Округление цены
- **WHEN** `current_price = 3.14159`
- **THEN** в сообщении `3.142`

### Requirement: Эмодзи в сообщениях
- ПОКУПКА: "🚀 ПОКУПАТЬ!"; ПРОДАЖА: "📉 ПРОДАВАТЬ!"; УДЕРЖАНИЕ: "😴 Отдыхаем, сигналов нет."

#### Scenario: Эмодзи присутствуют
- **WHEN** принимается любое решение
- **THEN** соответствующее эмодзи присутствует в тексте
