# Агрегация сигналов и принятие решений

## Purpose

Агрегирует сигналы индикаторов по свечам за скользящее окно и вырабатывает финальное торговое решение (ПОКУПКА, ПРОДАЖА или УДЕРЖАНИЕ) на основе консенсуса всех трёх индикаторов.

## Requirements

### Requirement: Агрегация сигналов за скользящее окно
- Система ДОЛЖНА предоставлять функцию `get_last_signals(data_ta, window=5)`, возвращающую кортеж из трёх сумм: `(macd_sum, rsi_sum, stoch_sum)`.
- Каждая сумма — это арифметическая сумма значений соответствующего столбца сигналов за последние `window` свечей.
- Если в DataFrame меньше строк, чем `window`, система ДОЛЖНА использовать все доступные строки (т.е. `window = len(data_ta)`).

#### Scenario: Агрегация по окну из 5 свечей
- **WHEN** DataFrame содержит 20 строк и `window=5`
- **THEN** каждая из трёх сумм вычисляется как сумма последних 5 значений соответствующего столбца сигналов

#### Scenario: Окно больше объёма данных
- **WHEN** `get_last_signals` вызывается с `window=10`, но DataFrame содержит всего 7 строк
- **THEN** функция использует `window=7` и суммирует по всем доступным строкам

### Requirement: Принятие решения о покупке
- Решение — **ПОКУПКА**, когда все три суммы строго положительные (`macd_sum > 0 AND rsi_sum > 0 AND stoch_sum > 0`).

#### Scenario: Все индикаторы бычьи
- **WHEN** `macd_sum = 3`, `rsi_sum = 2`, `stoch_sum = 1` (все положительные)
- **THEN** `make_decision` возвращает сообщение о ПОКУПКЕ с текущей ценой

### Requirement: Принятие решения о продаже
- Решение — **ПРОДАЖА**, когда все три суммы строго отрицательные (`macd_sum < 0 AND rsi_sum < 0 AND stoch_sum < 0`).

#### Scenario: Все индикаторы медвежьи
- **WHEN** `macd_sum = -2`, `rsi_sum = -1`, `stoch_sum = -3` (все отрицательные)
- **THEN** `make_decision` возвращает сообщение о ПРОДАЖЕ с текущей ценой

### Requirement: Принятие решения об удержании
- Решение — **УДЕРЖАНИЕ** во всех остальных случаях (смешанные или нулевые сигналы).

#### Scenario: Смешанные сигналы
- **WHEN** `macd_sum = 1`, `rsi_sum = -1`, `stoch_sum = 0` (не все одного знака)
- **THEN** `make_decision` возвращает сообщение об УДЕРЖАНИИ

#### Scenario: Нулевые сигналы у всех индикаторов
- **WHEN** `macd_sum = 0`, `rsi_sum = 0`, `stoch_sum = 0`
- **THEN** `make_decision` возвращает сообщение об УДЕРЖАНИИ (ноль не является строго положительным и строго отрицательным)

### Requirement: Формат сообщения о покупке
- Сообщение о ПОКУПКЕ ДОЛЖНО содержать эмодзи "🚀", текст "ПОКУПАТЬ!" и текущую цену, округлённую до 3 знаков после запятой.

#### Scenario: Форматирование цены при покупке
- **WHEN** `make_decision` возвращает сообщение о ПОКУПКЕ с `current_price = 3.14159`
- **THEN** цена в сообщении отображается как `3.142` (округлённая до 3 знаков после запятой)

### Requirement: Формат сообщения о продаже
- Сообщение о ПРОДАЖЕ ДОЛЖНО содержать эмодзи "📉", текст "ПРОДАВАТЬ!" и текущую цену, округлённую до 3 знаков после запятой.

#### Scenario: Форматирование цены при продаже
- **WHEN** `make_decision` возвращает сообщение о ПРОДАЖЕ с `current_price = 3.14159`
- **THEN** цена в сообщении отображается как `3.142` (округлённая до 3 знаков после запятой)

### Requirement: Формат сообщения об удержании
- Сообщение об УДЕРЖАНИИ ДОЛЖНО содержать эмодзи "😴" и текст "Отдыхаем, сигналов нет."

#### Scenario: Текст сообщения об удержании
- **WHEN** `make_decision` возвращает решение УДЕРЖАНИЕ
- **THEN** сообщение содержит эмодзи "😴" и текст "Отдыхаем, сигналов нет."
