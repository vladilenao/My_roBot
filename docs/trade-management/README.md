# Документация пользователя: управление сделками

- [Общий риск портфеля: 2% от цен входа](portfolio-risk.md) — согласованная
  торговая модель, формулы LONG/SHORT, общий бюджет, перенос стопа,
  частичные выходы, доборы и резервы ожидающих заявок с численными примерами.
- [Конвейер сигнала: от решения до исполнения](signal-pipeline.md) — порядок
  шагов тика, путь одного сигнала, фазы сделки и таблица ответственности:
  кто владеет состоянием, а кто только читает.
- [Четыре профиля управления сделкой](profiles.md) — уровни, цели, стопы, доборы
  и выходы с графиками (`levels_rr`, `atr_trend`, `ma_cloud`, `pattern_targets`).
- [Хранилище сделок, CSV-экспорт и аудит](storage-and-audit.md) — SQLite как
  источник истины, автоматические `journal.csv`/`positions.csv`, `trade_audit.log`
  и поведение при блокировке файлов на Windows/macOS.

Уведомления пользователю: [События шины уведомлений](../notification/events.md) —
каталог событий, видимость по каналам и точки публикации;
[Схемы payload](../notification/event-schemas.md) — форма данных каждого события.
