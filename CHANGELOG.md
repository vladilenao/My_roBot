# История изменений

Все заметные изменения робота фиксируются в этом файле.
Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версионирование — [SemVer](https://semver.org/lang/ru/).

## 1.1.0 — 11.09.2026

### Добавлено
- Технический журнал робота: рядом с исполняемым файлом создаётся файл `bot_debug.log`, в который записываются все подробности работы:
  - **данные** — например, загруженные свечи по инструменту «NG»;
  - **ошибки** — например, сбой при обращении к API или ошибка тика;
  - **предупреждения** — например, превышение лимита запросов или задержка публикации свечи.
- Каждая запись журнала помечена временем и номером тика — например, `2026-09-11 11:21:50 [ID:tick-379072ce]`. По этой метке удобно искать конкретный момент, если что-то пошло не так.
- Журнал работает «из коробки»: настройка не требуется, при желании параметры можно изменить в разделе `[logging]` файла `robot.toml`.

### Изменено
- Консоль больше не засоряется техническими сообщениями: там остались только торговые уведомления (сигналы, сердцебиение, ошибки). Подробности — в `bot_debug.log`.

## 1.0.0 — 10.09.2026

### Добавлено
- Версия робота (SemVer) и её вывод в лог при запуске.
- Журнал изменений (этот файл).
- Параметры запуска выносятся в `robot.toml` рядом с исполняемым файлом;
  при отсутствии файла используются значения, вшитые в сборку.
- Токены и прочие секреты не попадают в сборку — они задаются в `.env`
  у получателя.
