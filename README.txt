========================================================================
ПОЛУЧЕНИЕ И СБОРКА РЕЛИЗА РОБОТА
========================================================================

Эта инструкция находится внутри готового дистрибутива. Полный регламент
выпуска для разработчиков — docs/release/build-and-distribution.md в исходном
репозитории.

------------------------------------------------------------------------
1. СКАЧИВАНИЕ ГОТОВОЙ СБОРКИ
------------------------------------------------------------------------
Откройте страницу GitHub Releases и выберите нужную версию:
  * macOS Apple Silicon: robot-vX.Y.Z-macos-arm64.zip
  * Windows x64: robot-vX.Y.Z-windows-x64.zip

Архивы со страницы Releases — официальный способ получения робота.
Временные artifacts во вкладке Actions предназначены только для диагностики.

------------------------------------------------------------------------
2. ПОДГОТОВКА К ЗАПУСКУ
------------------------------------------------------------------------
Распакуйте ZIP. Внутри находится одна папка с binary, VERSION.txt,
README.txt, robot.toml.example и notes.

Скопируйте robot.toml.example в robot.toml и настройте параметры для своей
машины. Создайте .env с собственными токенами. Не передавайте .env другим
людям и не добавляйте его в архив.

------------------------------------------------------------------------
3. ЗАПУСК
------------------------------------------------------------------------
macOS: откройте Терминал в распакованной папке и запустите файл:

$ ./robot-vX.Y.Z-macos-arm64

Windows: откройте Командную строку или PowerShell в изолированной папке
и запустите файл:

> robot-vX.Y.Z-windows-x64.exe

Программа работает автономно: конфигурация читается из robot.toml,
токены — из .env. Правки исходного кода не влияют на уже распакованный
binary.

В текущем режиме при запуске показывается обзор последних доступных закрытых
свечей с датами, временем и результатами стратегий. Обзор сам по себе не создаёт
торговую заявку. Далее робот анализирует новые завершённые свечи и сообщает
об ожидании сессии, задержке и восстановлении данных.

Live-свечи принимаются в фоне: по умолчанию опросом, а при
[market_data] live_transport = "stream" — подпиской с резервным опросом.
Если нужная свеча не пришла, анализ и сделки по этому инструменту ждут
восстановления данных, остальные инструменты продолжают работу. Откат —
вернуть live_transport = "polling". Подробности для разработчиков:
docs/market-data/live-ingestion.md.

Неблагоприятное отклонение текущей цены от планового входа ограничивается
параметром [trading.risk_limits] max_entry_deviation_r (дефолт 0.25R, где R —
расстояние вход–стоп). Полное описание для разработчиков:
docs/live-session-analysis.md.

Сделки с таймфреймом до 15m открываются только в утренней и основной
сессиях и не позже чем за 60 минут до конца основной сессии; за 20 минут
до конца они закрываются, кроме уже взявших первую цель со стопом в
безубытке. Настройки — секция [trading.intraday] в robot.toml, выключить —
enabled = false. Подробности: docs/trade-management/signal-pipeline.md.

ВАЖНО:
- Используйте только архив своей ОС и архитектуры.
- Сверьте SHA-256 с checksums.txt до первого запуска.
