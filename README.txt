========================================================================
ИНСТРУКЦИЯ ПО СБОРКЕ ИЗОЛИРОВАННОГО ПРИЛОЖЕНИЯ (МАCОS)
========================================================================

Данная инструкция описывает процесс сборки торгового робота в один
самодостаточный исполняемый файл, который можно запускать автономно
от папки разработки.

------------------------------------------------------------------------
1. ПОДГОТОВКА И УСТАНОВКА СБОРЩИКА
------------------------------------------------------------------------
Перед сборкой убедитесь, что терминал находится в папке проекта
и виртуальное окружение (например, Anaconda или venv) активно.

Установите или обновите утилиту PyInstaller:
$ pip install --upgrade pyinstaller

------------------------------------------------------------------------
2. КОМАНДА СБОРКИ Проекта
------------------------------------------------------------------------
Запустите в терминале следующую команду (выполняется из корня проекта):

$ pyinstaller --onefile --paths=. --exclude-module PyQt6 --exclude-module PySide6 --collect-all pandas_ta_classic --collect-all t_tech run.py

Что означают флаги:
* --onefile : упаковать всё в один единственный бинарный файл.
* --paths=. : явно указать корень проекта для правильного поиска вашей папки 'src'.
* --exclude-module : исключить лишние GUI библиотеки Qt, чтобы избежать конфликтов.
* --collect-all : принудительно зашить все внутренние файлы данных, папки индикаторов
  (для pandas_ta_classic) и SSL-сертификаты (для t_tech) внутрь бинарника.

------------------------------------------------------------------------
3. ПУБЛИКАЦИЯ И ЗАПУСК В ИЗОЛЯЦИИ
------------------------------------------------------------------------
После завершения процесса сборки:

1. Перейдите в появившуюся папку `dist/`.
2. Скопируйте созданный исполняемый файл `run` в любую отдельную папку на Mac
   (например, в новую папку на Рабочем столе: `~/Desktop/My_Bot_App`).
3. СКОПИРУЙТЕ ваш файл `.env` с токенами доступа из корня проекта и положите
   его в эту же новую папку РЯДОМ с файлом `run`.

Структура изолированной папки для запуска должна быть такой:
My_Bot_App/
├── run   (исполняемый файл)
└── .env  (файл с API-токенами)

------------------------------------------------------------------------
4. ЗАПУСК
------------------------------------------------------------------------
Откройте Терминал, перейдите в вашу изолированную папку и запустите файл:

$ cd ~/Desktop/My_Bot_App
$ ./run

Программа будет работать полностью автономно, используя переменные из файла .env.
Вы можете продолжать вносить любые правки в исходный код в PyCharm/VS Code —
на работу запущенного файла это не повлияет.

ВАЖНО: Исполняемый файл собирается под архитектуру вашего текущего процессора
(Apple Silicon M-серии или Intel) и будет работать на других Mac с такой же архитектурой.
